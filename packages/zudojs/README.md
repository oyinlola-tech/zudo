# zudojs

The command-line interface for [ZudoJS](https://zudojs.oyinlola.site), a modular TypeScript framework for Node.js.

```bash
npm install -g zudojs
zudojs create my-api
cd my-api
zudojs dev
```

`zudo` works as a shorter alias for every command (`zudo create my-api`, `zudo dev`).

This package only installs and runs [`zudojs-cli`](https://www.npmjs.com/package/zudojs-cli); both give you the same `zudojs` command. Full reference: [zudojs.oyinlola.site/docs/packages-cli](https://zudojs.oyinlola.site/docs/packages-cli).
