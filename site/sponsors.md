# Sponsors

ZudoJS is built in the open and supported by developers and organizations who believe in a better framework ecosystem.

COMMUNITY SPONSORSHIP

## Why Sponsor?

Open-source frameworks require ongoing investment. Every release involves writing and reviewing code across 39 packages, maintaining comprehensive documentation, testing across multiple environments, addressing security vulnerabilities, and building tools that improve developer experience.

Sponsorship directly funds the time and infrastructure needed to maintain and improve ZudoJS for everyone.

## What Sponsorship Supports

Core Development

Framework architecture, package implementations, API design

New Packages

Extending the ecosystem with additional official packages

CLI Improvements

Better project scaffolding, code generation, and developer tools

Documentation

Guides, API references, tutorials, and examples

Testing Infrastructure

Unit tests, integration tests, and CI/CD pipelines

Security Maintenance

Vulnerability patches, dependency updates, security audits

Performance Optimization

Profiling, benchmarking, and runtime improvements

Community Tooling

Issue templates, contribution guides, and release automation
