@zudojs/events

Event bus, emitter, middleware pipeline, and registry for Zudojs. Provides typed pub/sub, namespace pattern matching, middleware interception, and a centralized event definition store.

EVENT BUS MIDDLEWARE PUB/SUB

INSTALLATION

// npm npm install @zudojs/events // pnpm pnpm add @zudojs/events // yarn yarn add @zudojs/events
Dependencies: @zudojs/events depends on @zudojs/errors and @zudojs/constants, both at version 0.1.0.

WHAT IT DOES

@zudojs/events is the event infrastructure for Zudojs. It provides:

  • → An EventBus that coordinates publish/subscribe with lifecycle management
  • → An EventEmitter for low-level event dispatching with pattern matching
  • → An EventRegistry that stores event definitions and handler mappings
  • → A middleware pipeline that intercepts events before/after/around handlers
  • → Pattern matching with exact names, namespace wildcards (user.*), and catch-all (*)
Core Principle: Events are first-class citizens. Define them once with defineEvent(), register them on the bus, publish through the bus, and let middleware handle cross-cutting concerns like logging, validation, and timing. Handlers registered on the bus or directly on its registry are dispatched alike.

WHERE IT SITS

APPLICATION LAYER (CQRS, Modules, Handlers)
EVENT BUS (@zudojs/events)
MESSAGING LAYER (@zudojs/messaging)
ADAPTER LAYER (@zudojs/adapters, External Platforms)

Events sit at the application boundary. Application code publishes events through the bus. The bus dispatches them to registered handlers, optionally routing them through middleware. For cross-service communication, events flow down to the messaging layer.

CORE API — EVENT

Interface: Event

The base shape for all events flowing through the bus. Events are frozen; the payload is deep-frozen by the emitter when freezeEvents is on (the default).

interface Event<TPayload = unknown> { readonly id: EventId; // branded string, "event:<uuid>" by default readonly type: EventType; // normalized dot-separated name, e.g. "user.created" readonly payload: TPayload; readonly timestamp: Date; readonly source?: string; readonly correlationId?: EventCorrelationId; readonly causationId?: string; readonly metadata?: Readonly<Record<string, unknown>>; }

Interface: EventInput

The input shape when creating events. id and timestamp are generated when omitted; plain strings are accepted for ids.

interface EventInput<TPayload = unknown> { readonly id?: EventId | string; readonly type: EventType; readonly payload: TPayload; readonly timestamp?: Date | number; readonly source?: string; readonly correlationId?: EventCorrelationId | string; readonly causationId?: string; readonly metadata?: Readonly<Record<string, unknown>>; }

Interface: EventDefinition

A typed definition created with defineEvent(). It carries the normalized type and a create() factory; this is what bus.register() accepts.

interface EventDefinition<TType extends string = string, TPayload = unknown> { readonly type: TType; readonly create: (payload: TPayload, options?: Omit<EventInput<TPayload>, "type" | "payload">) => Event<TPayload>; }

Creating Events

import { defineEvent, createEvent } from "@zudojs/events"; // Define a reusable event type const UserCreated = defineEvent<"user.created", { id: string; email: string }>("user.created"); // Create an instance from the definition … const event = UserCreated.create({ id: "abc-123", email: "alice@example.com" }); // … or from plain input const same = createEvent({ type: "User.Created", // normalized to "user.created" payload: { id: "abc-123", email: "alice@example.com" }, }); // event.type === "user.created" // event.timestamp instanceof Date // Invalid types, ids or timestamps throw InvalidEventError

EVENT BUS

The EventBus is the central coordination point. It owns an EventRegistry (definitions and handlers) and an EventEmitter that dispatches through the registry, so handlers registered on either surface are dispatched.

Interface: EventBusOptions

interface EventBusOptions { readonly emitter?: { readonly mode?: EventEmitterMode; // SEQUENTIAL (default) | PARALLEL readonly errorMode?: EventErrorMode; // CONTINUE (bus default) | THROW readonly freezeEvents?: boolean; // deep-freeze events before dispatch, default true readonly maxListeners?: number; // leak warning threshold per pattern, default 100 (0 = off) }; readonly registry?: { readonly allowDuplicateDefinitions?: boolean; readonly onDuplicateHandlerId?: "throw" | "replace"; // default "throw" }; readonly requireRegistration?: boolean; // reject unregistered types with EventTypeNotFoundError readonly middleware?: readonly EventBusMiddlewareItem[]; readonly onWarning?: (warning: EventRegistryWarning) => void; readonly onError?: (error: unknown, context: { source: "handler" | "observer"; event?: Event }) => void; }

Enum: EventBusState

enum EventBusState { CREATED = "created", // starts itself on first publish/subscribe ACTIVE = "active", STOPPED = "stopped", // publish/subscribe throw EventBusStoppedError until start() DISPOSED = "disposed", // final; every operation throws EventBusDisposedError }

Factory Functions

// Create a bus in CREATED state (auto-starts on first use) const bus = createEventBus({ requireRegistration: true }); // Create a bus that is already ACTIVE const started = createStartedEventBus();

Interface: EventPublishResult

interface EventPublishResult<TEvent extends Event = Event> { readonly event: TEvent; readonly handled: boolean; // at least one handler succeeded readonly handlerCount: number; // handlers invoked readonly succeeded: number; readonly failed: number; readonly results: readonly unknown[]; readonly errors: readonly unknown[]; // EventHandlerError[] (cause = raw thrown value) readonly shortCircuited: boolean; // a middleware did not call next() readonly middlewareExecutions?: readonly { middlewareId: string; result: unknown; duration: number }[]; }

Example: Creating and Using a Bus

import { createStartedEventBus, defineEvent, } from "@zudojs/events"; const bus = createStartedEventBus({ requireRegistration: true }); // Register an event definition const UserCreated = defineEvent<"user.created", { id: string; email: string }>("user.created"); bus.register(UserCreated); // Subscribe bus.on("user.created", async (event) => { const { email } = event.payload as { email: string }; console.log(`New user: ${email}`); }); // Publish const result = await bus.publish(UserCreated.create({ id: "1", email: "alice@example.com" })); console.log(result.handled, result.succeeded, result.failed); // Pause, resume, cleanup bus.stop(); // publish() now throws EventBusStoppedError bus.start(); bus.dispose();

EVENT EMITTER

The EventEmitter dispatches events to matching handlers. It stores handlers in an EventHandlerStore (a private EventRegistry, or the store passed via options.store).

Enum: EventEmitterMode

enum EventEmitterMode { SEQUENTIAL = "sequential", // one handler at a time, priority order (default) PARALLEL = "parallel", // all handlers start together }

Enum: EventErrorMode

enum EventErrorMode { THROW = "throw", // first EventHandlerError rejects the emit (emitter default) CONTINUE = "continue", // failures are collected in result.errors (bus default) }

Interface: EventEmitterOptions

interface EventEmitterOptions { readonly mode?: EventEmitterMode; readonly errorMode?: EventErrorMode; readonly freezeEvents?: boolean; // default true readonly store?: EventHandlerStore; // share handlers with a registry readonly maxListeners?: number; // default 100 per pattern, 0 = off readonly onWarning?: (warning: EventRegistryWarning) => void; }

Methods

Method Signature Behaviour
on() · once() · onAny()(pattern, handler, options?): EventSubscriptionRegister handlers. Duplicate ids throw DuplicateEventHandlerError.
off()off(subscription): booleanCancels a subscription.
emit()emit(event: Event, options?): Promise<EventEmitResult>Dispatches. Non-events throw InvalidEventError; an aborted signal throws EventDispatchAbortedError (with partial results).
emitEvent()emitEvent(input: EventInput, options?): Promise<EventEmitResult>Creates the event, then emits.
listenerCount · getRegistrations() · getStore()Introspection.
removeAllListeners()(): voidCancels every subscription.
dispose() · isDisposed()After dispose every call throws EventEmitterDisposedError.

Interface: EventEmitResult

interface EventEmitResult<TEvent extends Event = Event> { readonly event: TEvent; readonly handled: boolean; readonly results: readonly EventHandlerExecutionResult[]; // { handlerId, eventId, ok, result, duration, error? } readonly errors: readonly unknown[]; readonly succeeded: number; readonly failed: number; }
Once semantics: a once handler is removed before it runs, so a handler that throws, or two overlapping dispatches, never invoke it twice. In PARALLEL mode a signal aborted after handlers have started cannot stop them; handlers can observe context.signal to cooperate.

EVENT REGISTRY

The EventRegistry stores event definitions and handlers and notifies observers of changes. It does not dispatch; the emitter reads handlers from it.

Interface: EventRegistryOptions

interface EventRegistryOptions { readonly allowDuplicateDefinitions?: boolean; readonly onDuplicateHandlerId?: "throw" | "replace"; // default "throw" readonly maxHandlersPerPattern?: number; // default 100, 0 = off readonly onWarning?: (warning: EventRegistryWarning) => void; readonly onError?: (error: unknown, context: { source: "observer" }) => void; }

Enum: EventRegistryChangeType

enum EventRegistryChangeType { EVENT_REGISTERED = "event.registered", EVENT_UNREGISTERED = "event.unregistered", HANDLER_REGISTERED = "handler.registered", HANDLER_UNREGISTERED = "handler.unregistered", }

HANDLERS

Type: EventHandler

type EventHandler<TEvent extends Event = Event> = ( event: TEvent, context: EventHandlerContext<TEvent>, ) => unknown | Promise<unknown>; // Object form: { handle(event, context) } type EventHandlerLike<TEvent> = EventHandler<TEvent> | EventHandlerObject<TEvent>;

Interface: EventHandlerContext

interface EventHandlerContext<TEvent extends Event = Event> { readonly event: TEvent; readonly type: EventType; readonly eventId: string; readonly correlationId?: string; readonly causationId?: string; readonly signal: AbortSignal; readonly metadata: Readonly<Record<string, unknown>>; }

Interface: EventHandlerOptions

interface EventHandlerOptions { readonly id?: string; // must be unique per store readonly description?: string; readonly eventType?: EventTypePattern; readonly priority?: number; // finite; higher runs first, default 0 readonly enabled?: boolean; readonly once?: boolean; readonly timeoutMs?: number; // positive; EventTimeoutError when exceeded }

Pattern Matching

Pattern Matches
user.createdOnly user.created (types are normalized, so User.Created is the same).
user.*user, user.created, user.profile.updated, …
*Every event.
user.*.created · user.cre*Rejected with TypeError; wildcards are only valid as a trailing .*.

Helper Functions

createEventHandler, typedEventHandler, onceEventHandler, prioritizedEventHandler, enableEventHandler, disableEventHandler, setEventHandlerPriority, fireAndForgetHandler, sortEventHandlers, getMatchingEventHandlers, executeEventHandler, executeRegisteredEventHandler (applies timeoutMs).

Example: Registering Handlers

// High priority runs first bus.on("order.placed", reserveStock, { id: "reserve-stock", priority: 100 }); bus.on("order.placed", sendReceipt, { id: "send-receipt", priority: 10, timeoutMs: 5000 }); // Namespace subscription bus.on("order.*", (event, ctx) => audit.log(event.type, ctx.correlationId)); // One-time handler bus.once("app.ready", () => console.log("ready"));

SUBSCRIPTIONS

Interface: EventSubscription

interface EventSubscription { readonly id: string; // equals the handler id readonly description?: string; readonly state: EventSubscriptionState; // ACTIVE | CANCELLED readonly active: boolean; unsubscribe(): void; // idempotent; no-op after the registry was disposed }

Class: EventSubscriptionGroup

Collects subscriptions to dispose together. unsubscribe() attempts every member; failures are re-thrown as an AggregateError and the failed members stay in the group for a retry.

const group = createEventSubscriptionGroup(); group.add(bus.on("user.created", onCreated)); group.add(bus.on("user.deleted", onDeleted)); // later group.unsubscribe();

MIDDLEWARE

Middleware wraps the dispatch of a published event. Constructor middleware, bus.use() middleware and per-publish middleware are merged and run in descending priority order.

Type: EventMiddleware

type EventMiddleware<TEvent extends Event = Event, TResult = unknown> = ( context: EventMiddlewareContext<TEvent>, next: () => Promise<TResult>, ) => Promise<TResult>; // Object form: { handle(context, next) }

Interface: EventMiddlewareContext

interface EventMiddlewareContext<TEvent extends Event = Event> { readonly event: TEvent; readonly signal: AbortSignal; readonly metadata: Readonly<Record<string, unknown>>; readonly executionId: string; readonly startedAt: Date; readonly state: Map<string, unknown>; // shared scratch space for the pipeline }

Built-in Middleware

Builder Purpose
createEventMiddleware(mw, options?)Wraps a function/object as a registered middleware (validates it and its priority).
beforeEvent(cb) · afterEvent(cb) · aroundEvent(cb)Run before, after (with the result), or around the downstream dispatch.
validateEventMiddleware(validator)Throws EventMiddlewareError when the validator returns false.
timingEventMiddleware(callback)Reports the downstream duration in ms.
stateEventMiddleware(key, factory)Stores a value in context.state.
abortableEventMiddleware()Throws EventDispatchAbortedError when the signal is aborted.
enableEventMiddleware · disableEventMiddlewareToggle a registered middleware.
Error attribution: only errors thrown by a middleware itself are wrapped as EventMiddlewareError (with middlewareId). Handler failures (EventHandlerError) and aborts (EventDispatchAbortedError) pass through unwrapped. A middleware that returns without calling next() produces a result with shortCircuited: true and no handler runs. Calling next() twice throws.

Example: Middleware Pipeline

import { createStartedEventBus, timingEventMiddleware, validateEventMiddleware } from "@zudojs/events"; const bus = createStartedEventBus({ middleware: [ validateEventMiddleware((event) => event.payload !== null, { priority: 100 }), timingEventMiddleware((ms, ctx) => metrics.timing(ctx.event.type, ms)), ], }); // Ad-hoc logging middleware const remove = bus.use(async (ctx, next) => { console.log("→", ctx.event.type); const result = await next(); console.log("←", ctx.event.type); return result; }); // Deduplication: skip already-seen events bus.use(async (ctx, next) => (seen.has(ctx.event.id) ? undefined : next())); remove();

ERROR HIERARCHY

All errors extend EventError from @zudojs/errors and expose eventType, eventId and, where relevant, handlerId / middlewareId. They are re-exported from @zudojs/events.

Error Thrown when
InvalidEventErrorInvalid type, id or timestamp in createEvent / defineEvent; a non-event passed to publish / emit.
EventTypeNotFoundErrorPublishing an unregistered type with requireRegistration.
DuplicateEventDefinitionError · EventDefinitionNotFoundErrorRegistry definition conflicts / require() misses.
DuplicateEventHandlerError · EventHandlerNotFoundErrorHandler id conflicts / requireHandler() misses.
EventHandlerErrorA handler threw; cause holds the raw value. Collected in result.errors (CONTINUE) or thrown (THROW).
EventTimeoutErrorA handler exceeded its timeoutMs (appears as the handler's error).
EventMiddlewareErrorA middleware threw, called next() twice, or a validation middleware rejected the event.
EventDispatchAbortedErrorThe signal was aborted; carries partial results / errors.
EventBusStoppedError · EventBusDisposedErrorUsing a stopped / disposed bus.
EventEmitterDisposedError · EventRegistryDisposedErrorUsing a disposed emitter / registry.
EventSerializationError · EventDeserializationError · EventPublishErrorReserved for transports built on top of the bus.

Error Handling Pattern

import { EventHandlerError, EventMiddlewareError, EventDispatchAbortedError } from "@zudojs/events"; try { const result = await bus.publish(event, { errorMode: EventErrorMode.THROW }); } catch (error) { if (error instanceof EventHandlerError) { logger.error(`handler ${error.handlerId} failed`, error.cause); } else if (error instanceof EventMiddlewareError) { logger.error(`middleware ${error.middlewareId} failed`, error.cause); } else if (error instanceof EventDispatchAbortedError) { logger.warn("aborted after", error.results.length, "handlers"); } else { throw error; } } // Fire-and-forget publishes: route failures through onError instead const bus = createStartedEventBus({ onError: (error, { source, event }) => logger.error(source, event?.type, error), }); void bus.publish(event).catch((error) => logger.error("publish rejected", error));

TESTING

Buses are cheap and self-contained: create one per test, inspect the EventPublishResult, and dispose it afterwards. Pass onWarning to silence listener-leak warnings in tests that intentionally register many handlers.

import { describe, it, expect, vi } from "vitest"; import { createStartedEventBus, createEvent, EventBusStoppedError } from "@zudojs/events"; describe("user events", () => { it("dispatches to matching handlers", async () => { const bus = createStartedEventBus(); const handler = vi.fn(); bus.on("user.*", handler); const result = await bus.publish(createEvent({ type: "user.created", payload: { id: "1" } })); expect(result.handled).toBe(true); expect(handler).toHaveBeenCalledTimes(1); bus.dispose(); }); it("collects handler failures", async () => { const bus = createStartedEventBus(); bus.on("user.created", () => { throw new Error("boom"); }); const result = await bus.publishEvent({ type: "user.created", payload: {} }); expect(result.handled).toBe(false); expect(result.failed).toBe(1); }); it("rejects publishes while stopped", async () => { const bus = createStartedEventBus().stop(); await expect(bus.publishEvent({ type: "x", payload: null })).rejects.toBeInstanceOf(EventBusStoppedError); }); });

FULL INTEGRATION EXAMPLE

import { createStartedEventBus, defineEvent, timingEventMiddleware, EventEmitterMode, } from "@zudojs/events"; // 1. Definitions const UserCreated = defineEvent<"user.created", { id: string; email: string }>("user.created"); const UserDeleted = defineEvent<"user.deleted", { id: string }>("user.deleted"); // 2. Bus with middleware and error routing const bus = createStartedEventBus({ requireRegistration: true, emitter: { mode: EventEmitterMode.SEQUENTIAL }, middleware: [timingEventMiddleware((ms, ctx) => metrics.timing(`event.${ctx.event.type}`, ms))], onError: (error, { source, event }) => logger.error({ source, type: event?.type }, error), }); // 3. Register definitions bus.register(UserCreated); bus.register(UserDeleted); // 4. Handlers bus.on("user.created", async (event) => { await sendWelcomeEmail((event.payload as { email: string }).email); }, { id: "welcome-email", timeoutMs: 10_000 }); bus.on("user.*", async (event, ctx) => { await auditLog(event.type, event.payload, ctx.correlationId); }, { id: "audit", priority: -10 }); bus.onAny((event) => metrics.increment(`event.${event.type}`), { id: "metrics" }); // 5. Publish const result = await bus.publish( UserCreated.create({ id: "u-001", email: "alice@example.com" }, { correlationId: "req-abc-123" }), ); if (!result.handled) logger.warn("no handler succeeded", result.errors); // 6. Graceful shutdown process.on("SIGTERM", () => { bus.stop(); // new publishes are rejected bus.dispose(); // cancel subscriptions, release definitions process.exit(0); });
