@zudojs/events

Event bus, emitter, middleware pipeline, and registry for Zudojs. Provides typed pub/sub, namespace pattern matching, middleware interception, and a centralized event definition store.

EVENT BUS MIDDLEWARE PUB/SUB

INSTALLATION

// npm npm install @zudojs/events // pnpm pnpm add @zudojs/events // yarn yarn add @zudojs/events
Peer Dependencies: @zudojs/events depends on @zudojs/errors, @zudojs/constants, and @zudojs/types. All at version 0.1.0.

WHAT IT DOES

@zudojs/events is the event infrastructure for Zudojs. It provides:

  • → An EventBus that coordinates publish/subscribe with lifecycle management
  • → An EventEmitter for low-level event dispatching with pattern matching
  • → An EventRegistry that stores event definitions and handler mappings
  • → A middleware pipeline that intercepts events before/after/around handlers
  • → Pattern matching with exact names, namespace wildcards (user.*), and catch-all (*)
Core Principle: Events are first-class citizens. Define them once in the registry, publish them through the bus, and let middleware handle cross-cutting concerns like logging, validation, and timing.

WHERE IT SITS

APPLICATION LAYER (CQRS, Modules, Handlers)
EVENT BUS (@zudojs/events)
MESSAGING LAYER (@zudojs/messaging)
ADAPTER LAYER (@zudojs/adapters, External Platforms)

Events sit at the application boundary. Application code publishes events through the bus. The bus dispatches them to registered handlers, optionally routing them through middleware. For cross-service communication, events flow down to the messaging layer.

CORE API — EVENT

Interface: Event

The base shape for all events flowing through the bus:

interface Event<TName extends string = string, TPayload = unknown> { readonly name: TName; readonly payload: TPayload; readonly timestamp: number; readonly correlationId?: string; readonly metadata?: Record<string, unknown>; }

Interface: EventInput

The input shape when creating events (timestamp is auto-generated):

interface EventInput<TName extends string = string, TPayload = unknown> { readonly name: TName; readonly payload: TPayload; readonly correlationId?: string; readonly metadata?: Record<string, unknown>; }

Interface: EventDefinition

A registered event definition with schema and handler references:

interface EventDefinition<TName extends string = string, TPayload = unknown> { readonly name: TName; readonly description?: string; readonly version?: string; readonly schema?: unknown; readonly handlerCount: number; }

Creating Events

import { defineEvent, createEvent } from "@zudojs/events"; // Define a reusable event type const UserCreated = defineEvent<"user.created", { id: string; email: string }>("user.created"); // Create an instance const event = createEvent("user.created", { id: "abc-123", email: "alice@example.com", }); // event.name === "user.created" // event.timestamp === Date.now()

EVENT BUS

The EventBus is the central coordination point. It manages lifecycle, registration, publishing, middleware, and handler dispatch.

Interface: EventBusOptions

interface EventBusOptions { readonly name?: string; readonly errorHandler?: (error: unknown) => void; readonly maxListeners?: number; }

Enum: EventBusState

enum EventBusState { IDLE = "idle", STARTING = "starting", RUNNING = "running", STOPPING = "stopping", STOPPED = "stopped", ERROR = "error", }

Factory Functions

// Create a bus that starts in IDLE state const bus = createEventBus({ name: "app-events" }); // Create a bus that starts in RUNNING state const bus = createStartedEventBus({ name: "app-events" });

Example: Creating and Using a Bus

import { createStartedEventBus, defineEvent, } from "@zudojs/events"; const bus = createStartedEventBus({ name: "app" }); // Register an event definition bus.register({ name: "user.created", description: "Emitted when a new user signs up", version: "1.0.0", }); // Subscribe bus.on("user.created", async (event) => { console.log(`New user: ${event.payload.email}`); }); // Publish await bus.publish({ name: "user.created", payload: { id: "1", email: "alice@example.com" }, }); // Cleanup await bus.dispose();

EVENT EMITTER

The EventEmitter handles low-level event dispatching with pattern matching support. The EventBus wraps an internal emitter.

Enum: EventEmitterMode

enum EventEmitterMode { SYNCHRONOUS = "synchronous", ASYNCHRONOUS = "asynchronous", }

Enum: EventErrorMode

enum EventErrorMode { THROW = "throw", CATCH = "catch", PROPAGATE = "propagate", }

Methods

Method Signature Returns
on() on(pattern: string, handler: EventHandler): EventSubscription Subscribes to events matching the pattern.
once() once(pattern: string, handler: EventHandler): EventSubscription Subscribes for one invocation, then auto-removes.
onAny() onAny(handler: (event: Event) => void): EventSubscription Subscribes to all events regardless of name.
off() off(subscription: EventSubscription): void Removes a subscription.
emit() emit(name: string, payload: unknown): void Synchronous dispatch. Calls matching handlers.
emitEvent() emitEvent(event: Event): Promise<void> Async dispatch of a full Event object.
removeAllListeners() removeAllListeners(pattern?: string): void Removes all listeners for a pattern, or all listeners.
createSubscriptionGroup() createSubscriptionGroup(): EventSubscriptionGroup Creates a group for batch unsubscribe.
dispose() dispose(): void Clears all listeners.

EVENT REGISTRY

The EventRegistry is a centralized store for event definitions and handler mappings. It enables event discovery, validation, and subscription management.

Enum: EventRegistryChangeType

enum EventRegistryChangeType { REGISTERED = "registered", UNREGISTERED = "unregistered", HANDLER_ADDED = "handler_added", HANDLER_REMOVED = "handler_removed", }

Methods

Method Signature Returns
register() register(definition: EventDefinition): void Stores an event definition. Throws on duplicate.
registerHandler() registerHandler(name: string, handler: EventHandler): void Associates a handler with an event name.
get() get(name: string): EventDefinition | undefined Retrieves a definition by name.
require() require(name: string): EventDefinition Retrieves or throws EventNotRegisteredError.
has() has(name: string): boolean True if event is registered.
unregister() unregister(name: string): void Removes event definition and its handlers.
getHandler() getHandler(name: string): EventHandler | undefined Returns the first registered handler for an event.
getDefinitions() getDefinitions(): readonly EventDefinition[] All registered definitions.
getHandlers() getHandlers(): ReadonlyMap<string, EventHandler[]> All handlers keyed by event name.
getHandlersForEvent() getHandlersForEvent(name: string): EventHandler[] All handlers for a specific event name.
subscribe() subscribe(name: string, handler: EventHandler): EventSubscription Registers handler and returns subscription.
clear() clear(): void Removes all definitions and handlers.
dispose() dispose(): void Clears all data and subscriptions.

HANDLERS

Type: EventHandler

type EventHandler = ( event: Event, context: EventHandlerContext, ) => Promise<void> | void;

Interface: EventHandlerContext

interface EventHandlerContext { readonly eventName: string; readonly handlerName?: string; readonly timestamp: number; readonly correlationId?: string; readonly abortSignal?: AbortSignal; }

Interface: EventHandlerOptions

interface EventHandlerOptions { readonly priority?: number; readonly once?: boolean; readonly errorHandler?: (error: unknown) => void; }

Pattern Matching

Handlers are matched against event names using three patterns:

Pattern Example Matches
Exact "user.created" Only "user.created"
Namespace wildcard "user.*" All events under user. namespace: user.created, user.updated, user.deleted
Catch-all "*" Every event regardless of name

Example: Registering Handlers

// Exact match bus.on("user.created", async (event, ctx) => { console.log("User created:", event.payload); }); // Namespace wildcard bus.on("user.*", async (event, ctx) => { console.log(`User event: ${event.name}`); }); // Catch-all bus.on("*", async (event, ctx) => { // Log every event logger.info("event published", { name: event.name, correlationId: ctx.correlationId, }); });

SUBSCRIPTIONS

Interface: EventSubscription

interface EventSubscription { readonly id: string; readonly eventName: string; readonly pattern: string; unsubscribe(): void; }

Class: EventSubscriptionGroup

class EventSubscriptionGroup { add(subscription: EventSubscription): void; unsubscribeAll(): void; readonly size: number; }

Example: Cleanup Pattern

// Individual unsubscribe const sub = bus.on("user.created", handler); // Later... sub.unsubscribe(); // Batch unsubscribe with group const group = bus.createSubscriptionGroup(); group.add(bus.on("user.created", handler1)); group.add(bus.on("user.updated", handler2)); // Cleanup all at once group.unsubscribeAll();

MIDDLEWARE

Middleware intercepts events at three points: before dispatch, after dispatch, and around the entire pipeline. This is where you add logging, validation, metrics, and error handling.

Type: EventMiddleware

type EventMiddleware = ( context: EventMiddlewareContext, next: () => Promise<void>, ) => Promise<void>;

Interface: EventMiddlewareContext

interface EventMiddlewareContext { readonly event: Event; readonly eventName: string; readonly timestamp: number; readonly handlerCount: number; }

Built-in Middleware

Middleware Purpose
beforeEvent() Runs logic before event dispatch
afterEvent() Runs logic after event dispatch completes
aroundEvent() Wraps the entire dispatch (before + after)
validateEventMiddleware() Validates event payload against registered schema
timingEventMiddleware() Measures handler execution time and logs it

Example: Middleware Pipeline

import { timingEventMiddleware, validateEventMiddleware, } from "@zudojs/events"; // Timing middleware bus.use(timingEventMiddleware()); // Validation middleware bus.use(validateEventMiddleware()); // Custom middleware bus.use(async (ctx, next) => { console.log(`→ ${ctx.event.name} (${ctx.handlerCount} handlers)`); const start = Date.now(); await next(); console.log(`← ${ctx.event.name} in ${Date.now() - start}ms`); });

ERROR HIERARCHY

All error types are defined in @zudojs/errors and re-exported by this package.

Error When Thrown
EventErrorBase error for all event-related issues
EventNotRegisteredErrorPublishing an event not in the registry
EventHandlerErrorA handler threw during dispatch
EventBusNotRunningErrorPublishing on a bus not in RUNNING state
EventBusAlreadyRunningErrorStarting a bus already in RUNNING state
EventMiddlewareErrorA middleware threw during pipeline execution
EventValidationErrorEvent payload failed schema validation
EventTimeoutErrorEvent handler exceeded timeout
EventDuplicateErrorDuplicate event registration
EventDisposeErrorError during bus disposal

Error Handling Pattern

import { isEventError, EventHandlerError, } from "@zudojs/events"; try { await bus.publish(event); } catch (error) { if (isEventError(error)) { console.error(`Event ${error.eventName}: ${error.message}`); if (error instanceof EventHandlerError) { // Handler-specific error handling } } }

TESTING

Import from @zudojs/events for test utilities. The bus is fully synchronous-friendly for testing.

Full Test Example

import { describe, it, expect } from "vitest"; import { createEventBus, createStartedEventBus, defineEvent, createEvent, } from "@zudojs/events"; describe("EventBus", () => { it("delivers events to subscribers", async () => { const bus = createStartedEventBus(); const received: unknown[] = []; bus.register({ name: "test.event" }); bus.on("test.event", async (event) => { received.push(event.payload); }); await bus.publish({ name: "test.event", payload: { value: 42 }, }); expect(received).toHaveLength(1); expect(received[0]).toEqual({ value: 42 }); await bus.dispose(); }); it("supports namespace wildcards", async () => { const bus = createStartedEventBus(); const events: string[] = []; bus.on("user.*", async (event) => { events.push(event.name); }); await bus.publish({ name: "user.created", payload: {} }); await bus.publish({ name: "user.updated", payload: {} }); await bus.publish({ name: "order.created", payload: {} }); expect(events).toEqual(["user.created", "user.updated"]); await bus.dispose(); }); it("executes middleware pipeline", async () => { const bus = createStartedEventBus(); const log: string[] = []; bus.use(async (ctx, next) => { log.push("before"); await next(); log.push("after"); }); bus.register({ name: "test.event" }); bus.on("test.event", async () => { log.push("handler"); }); await bus.publish({ name: "test.event", payload: {} }); expect(log).toEqual(["before", "handler", "after"]); await bus.dispose(); }); it("unsubscribes correctly", async () => { const bus = createStartedEventBus(); let count = 0; const sub = bus.on("counter", async () => { count++; }); await bus.publish({ name: "counter", payload: {} }); expect(count).toBe(1); sub.unsubscribe(); await bus.publish({ name: "counter", payload: {} }); expect(count).toBe(1); await bus.dispose(); }); });

FULL INTEGRATION EXAMPLE

Complete example: define events, register on bus, add middleware, publish, and handle.

import { createStartedEventBus, defineEvent, createEvent, timingEventMiddleware, } from "@zudojs/events"; // 1. Define event types const UserCreated = defineEvent<"user.created", { id: string; email: string; }>("user.created"); const UserDeleted = defineEvent<"user.deleted", { id: string; }>("user.deleted"); // 2. Create bus with middleware const bus = createStartedEventBus({ name: "app" }); bus.use(timingEventMiddleware()); // 3. Register event definitions bus.register({ name: "user.created", version: "1.0.0" }); bus.register({ name: "user.deleted", version: "1.0.0" }); // 4. Subscribe to specific events bus.on("user.created", async (event, ctx) => { await sendWelcomeEmail(event.payload.email); }); // 5. Subscribe to namespace bus.on("user.*", async (event) => { await auditLog(event.name, event.payload); }); // 6. Global catch-all for metrics bus.onAny(async (event) => { metrics.increment(`event.${event.name}`); }); // 7. Publish events await bus.publish({ name: "user.created", payload: { id: "u-001", email: "alice@example.com" }, correlationId: "req-abc-123", }); // 8. Graceful shutdown process.on("SIGTERM", async () => { await bus.dispose(); process.exit(0); });
