@zudojs/messaging

In-process message bus infrastructure with handlers, middleware, and publish/subscribe patterns. The foundational layer that CQRS and Events build upon.

MESSAGING PUB/SUB MIDDLEWARE DISPATCH

INSTALLATION

// npm npm install @zudojs/messaging // pnpm pnpm add @zudojs/messaging // yarn yarn add @zudojs/messaging
Peer Dependencies: @zudojs/messaging depends on @zudojs/errors and @zudojs/constants. All at version 0.1.0.

WHAT IT DOES

@zudojs/messaging is the core messaging infrastructure for Zudojs. It provides:

  • → An in-process message bus for dispatching messages between components
  • → A publish/subscribe pattern where handlers subscribe to message types
  • → Typed message payloads with Message<TPayload> generic contracts
  • → A handler registry for managing handler registration and resolution
  • → A middleware pipeline that intercepts dispatch with cross-cutting concerns
  • → Dispatcher coordination that validates, contextualizes, and routes messages
  • → Context propagation carrying correlationId, causationId, signal, and state
  • → Timeout handling and abort support via AbortSignal integration
Core Principle: Messages are the fundamental unit of communication. @zudojs/messaging provides the primitives that @zudojs/cqrs (commands/queries) and @zudojs/events (domain events) specialize into higher-level patterns.

WHERE IT SITS

APPLICATION LAYER (CQRS, Modules, Handlers)
MESSAGING LAYER (@zudojs/messaging)
EVENT BUS (@zudojs/events)
ADAPTER LAYER (@zudojs/adapters, External Platforms)

Messaging sits below the application layer. Commands and queries flow through the messaging bus. The event bus wraps messaging for domain event patterns. Adapters sit below for external platform integration.

CORE MESSAGE

Interface: Message

The base shape for all messages flowing through the bus:

interface Message<TPayload = unknown> { readonly id: MessageId; readonly type: MessageType; readonly payload: TPayload; readonly timestamp: MessageTimestamp; readonly source?: MessageSource; readonly correlationId?: MessageCorrelationId; readonly causationId?: MessageCausationId; readonly metadata?: Readonly<Record<string, unknown>>; }

Interface: MessageInput

The input shape when creating messages (id and timestamp are auto-generated):

interface MessageInput<TPayload = unknown> { readonly id?: MessageId; readonly type: MessageType; readonly payload: TPayload; readonly timestamp?: MessageTimestamp | number; readonly source?: MessageSource; readonly correlationId?: MessageCorrelationId; readonly causationId?: MessageCausationId; readonly metadata?: Readonly<Record<string, unknown>>; }

Type Alias: MessageId

type MessageId = Brand<string, "MessageId">;

Factory Functions

// Create an immutable message from input const msg = createMessage({ type: "order.created", payload: { orderId: "ord-001", total: 99.99 }, }); // Create a derived message preserving correlation const derived = createDerivedMessage(originalMsg, { type: "order.confirmed", payload: { orderId: "ord-001" }, }); // Type guard isMessage(value); // boolean // Accessors getMessageType(msg); // "order.created" getMessagePayload(msg); // { orderId: "ord-001", total: 99.99 } describeMessage(msg); // "order.created (msg:uuid)"

ERROR HIERARCHY

All error types are defined in @zudojs/errors and re-exported by this package.

Error When Thrown
MessageErrorBase error for all messaging-related issues
MessageDispatchErrorGeneral dispatch failure (e.g. bus disposed)
InvalidMessageErrorMessage failed validation (missing type, empty payload)
MessageTypeNotFoundErrorNo handlers registered for the message type
MessageHandlerErrorA handler threw during dispatch
MessageHandlerNotFoundErrorHandler ID not found in registry
DuplicateMessageHandlerErrorHandler with same ID already registered
MessageDispatchAbortedErrorDispatch was aborted via AbortSignal
MessageBusDisposedErrorAttempting to use a disposed bus
MessageTimeoutErrorDispatch exceeded timeout limit
MessageMiddlewareErrorA middleware threw during pipeline execution
MessageValidationErrorMessage failed schema validation

Error Handling Pattern

import { isMessageError, MessageHandlerError, MessageTimeoutError, } from "@zudojs/messaging"; try { const result = await bus.dispatch(message, { timeout: 5000 }); if (!result.success) { console.error("Dispatch failed:", result.error); } } catch (error) { if (isMessageError(error)) { console.error(`Messaging error [${error.code}]: ${error.message}`); if (error instanceof MessageTimeoutError) { // Handle timeout specifically } } }

FULL INTEGRATION EXAMPLE

Complete working example: create a bus, register handlers, add middleware, and dispatch messages.

import { createMessageBus, createMessage, createMessageContext, describeMessage, isMessage, } from "@zudojs/messaging"; // 1. Create the message bus const bus = createMessageBus({ allowMultipleHandlers: true, defaultTimeout: 10000, }); // 2. Add logging middleware bus.use(async (ctx, next) => { const start = performance.now(); console.log(`[MW] → ${ctx.message.type}`, { correlationId: ctx.context.correlationId, }); const result = await next(); const duration = performance.now() - start; console.log(`[MW] ← ${ctx.message.type} (${duration.toFixed(2)}ms)`); return result; }); // 3. Add validation middleware bus.use(async (ctx, next) => { if (!ctx.message.payload || typeof ctx.message.payload !== "object") { throw new Error("Invalid payload"); } return next(); }); // 4. Register handler for "order.created" bus.on("order.created", async (message, ctx) => { console.log(`Processing order: ${message.payload.orderId}`); console.log(` correlation: ${ctx.correlationId}`); return { status: "processed", orderId: message.payload.orderId }; }); // 5. Register handler for "order.confirmed" bus.on("order.confirmed", async (message) => { console.log(`Order confirmed: ${message.payload.orderId}`); }); // 6. Dispatch using send() — creates message automatically const result = await bus.send( { type: "order.created", payload: { orderId: "ord-001", total: 99.99 }, correlationId: "req-abc-123", }, { timeout: 5000 }, ); console.log("Dispatch result:", result.success, result.value); // 7. Dispatch using dispatch() — with a pre-created message const msg = createMessage({ type: "order.confirmed", payload: { orderId: "ord-001" }, }); await bus.dispatch(msg); // 8. Check handler status console.log("Handlers registered:", bus.handlerCount); console.log("Has order.created handlers:", bus.hasHandlers("order.created")); // 9. Cleanup bus.dispose();
