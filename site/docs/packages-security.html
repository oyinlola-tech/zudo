@zudojs/security

Security primitives for input validation, header security, CORS, CSRF protection, rate limiting, and security headers with secure defaults.

SECURITY INPUT VALIDATION CORS CSRF RATE LIMITING HEADERS SANITIZATION

INSTALLATION

// npm npm install @zudojs/security // pnpm pnpm add @zudojs/security // yarn yarn add @zudojs/security
Peer Dependencies: @zudojs/security depends on @zudojs/errors and @zudojs/constants. All at version 0.1.0.

WHAT IT DOES

@zudojs/security provides comprehensive security primitives for the Zudojs framework:

  • → Input sanitization against SQL injection and XSS attacks
  • → CORS origin, method, and header validation
  • → CSRF token generation and validation with HMAC signatures
  • → Rate limiting with sliding window algorithm
  • → Security response headers generation with secure defaults
  • → Body size validation with content-type-aware presets
  • → Cookie parsing and secure serialization with HttpOnly, Secure, SameSite
  • → URL validation and path normalization with traversal blocking
  • → Request target validation against null bytes and control characters
  • → HTML escaping and stripping for output safety
  • → Threat detection for SQL injection, XSS, null bytes, and control characters
  • → Prototype pollution prevention for object sanitization
Core Principle: All security functions are pure, stateless, and can be used independently or composed into middleware pipelines.

INPUT SANITIZATION

Functions for detecting and preventing common attack patterns in user input.

containsSqlInjection

function containsSqlInjection(input: string): boolean

Checks if a string contains SQL injection patterns (SELECT, DROP, UNION, comment sequences, etc.).

containsXss

function containsXss(input: string): boolean

Checks if a string contains XSS patterns (script tags, event handlers, javascript: URIs, etc.).

containsPrototypePollution

function containsPrototypePollution(input: string): boolean

Checks if a string matches prototype pollution keys (__proto__, constructor, prototype).

sanitizeString

function sanitizeString( input: string, config?: InputSanitizationConfig, ): string

Sanitizes a string by removing null bytes, control characters, truncating to max length, and applying custom sanitizer.

sanitizeObject

function sanitizeObject<T extends Record<string, unknown>>( obj: T, config?: InputSanitizationConfig, ): T

Recursively sanitizes an object: removes prototype pollution keys, sanitizes string values, and handles nested objects and arrays.

isSafeString

function isSafeString(input: string, allowedPattern?: RegExp): boolean

Validates that a string contains only safe characters (no null bytes, control characters, or pattern violations).

detectThreats

function detectThreats(input: string): string[]

Returns an array of detected threat types: "SQL_INJECTION", "XSS", "NULL_BYTE", "CONTROL_CHARACTERS".

escapeHtml

function escapeHtml(input: string): string

HTML-escapes &, <, >, ", and ' to prevent XSS in output.

stripHtml

function stripHtml(input: string): string

Strips all HTML tags from a string, returning only the text content.

CORS

Cross-Origin Resource Sharing validation and header generation. Exported as both individual functions and a cors namespace.

isOriginAllowed

function isOriginAllowed( origin: string | undefined, config: CorsConfig, ): string | undefined

Checks if a request origin is allowed by the CORS config. Returns the allowed origin string, or undefined if not allowed.

generatePreflightHeaders

function generatePreflightHeaders( requestOrigin: string | undefined, config: CorsConfig, ): CorsHeaders

Generates CORS headers for OPTIONS preflight requests, including Allow-Methods, Allow-Headers, Max-Age, and credentials.

generateSimpleHeaders

function generateSimpleHeaders( requestOrigin: string | undefined, config: CorsConfig, ): CorsHeaders

Generates CORS headers for simple (non-preflight) requests with Allow-Origin, credentials, and Expose-Headers.

isMethodAllowed

function isMethodAllowed(method: string, config: CorsConfig): boolean

Validates that an HTTP method is in the CORS allowed methods list.

getDisallowedHeaders

function getDisallowedHeaders( headers: string[], config: CorsConfig, ): string[]

Returns an array of headers not in the CORS allowed headers list.

CSRF

Cross-Site Request Forgery token generation and validation using HMAC-SHA256 signatures.

generateCsrfToken

function generateCsrfToken( secret: string, expiration?: number, ): string

Generates a cryptographically secure CSRF token with expiry timestamp, random bytes, and HMAC-SHA256 signature. Default expiry: 3600s.

validateCsrfToken

function validateCsrfToken( token: string, secret: string, expiration?: number, ): boolean

Validates a CSRF token: checks format, expiration, and HMAC signature using constant-time comparison.

requiresCsrfProtection

function requiresCsrfProtection( method: string, config?: CsrfConfig, ): boolean

Returns true if the HTTP method requires CSRF protection (POST, PUT, PATCH, DELETE by default; GET, HEAD, OPTIONS, TRACE are safe).

extractCsrfTokenFromHeaders

function extractCsrfTokenFromHeaders( headers: Record<string, string | string[] | undefined>, headerName?: string, ): string | undefined

Extracts CSRF token from request headers. Default header: "x-csrf-token".

extractCsrfTokenFromCookies

function extractCsrfTokenFromCookies( cookieHeader: string, cookieName?: string, ): string | undefined

Extracts CSRF token from the raw Cookie header. Default cookie name: "_csrf".

generateCsrfCookie

function generateCsrfCookie( token: string, config?: CsrfConfig, ): string

Generates a Set-Cookie header value with HttpOnly, SameSite=Strict, and Max-Age attributes.

RATE LIMITING

Sliding window rate limiting with in-memory storage. Exported as both individual functions and a rateLimit namespace.

createRateLimiter

function createRateLimiter(config: RateLimitConfig): { check(request: RateLimitRequest): RateLimitResult; middleware(request: RateLimitRequest, response?: RateLimitResponse): RateLimitResult; reset(key: string): void; clear(): void; getCount(key: string): number; destroy(): void; }

Creates an in-memory rate limiter with sliding window. Returns an object with check, middleware, reset, clear, getCount, and destroy methods.

defaultKeyGenerator

function defaultKeyGenerator(request: RateLimitRequest): string

Default key generator using the client IP address (falls back to "unknown").

defaultHandler

function defaultHandler( _request: RateLimitRequest, response: { statusCode: number; headers: Record<string, string>; body?: string }, ): void

Default handler when rate limit is exceeded. Sets status 429, Retry-After header, and JSON error body.

extractClientIp

function extractClientIp( headers: Record<string, string | string[] | undefined>, ): string

Extracts client IP from X-Forwarded-For (first entry) or X-Real-IP headers. Falls back to "unknown".

createRateLimiter Return Methods

Method Returns Description
check(request) RateLimitResult Checks if request is allowed and updates the counter
middleware(request, response?) RateLimitResult Checks and optionally invokes handler when blocked
reset(key) void Resets the rate limit for a specific key
clear() void Clears all rate limit data
getCount(key) number Gets the current request count for a key
destroy() void Destroys the rate limiter and cleans up resources

ERROR HIERARCHY

Security operations use error types from @zudojs/errors. There is no dedicated SecurityError class.

Error Type Used When
ValidationError Header, URL, body, cookie, or CSP validation fails
ConfigurationError Invalid security configuration (e.g., body limit config)
RateLimitError Rate limit exceeded (can be used with custom handlers)
Design Note: Security functions are designed to be pure and return results rather than throwing. Use the returned error messages or result objects to handle failures in your middleware pipeline.

FULL INTEGRATION EXAMPLE

Complete example combining input sanitization, CORS, CSRF, rate limiting, security headers, cookie security, and URL validation.

import { // Input sanitization containsSqlInjection, containsXss, sanitizeString, sanitizeObject, detectThreats, escapeHtml, // CORS isOriginAllowed, generatePreflightHeaders, generateSimpleHeaders, isMethodAllowed, // CSRF generateCsrfToken, validateCsrfToken, requiresCsrfProtection, extractCsrfTokenFromHeaders, generateCsrfCookie, // Rate limiting createRateLimiter, extractClientIp, // Security headers generateSecurityHeaders, // Cookie security createSecureCookie, // URL validation validateUrl, normalizePath, } from "@zudojs/security"; import type { CorsConfig, CsrfConfig } from "@zudojs/security"; // ─── Configuration ───────────────────────────────────────────── const corsConfig: CorsConfig = { origin: ["https://app.example.com", "https://admin.example.com"], methods: ["GET", "POST", "PUT", "DELETE"], allowedHeaders: ["Content-Type", "Authorization", "X-CSRF-Token"], credentials: true, maxAge: 86400, }; const csrfConfig: CsrfConfig = { secret: process.env.CSRF_SECRET!, expiration: 3600, cookieName: "_csrf", headerName: "x-csrf-token", }; // ─── Rate Limiter ───────────────────────────────────────────── const limiter = createRateLimiter({ max: 100, windowMs: 60_000, keyGenerator: (req) => extractClientIp(req.headers ?? {}), handler: (req, res) => { res.statusCode = 429; res.headers["Retry-After"] = "60"; res.body = JSON.stringify({ error: { code: "RATE_LIMIT_EXCEEDED", message: "Too many requests" }, }); }, }); // ─── Security Middleware ─────────────────────────────────────── async function securityMiddleware(request: Request): Promise<Response> { // 1. URL validation const urlResult = validateUrl(request.url); if (!urlResult.valid) { return new Response("Bad Request", { status: 400 }); } // 2. Rate limiting const rateResult = limiter.check({ ip: request.headers.get("x-forwarded-for") ?? "unknown", method: request.method, path: new URL(request.url).pathname, }); if (!rateResult.allowed) { return new Response("Too Many Requests", { status: 429, headers: { "Retry-After": "60" }, }); } // 3. CORS headers const origin = request.headers.get("origin") ?? undefined; const isPreflight = request.method === "OPTIONS"; const corsHeaders = isPreflight ? generatePreflightHeaders(origin, corsConfig) : generateSimpleHeaders(origin, corsConfig); if (isPreflight) { return new Response(null, { status: 204, headers: corsHeaders }); } // 4. CSRF protection for state-changing requests if (requiresCsrfProtection(request.method, csrfConfig)) { const token = extractCsrfTokenFromHeaders( Object.fromEntries(request.headers), ); if (!token || !validateCsrfToken(token, csrfConfig.secret)) { return new Response("CSRF Token Invalid", { status: 403 }); } } // 5. Input sanitization const body = await request.json(); const sanitized = sanitizeObject(body); // 6. Threat detection const name = sanitized.name as string; const threats = detectThreats(name); if (threats.length > 0) { return new Response("Suspicious Input", { status: 400 }); } // 7. Security headers const securityHeaders = generateSecurityHeaders({ contentSecurityPolicy: "default-src 'self'", hsts: "max-age=31536000; includeSubDomains", }); // 8. Secure cookie const sessionCookie = createSecureCookie("session", "abc123", { path: "/", maxAge: 3600, sameSite: "lax", }); // 9. Response return new Response(JSON.stringify({ success: true }), { status: 200, headers: { ...corsHeaders, ...securityHeaders, "Set-Cookie": sessionCookie, }, }); }
