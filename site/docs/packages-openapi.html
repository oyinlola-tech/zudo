@zudojs/openapi

OpenAPI specification generation, validation, and serialization engine for the Zudojs framework. Converts route metadata and schemas into fully compliant OpenAPI 3.1 documents with JSON and YAML output.

OPENAPI SPECIFICATION VALIDATION SDK SCHEMA

INSTALLATION

// npm npm install @zudojs/openapi // pnpm pnpm add @zudojs/openapi // yarn yarn add @zudojs/openapi
Dependencies: @zudojs/openapi depends only on @zudojs/errors at version 0.1.0. Schemas from @zudojs/schema are converted structurally, so it is not a build-time dependency.

WHAT IT DOES

@zudojs/openapi generates, validates, and serializes OpenAPI 3.1 specifications from your Zudojs application. It provides:

  • → OpenAPI 3.1 specification generation from route metadata and schemas
  • → Route scanning that converts Zudojs route patterns to OpenAPI path templates
  • → Schema conversion from Zudo schema definitions to OpenAPI schema objects
  • → Document validation — required fields, response keys, path template/parameter agreement, operationId uniqueness and length, security scheme references, and $ref resolution
  • → JSON and YAML serialization for serving documentation
  • → $ref component references for reusable schemas, responses, and parameters
  • → Document builder pattern for programmatic document construction
  • → Built-in error hierarchy — 10 error classes for OpenAPI-specific failures
  • → High-level manager class that coordinates generation, validation, and serialization
Core Principle: Define your API in code using Zudojs routes and schemas. This package automatically produces a standards-compliant OpenAPI spec — no manual YAML editing required.

WHERE IT SITS

APPLICATION LAYER (Routes, Schemas, Metadata)
@zudojs/openapi
Router | Schema | Errors | Constants
EXTERNAL (Swagger UI, Postman, Code Generators)

The OpenAPI package sits between your application's route definitions and external documentation tools. It consumes route metadata and Zudo schemas, then produces a standard OpenAPI document.

DEPENDENCIES

Package Version Purpose
@zudojs/errors 0.1.0 Base error class and OpenAPI error hierarchy
@zudojs/schema 0.1.0 (not a dependency) Schemas are converted structurally — no import, so any compatible schema object works
Version Lock: All internal dependencies use workspace:* in development. When published, they use exact version 0.1.0. Always use matching versions across the ecosystem.

Method Signature Returns

registerSchema() registerSchema(name: string, schema: OpenAPISchema): void Registers a named schema component.
registerResponse() registerResponse(name: string, response: unknown): void Registers a reusable response component.
registerParameter() registerParameter(name: string, parameter: OpenAPIParameter): void Registers a reusable parameter component.
registerRequestBody() registerRequestBody(name: string, body: OpenAPIRequestBody): void Registers a reusable request body component.
registerHeader() registerHeader(name: string, header: unknown): void Registers a reusable header component.
registerExample() registerExample(name: string, example: unknown): void Registers a reusable example component.
registerSecurityScheme() registerSecurityScheme(name: string, scheme: OpenAPISecurityScheme): void Registers a reusable security scheme.
registerTag() registerTag(tag: OpenAPITag): void Registers a tag for grouping operations.

Optional Path Params: Optional path parameters (:id?) are not supported in OpenAPI. Use separate routes or a query parameter instead.

DOCUMENT BUILDER

The OpenAPIDocumentBuilder provides a fluent API for constructing OpenAPI documents programmatically.

OpenAPIDocumentOptions

interface OpenAPIDocumentOptions { readonly info: { readonly title: string; readonly version: string; readonly description?: string; readonly summary?: string; readonly termsOfService?: string; readonly contact?: { readonly name?: string; readonly url?: string; readonly email?: string }; readonly license?: { readonly name: string; readonly url?: string }; }; readonly openapi?: string; readonly servers?: readonly { readonly url: string; readonly description?: string }[]; readonly tags?: readonly { readonly name: string; readonly description?: string }[]; readonly security?: readonly Record<string, readonly string[]>[]; }

OpenAPIDocumentBuilder Methods

class OpenAPIDocumentBuilder { constructor(options: OpenAPIDocumentOptions); version(version: string): this; addServer(server: { readonly url: string; readonly description?: string }): this; addTag(tag: { readonly name: string; readonly description?: string }): this; addSecurity(security: Record<string, readonly string[]>): this; addPath(path: string, pathItem: Record<string, unknown>): this; addSchema(name: string, schema: unknown): this; addResponse(name: string, response: unknown): this; addParameter(name: string, parameter: unknown): this; addSecurityScheme(name: string, scheme: unknown): this; build(): Readonly<OpenAPIDocument>; }

Example: Builder Pattern

import { OpenAPIDocumentBuilder } from "@zudojs/openapi"; const doc = new OpenAPIDocumentBuilder({ info: { title: "My API", version: "1.0.0", description: "A sample API", }, }) .addServer({ url: "https://api.example.com" }) .addTag({ name: "users", description: "User operations" }) .addSchema("User", { type: "object", properties: { id: { type: "string" } } }) .build();

Validation Checks

Check Severity Description
openapi version required error Document must have an openapi version string
info object required error Document must have an info object
info.title required error Info must have a title
info.version required error Info must have a version
empty paths warning warning Document has no paths defined
unconverted path params error Paths must use {param} not :param
path param must be required error Path parameters must have required: true
duplicate operationId error operationId values must be unique across all operations

SERIALIZATION

Serialize OpenAPI documents to JSON or YAML for serving documentation.

import { toOpenAPIJSON, toOpenAPIYAML } from "@zudojs/openapi"; const document = registry.generate(); // Serialize to JSON const json = toOpenAPIJSON(document); // Serialize to YAML const yaml = toOpenAPIYAML(document);
YAML Support: The YAML serializer currently falls back to formatted JSON. For true YAML output, integrate a YAML library alongside this package.

import { isOpenAPIError, OpenAPIValidationError, } from "@zudojs/openapi"; try { validator.assertValid(document); } catch (error) { if (isOpenAPIError(error)) { if (error instanceof OpenAPIValidationError) { console.error("Validation failed:", error.message); } } }

FULL INTEGRATION EXAMPLE

Complete working example: create a registry, register schemas and routes, build and validate the document, serialize to JSON, and serve it.

import { OpenAPIRegistryImpl, OpenAPIValidatorImpl, toOpenAPIJSON, toOpenAPIPath, } from "@zudojs/openapi"; // 1. Create registry const registry = new OpenAPIRegistryImpl("3.1.0"); // 2. Register schemas registry.registerSchema("User", { type: "object", properties: { id: { type: "string", format: "uuid" }, name: { type: "string" }, email: { type: "string", format: "email" }, }, required: ["id", "name", "email"], }); registry.registerSchema("CreateUserRequest", { type: "object", properties: { name: { type: "string" }, email: { type: "string", format: "email" }, }, required: ["name", "email"], }); // 3. Register security scheme registry.registerSecurityScheme("bearerAuth", { type: "http", scheme: "bearer", bearerFormat: "JWT", }); // 4. Register routes registry.registerRoute({ method: "get", path: "/users", operation: { operationId: "listUsers", summary: "List all users", tags: ["users"], responses: { "200": { description: "A list of users", content: { "application/json": { schema: { type: "array", items: registry.ref("schemas", "User"), }, }, }, }, }, }, }); registry.registerRoute({ method: "post", path: "/users", operation: { operationId: "createUser", summary: "Create a new user", tags: ["users"], security: [{ bearerAuth: [] }], requestBody: { content: { "application/json": { schema: registry.ref("schemas", "CreateUserRequest"), }, }, }, responses: { "201": { description: "User created", content: { "application/json": { schema: registry.ref("schemas", "User"), }, }, }, }, }, }); registry.registerRoute({ method: "get", path: "/users/:id", operation: { operationId: "getUser", summary: "Get a user by ID", tags: ["users"], parameters: [ { name: "id", in: "path", required: true, schema: { type: "string" } }, ], responses: { "200": { description: "User found", content: { "application/json": { schema: registry.ref("schemas", "User"), }, }, }, }, }, }); // 5. Generate document const document = registry.generate(); // 6. Validate const validator = new OpenAPIValidatorImpl(); const result = validator.validate(document); console.log("Valid:", result.valid); console.log("Errors:", result.errors.length); console.log("Warnings:", result.warnings.length); // 7. Serialize to JSON const json = toOpenAPIJSON(document); console.log(json); // 8. Serve at /api-docs (example with @zudojs/http) // app.get("/api-docs", (req, res) => { // res.json(JSON.parse(json)); // });
