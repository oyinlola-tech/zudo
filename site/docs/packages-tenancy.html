@zudojs/tenancy

Multi-tenant context and isolation for the Zudojs framework. Provides tenant resolution, AsyncLocalStorage propagation, resolver chains, trust levels, guard middleware, and isolation strategies.

TENANCY MULTI-TENANT RESOLUTION ISOLATION SAAS

INSTALLATION

// npm npm install @zudojs/tenancy // pnpm pnpm add @zudojs/tenancy // yarn yarn add @zudojs/tenancy
Peer Dependencies: @zudojs/tenancy depends on @zudojs/errors and @zudojs/constants (required). @zudojs/http is an optional peer dependency — only needed for HTTP middleware.

WHAT IT DOES

@zudojs/tenancy provides the full multi-tenant infrastructure for SaaS applications:

  • → Branded TenantId type for type-safe tenant identification
  • → Tenant resolution from headers, subdomains, paths, JWT claims, and API keys
  • → AsyncLocalStorage-based context propagation — tenant context flows through async call chains automatically
  • → Resolver chain with priority ordering and conflict detection
  • → Tenant status lifecycle — provisioning, active, inactive, suspended, deleting, deleted
  • → Isolation strategies — shared, schema, database, hybrid
  • → Trust levels — trusted, verified, untrusted — with guard enforcement
  • → HTTP middleware for automatic tenant resolution and propagation
  • → In-memory repository and cache implementations
  • → Domain registry for domain-to-tenant mapping
  • → Tenant manager with cache-aside pattern
  • → 10 error types covering every failure mode

WHERE IT SITS

HTTP / API LAYER (@zudojs/http, @zudojs/security)
APPLICATION LAYER (CQRS, Events, Modules)
TENANCY LAYER (@zudojs/tenancy)
CONTEXT & STORAGE (@zudojs/context, @zudojs/database)

Tenancy sits between the transport layer and application logic. HTTP middleware resolves the tenant from requests, then context flows through AsyncLocalStorage into all downstream operations.

TENANT ID

TenantId is a branded string type that prevents accidental misuse. Use createTenantId() to create validated instances.

import { createTenantId, type TenantId } from "@zudojs/tenancy"; // Create a tenant ID const id = createTenantId("acme-corp"); // TypeScript prevents passing a plain string function getTenant(id: TenantId) { /* ... */ } getTenant("acme-corp"); // ❌ Type error getTenant(id); // ✅ Works
Why Branded Types? Branded types catch bugs at compile time. You can't accidentally mix up a TenantId with a regular string or another branded type like UserId.

CONTEXT

Tenant context is propagated through AsyncLocalStorage. All async code within a run() call automatically has access to the current tenant.

TenantContextStorage

interface TenantContextStorage { get(): ExecutionTenantContext | undefined; run<T>(context: ExecutionTenantContext, callback: () => T): T; }

Factory Functions

// Create a new storage instance function createTenantContextStorage(): TenantContextStorage; // Get or create the default storage singleton function getDefaultStorage(): TenantContextStorage; // Reset default storage (for testing) function resetDefaultStorage(): void;

ContextManagerOptions

interface ContextManagerOptions { readonly storage: TenantContextStorage; }

createContextManager

Creates a high-level context manager with convenience methods:

function createContextManager(options: ContextManagerOptions): { /** Get current execution context (tenant or system). */ getCurrent(): ExecutionTenantContext | undefined; /** Get current tenant, if in tenant mode. */ getCurrentTenant(): Tenant | undefined; /** Require current tenant — throws TenantContextMissingError if absent. */ requireCurrentTenant(): Tenant; /** Check if running in system mode (no tenant). */ isSystemMode(): boolean; /** Run callback within a tenant context. */ run<T>(tenant: Tenant, callback: () => T): T; /** Run callback in system mode (no tenant). */ runSystem<T>(callback: () => T): T; /** Run callback with a specific tenant (alias for run). */ runAs<T>(tenant: Tenant, callback: () => T): T; };

Example: Context Propagation

import { createContextManager, getDefaultStorage, } from "@zudojs/tenancy"; const ctx = createContextManager({ storage: getDefaultStorage(), }); // Run within tenant context ctx.run(tenant, () => { console.log(ctx.getCurrentTenant()); // Tenant { id: "acme", ... } // Async operations automatically inherit context await loadOrders(); // Can access ctx.getCurrentTenant() inside }); // System mode (no tenant) ctx.runSystem(() => { console.log(ctx.isSystemMode()); // true console.log(ctx.getCurrentTenant()); // undefined });

RESOLVERS

Resolvers extract tenant identity from a context. Chain multiple resolvers together — they run in priority order with optional conflict detection.

function createResolverChain<Context = unknown>( resolvers: readonly TenantResolver<Context>[], options?: ResolverChainOptions, ): { resolve(context: Context): Promise<TenantResolutionResult>; };

createHeaderResolver

Reads tenant ID from an HTTP header. Default header: x-tenant-id. Default priority: 80.

interface HeaderResolverOptions { readonly headerName?: string; // default: "x-tenant-id" readonly priority?: number; // default: 80 } function createHeaderResolver( options?: HeaderResolverOptions, ): TenantResolver<HeaderContext>;

createSubdomainResolver

Extracts tenant from subdomain. E.g. acme.example.com → "acme". Default priority: 70.

interface SubdomainResolverOptions { readonly baseDomain?: string; // e.g. "example.com" readonly priority?: number; // default: 70 } function createSubdomainResolver( options?: SubdomainResolverOptions, ): TenantResolver<SubdomainContext>;

createPathResolver

Extracts tenant from URL path. E.g. /acme/users → "acme". Default priority: 60. Trust: untrusted.

interface PathResolverOptions { readonly prefix?: string; // prefix to strip, e.g. "/tenant" readonly priority?: number; // default: 60 } function createPathResolver( options?: PathResolverOptions, ): TenantResolver<PathContext>;

createJwtResolver

ERROR HIERARCHY

All error types are defined in @zudojs/errors and re-exported by this package. The base TenantError extends AuthorizationError.

Error When Thrown
TenantErrorBase error for all tenancy failures
InvalidTenantIdErrorTenant ID is empty or invalid
TenantNotFoundErrorTenant with given ID does not exist
TenantContextMissingErrorRequired tenant context not in AsyncLocalStorage
TenantResolutionErrorTenant resolution failed
TenantResolutionConflictErrorMultiple resolvers returned different tenants
TenantUnavailableErrorTenant is not in an usable state (not active)
TenantAccessDeniedErrorInsufficient trust level or access denied
TenantAlreadyExistsErrorTenant with identifier already exists
TenantProvisioningErrorTenant setup/provisioning failed
TenantIsolationErrorTenant isolation violation detected

Error Handling Pattern

import { TenantNotFoundError, TenantUnavailableError, TenantIsolationError, TenantContextMissingError, } from "@zudojs/tenancy"; try { const tenant = await manager.require(id); manager.assertActive(tenant); assertTenantOwnership(resource, tenant.id); } catch (error) { if (error instanceof TenantNotFoundError) { // 404 — tenant doesn't exist } else if (error instanceof TenantUnavailableError) { // 403 — tenant is suspended/inactive } else if (error instanceof TenantIsolationError) { // 403 — accessing wrong tenant's resource } else if (error instanceof TenantContextMissingError) { // 401 — no tenant context in request } }

FULL INTEGRATION EXAMPLE

Complete working example: tenant resolution, context propagation, middleware, and guard enforcement.

import { createTenantId, createHeaderResolver, createSubdomainResolver, createResolverChain, createMemoryTenantRepository, createTenantManager, createContextManager, getDefaultStorage, assertTenantUsable, assertTenantOwnership, isTenantActive, sameTenant, createResolveTenantMiddleware, createRequireTenantMiddleware, createTenantGuardMiddleware, createTenantPropagationMiddleware, createForbidden, } from "@zudojs/tenancy"; import type { Tenant, TenantId } from "@zudojs/tenancy"; // 1. Create tenant IDs const acmeId = createTenantId("acme-corp"); const globexId = createTenantId("globex-inc"); // 2. Set up repository const repo = createMemoryTenantRepository(); repo.add({ id: acmeId, name: "Acme Corp", slug: "acme", status: "active", metadata: { plan: "enterprise" }, }); repo.add({ id: globexId, name: "Globex Inc", slug: "globex", status: "suspended", metadata: { plan: "starter" }, }); // 3. Set up resolvers const headerResolver = createHeaderResolver({ headerName: "x-tenant-id", priority: 80, }); const subdomainResolver = createSubdomainResolver({ baseDomain: "example.com", priority: 70, }); const chain = createResolverChain( [headerResolver, subdomainResolver], { detectConflicts: true }, ); // 4. Set up context manager const storage = getDefaultStorage(); const ctxManager = createContextManager({ storage }); // 5. Set up tenant manager const tenantManager = createTenantManager({ repository: repo, storage, }); // 6. HTTP middleware stack app.use(createResolveTenantMiddleware({ resolver: headerResolver, repository: repo, storage, })); app.use(createRequireTenantMiddleware({ requirement: "required", })); app.use(createTenantGuardMiddleware({ storage, repository: repo })); app.use(createTenantPropagationMiddleware(storage)); // 7. Route handler — tenant context is automatic app.get("/api/orders", async (req) => { // Tenant is already resolved and in context const tenant = ctxManager.requireCurrentTenant(); assertTenantUsable(tenant); const orders = await loadOrdersForTenant(tenant.id); return { orders }; }); // 8. Guard a resource against wrong-tenant access app.get("/api/orders/:orderId", async (req) => { const tenant = ctxManager.requireCurrentTenant(); const order = await loadOrder(req.params.orderId); // Ensure order belongs to current tenant assertTenantOwnership(order, tenant.id); return { order }; }); // 9. Run async operations within tenant context async function processWebhook(tenantId: TenantId, payload: unknown) { const tenant = await tenantManager.require(tenantId); return ctxManager.run(tenant, async () => { // All async calls here inherit the tenant context const config = await loadTenantConfig(tenant.id); const result = await handlePayload(config, payload); return result; }); } // 10. System-level operations (no tenant) async function runSystemJob() { return ctxManager.runSystem(async () => { // No tenant context — system-level access const allTenants = repo.all(); for (const t of allTenants) { if (isTenantActive(t)) { await sendBillingCycleEmail(t); } } }); }
