@zudojs/serialization

Data translation layer for the Zudojs framework. Provides JSON serialization with type preservation, a pluggable transformer registry, envelope pattern for metadata-rich payloads, and encoding utilities.

SERIALIZATION JSON TRANSFORMERS ENVELOPES REGISTRY

INSTALLATION

// npm npm install @zudojs/serialization // pnpm pnpm add @zudojs/serialization // yarn yarn add @zudojs/serialization
Peer Dependencies: @zudojs/serialization depends on @zudojs/constants, @zudojs/errors, @zudojs/types, and @zudojs/validation. All at version 0.1.0.

WHAT IT DOES

@zudojs/serialization is the data translation layer. It converts JavaScript values to and from portable formats while preserving type information:

  • → JSON serialization with type preservation for special JS types
  • → Pluggable type transformer registry for custom types
  • → Automatic Date, BigInt, Map, Set, Buffer, Error serialization
  • → Envelope pattern for metadata-rich payloads (format, version, encoding)
  • → Serializer registry for named serializer lookup
  • → Encoding utilities — base64 and UTF-8 encode/decode
  • → Depth, size, and circular reference validation
  • → Pretty-print and compact serialization modes
  • → Async serializer support for streaming and large payloads
Core Principle: Application code depends on Serializer interfaces, not concrete implementations. The registry provides lookup by name, and transformers handle type round-trips.

Serialization sits in the middle of the data flow. Application code calls Serializer.serialize(), which delegates to transformers for type preservation, then to JSON.stringify/parse for the actual encoding.

INTERFACES

SerializeOptions

interface SerializeOptions { /** Pretty-print the output (JSON only). */ readonly pretty?: boolean; /** Preserve special JS types (Date, BigInt, Map, Set, etc.). */ readonly preserveTypes?: boolean; /** Maximum object depth before throwing. */ readonly maxDepth?: number; /** Maximum serialized size in bytes. */ readonly maxSize?: number; /** Indentation for pretty-print (default: 2). */ readonly indent?: number; /** Include Error.stack when serializing errors (default: false). */ readonly includeStack?: boolean; /** Permit __proto__/constructor/prototype as data keys (default: false). */ readonly allowUnsafeKeys?: boolean; }

DeserializeOptions

interface DeserializeOptions { /** Restore special JS types from tagged representations. */ readonly preserveTypes?: boolean; /** Maximum object depth before throwing. */ readonly maxDepth?: number; /** Throw on malformed data, and on an unrecognised $type tag. */ readonly strict?: boolean; /** Allow prototype-polluting keys during reconstruction (default: false). * Off by default, __proto__/constructor/prototype are dropped; on, they are * reinstated as real own properties, never as a prototype assignment. */ readonly allowUnsafeKeys?: boolean; /** Maximum accepted input size in bytes. */ readonly maxSize?: number; }

SerializationMetadata

interface SerializationMetadata { /** The format used (e.g., "json"). */ readonly format: string; /** Schema version for forward/backward compatibility. */ readonly version?: number; /** MIME content type (e.g., "application/json"). */ readonly contentType?: string; /** Character encoding (e.g., "utf-8"). */ readonly encoding?: string; }

SerializedEnvelope

interface SerializedEnvelope { readonly metadata: SerializationMetadata; readonly data: SerializedValue; }

Serializer

interface Serializer<TValue = unknown, TSerialized = SerializedValue> { /** Canonical name for registry lookup (e.g., "json"). */ readonly name: string; /** The MIME content type produced by this serializer. */ readonly contentType: string; /** Serialize a value into the target format. */ serialize(value: TValue, options?: SerializeOptions): TSerialized; /** Deserialize a value from the target format. */ deserialize<T = TValue>(value: TSerialized, options?: DeserializeOptions): T; }

AsyncSerializer

interface AsyncSerializer< TValue = unknown, TSerialized = SerializedValue, > { readonly name: string; readonly contentType: string; serialize(value: TValue, options?: SerializeOptions): Promise<TSerialized>; deserialize<T = TValue>( value: TSerialized, options?: DeserializeOptions, ): Promise<T>; }

TypeTransformer

interface TypeTransformer<TValue = unknown> { /** Tag name used in tagged representations (e.g., "Date"). */ readonly type: string; /** Returns true when this transformer handles the given value. */ canSerialize(value: unknown): value is TValue; /** Convert the value into a JSON-safe representation. */ serialize(value: TValue): unknown; /** Reconstruct the original value from the serialized form. */ deserialize(value: unknown): TValue; }

SERIALIZER REGISTRY

The SerializerRegistry manages named serializer instances. Other packages look up serializers by name instead of importing concrete classes.

Methods

Method Signature Returns
register() register(serializer: Serializer): void void. Overwrites existing registration with the same name.
unregister() unregister(name: string): boolean true if removed, false if not found
get() get(name: string): Serializer Serializer. Throws SerializerNotFoundError if not found.
has() has(name: string): boolean true if registered
names() names(): string[] Array of all registered serializer names
clear() clear(): void Removes all serializers
size get size(): number Number of registered serializers

createSerializer()

function createSerializer( format: SerializationFormat, options?: { readonly transformers?: TransformerRegistry; readonly pretty?: boolean; readonly preserveTypes?: boolean; }, ): Serializer;

createDefaultRegistry()

function createDefaultRegistry(): SerializerRegistry;

Returns a SerializerRegistry pre-populated with the built-in "json" serializer.

Example

import { SerializerRegistry, createSerializer } from "@zudojs/serialization"; const registry = new SerializerRegistry(); // Register a JSON serializer registry.register(createSerializer("json")); // Look up by name const json = registry.get("json"); // Serialize with the looked-up serializer const output = json.serialize({ hello: "world" }); console.log(registry.names()); // ["json"] console.log(registry.size); // 1

JSON SERIALIZER

The JSONSerializer is the primary serializer. It supports two modes: fast path (native JSON.stringify/parse) and advanced path (type preservation with transformers).

Class: JSONSerializer

class JSONSerializer implements Serializer<unknown, string> { readonly name: string; // "json" readonly contentType: string; // "application/json" constructor(options?: { readonly transformers?: TransformerRegistry; }); registerTransformer(transformer: TypeTransformer): void; serialize(value: unknown, options?: SerializeOptions): string; deserialize<T = unknown>(value: string, options?: DeserializeOptions): T; }

Fast Path (Default)

Delegates directly to native JSON.stringify / JSON.parse. Nearly zero overhead.

import { JSONSerializer } from "@zudojs/serialization"; const serializer = new JSONSerializer(); // Serialize const json = serializer.serialize({ name: "Zudo", version: 1 }); // '{"name":"Zudo","version":1}' // Deserialize const data = serializer.deserialize(json); // { name: "Zudo", version: 1 }

Advanced Path (Type Preservation)

Enables recursive traversal with transformer-based type preservation for Date, BigInt, Map, Set, Buffer, and Error.

const serializer = new JSONSerializer(); const payload = { createdAt: new Date("2026-01-15T10:30:00Z"), amount: 100n, tags: new Set(["important", "urgent"]), metadata: new Map([["key", "value"]]), }; // Serialize with type preservation const json = serializer.serialize(payload, { preserveTypes: true }); // Output includes type tags: // { // "createdAt": { "__type": "Date", "__value": "2026-01-15T10:30:00.000Z" }, // "amount": { "__type": "BigInt", "__value": "100" }, // "tags": { "__type": "Set", "__value": ["important", "urgent"] }, // "metadata": { "__type": "Map", "__value": [["key", "value"]] } // } // Deserialize — types are fully restored const restored = serializer.deserialize(json, { preserveTypes: true }); // restored.createdAt instanceof Date → true // restored.amount === 100n → true // restored.tags instanceof Set → true // restored.metadata instanceof Map → true

Pretty Print

const json = serializer.serialize( { name: "Zudo", config: { debug: true } }, { pretty: true, indent: 4 }, ); // { // "name": "Zudo", // "config": { // "debug": true // } // }

TRANSFORMER REGISTRY

The TransformerRegistry manages type transformers that handle custom JS types during serialization and deserialization. Keyed by type tag string.

Methods

Method Signature Returns
register() register(transformer: TypeTransformer): void void. Throws if max transformer limit reached.
unregister() unregister(type: string): boolean true if removed, false if not found
get() get(type: string): TypeTransformer TypeTransformer. Throws TransformerNotFoundError if not found.
findForValue() findForValue(value: unknown): TypeTransformer | undefined First transformer where canSerialize(value) is true, or undefined.
has() has(type: string): boolean true if registered
types() types(): string[] Array of all registered type tags
clear() clear(): void Removes all transformers
size get size(): number Number of registered transformers

Example

import { TransformerRegistry, DateTransformer } from "@zudojs/serialization"; const registry = new TransformerRegistry(); // Register a transformer registry.register(DateTransformer); // Check if registered console.log(registry.has("Date")); // true console.log(registry.types()); // ["Date"] // Find a transformer for a value const now = new Date(); const t = registry.findForValue(now); // Returns DateTransformer

TYPE TRANSFORMERS

Built-in transformers handle round-trip serialization for common JavaScript types. Each produces a tagged object with __type and __value fields.

DateTransformer

const DateTransformer: TypeTransformer<Date>; // type: "Date" // Serialized format: // { "__type": "Date", "__value": "2026-01-15T10:30:00.000Z" }

BigIntTransformer

const BigIntTransformer: TypeTransformer<bigint>; // type: "BigInt" // Serialized format: // { "__type": "BigInt", "__value": "100" }

MapTransformer

const MapTransformer: TypeTransformer<Map<unknown, unknown>>; // type: "Map" // Serialized format: // { "__type": "Map", "__value": [["key1", "val1"], ["key2", "val2"]] }

SetTransformer

const SetTransformer: TypeTransformer<Set<unknown>>; // type: "Set" // Serialized format: // { "__type": "Set", "__value": ["a", "b", "c"] }

BufferTransformer

const BufferTransformer: TypeTransformer<Uint8Array>; // type: "Buffer" // Serialized format: // { "__type": "Buffer", "__encoding": "base64", "__value": "SGVsbG8=" }

ErrorTransformer

const ErrorTransformer: TypeTransformer<Error>; // type: "Error" // Serialized format: // { // "__type": "Error", // "name": "ValidationError", // "message": "Invalid input", // "stack": "Error: Invalid input\n at ...", // "code": "INVALID_INPUT" // }

ENVELOPES

Envelopes wrap serialized data with metadata (format, version, encoding) so consumers know how to deserialize the payload. Essential for messaging, queues, RPC, and cross-service communication.

createEnvelope()

function createEnvelope( data: SerializedValue, format?: string, // default: SerializationFormat.JSON options?: { readonly version?: number; readonly contentType?: string; readonly encoding?: string; }, ): SerializedEnvelope;

unwrapEnvelope()

function unwrapEnvelope( envelope: SerializedEnvelope, expectedFormat?: string, ): SerializedValue;

serializeToEnvelope()

function serializeToEnvelope<T>( value: T, serializer: { serialize(v: T): string }, format?: string, ): SerializedEnvelope;

deserializeFromEnvelope()

function deserializeFromEnvelope<T>( envelope: SerializedEnvelope, deserializer: { deserialize<U>(v: string): U }, expectedFormat?: string, ): T;

Example

import { createEnvelope, unwrapEnvelope, serializeToEnvelope, deserializeFromEnvelope, JSONSerializer, } from "@zudojs/serialization"; const serializer = new JSONSerializer(); // Create envelope manually const json = serializer.serialize({ order: 123 }); const envelope = createEnvelope(json); // { // metadata: { format: "json", version: 1, contentType: "application/json", encoding: "utf-8" }, // data: '{"order":123}' // } // Serialize directly to envelope const envelope2 = serializeToEnvelope({ order: 456 }, serializer); // Unwrap and deserialize const data = deserializeFromEnvelope(envelope2, serializer); // { order: 456 }

ENCODING UTILITIES

Low-level encoding helpers for Base64 and UTF-8. These work in both Node.js and browser environments.

function fromBase64(base64: string): Uint8Array;

encodeUtf8()

function encodeUtf8(text: string): Uint8Array;

Example

import { toBase64, fromBase64, encodeUtf8, decodeUtf8, } from "@zudojs/serialization"; // UTF-8 encode/decode const encoded = encodeUtf8("Hello, Zudo!"); const decoded = decodeUtf8(encoded); // decoded === "Hello, Zudo!" // Base64 encode/decode const b64 = toBase64(encoded); const back = fromBase64(b64); // back === encoded (same Uint8Array)

ERROR HIERARCHY

All error types are defined in @zudojs/errors and re-exported by this package.

Error When Thrown
TransformerNotFoundError Requested transformer not in registry by type tag
SerializerNotFoundError Requested serializer not in registry by name
UnsupportedSerializationFormatError Format not supported by createSerializer() factory

Error Handling Pattern

import { SerializerRegistry, SerializerNotFoundError, } from "@zudojs/serialization"; const registry = new SerializerRegistry(); try { const serializer = registry.get("msgpack"); } catch (error) { if (error instanceof SerializerNotFoundError) { console.error(`Serializer not found: ${error.message}`); // Fall back to default const fallback = registry.get("json"); } }

FULL INTEGRATION EXAMPLE

Complete working example: create transformer registry, register transformers, create JSON serializer, serialize with type preservation, use envelopes, use registry.

import { TransformerRegistry, SerializerRegistry, JSONSerializer, DateTransformer, BigIntTransformer, MapTransformer, SetTransformer, createEnvelope, serializeToEnvelope, deserializeFromEnvelope, createDefaultRegistry, } from "@zudojs/serialization"; // 1. Create a transformer registry with built-in transformers const transformers = new TransformerRegistry(); transformers.register(DateTransformer); transformers.register(BigIntTransformer); transformers.register(MapTransformer); transformers.register(SetTransformer); // 2. Create a JSON serializer with the custom transformer registry const serializer = new JSONSerializer({ transformers }); // 3. Serialize a complex object with type preservation const order = { id: 12345, createdAt: new Date("2026-09-05T12:00:00Z"), total: 999999999999999n, items: new Set(["widget", "gadget"]), attributes: new Map([ ["color", "red"], ["size", "large"], ]), }; const json = serializer.serialize(order, { preserveTypes: true }); console.log(json); // 4. Wrap in an envelope for cross-service transport const envelope = serializeToEnvelope(order, serializer); console.log(envelope.metadata.format); // "json" console.log(envelope.metadata.version); // 1 // 5. Use the default serializer registry const registry = createDefaultRegistry(); const jsonSerializer = registry.get("json"); // 6. Deserialize from envelope const restored = deserializeFromEnvelope(envelope, jsonSerializer); console.log(restored.id); // 12345 console.log(restored.createdAt instanceof Date); // true console.log(restored.total); // 999999999999999n console.log(restored.items instanceof Set); // true console.log(restored.attributes instanceof Map); // true
