@zudojs/storage

Storage infrastructure for the Zudojs framework. Database abstraction with connection pooling, transaction support with savepoints, generic repository pattern, object storage, distributed locking, lifecycle management, and health checking.

STORAGE DATABASE OBJECT REPOSITORY LOCKING LIFECYCLE HEALTH

INSTALLATION

// npm npm install @zudojs/storage // pnpm pnpm add @zudojs/storage // yarn yarn add @zudojs/storage
Peer Dependencies: @zudojs/storage depends on @zudojs/errors, @zudojs/constants, @zudojs/types, and @zudojs/serialization. All at version 0.1.0.

WHAT IT DOES

@zudojs/storage is the storage infrastructure layer for the Zudojs framework. It provides:

  • → Database abstraction with connection pooling, backpressure, and health checks
  • → Transaction support with isolation levels and savepoints
  • → Generic repository pattern for CRUD operations on any entity
  • → Local file-based object storage with path traversal protection
  • → In-memory distributed lock manager with TTL and wait queues
  • → Storage lifecycle management with phase transitions (uninitialized → initializing → ready → draining → drained → shutdown)
  • → Health checking with component registration and aggregated reports
  • → JSON serialization with type preservation (BigInt, Date, Map, Set, Uint8Array)
  • → Pool statistics and monitoring for connection usage tracking
  • → Graceful drain and shutdown for all storage components
Core Principle: Application code depends on interfaces like Database, ObjectStorage, and Repository. Concrete implementations are swapped without changing business logic.

LIFECYCLE

Interface: StorageLifecycle

interface StorageLifecycle { initialize(): Promise<void>; start(): Promise<void>; healthCheck(): Promise<StorageHealth>; drain(): Promise<void>; shutdown(): Promise<void>; getPhase(): StorageLifecyclePhase; }

Class: StorageLifecycleManager

class StorageLifecycleManager implements StorageLifecycle { /** Register a storage component for lifecycle management. */ register(component: StorageLifecycle): void; initialize(): Promise<void>; start(): Promise<void>; healthCheck(): Promise<StorageHealth>; drain(): Promise<void>; shutdown(): Promise<void>; getPhase(): StorageLifecyclePhase; }

StorageLifecyclePhase

type StorageLifecyclePhase = | "uninitialized" // Initial state | "initializing" // Components starting up | "ready" // All components ready | "draining" // Gracefully draining | "drained" // All work completed | "shutdown"; // Fully shut down
Phase Transitions: The lifecycle follows a strict state machine. You cannot start from initializing — you must reach ready first. Attempting invalid transitions throws STORAGE_LIFECYCLE_INVALID_PHASE.

SERIALIZATION

Interface: Serializer

interface Serializer { serialize<T>(value: T, format?: SerializationFormat): Uint8Array; deserialize<T>(data: Uint8Array, format?: SerializationFormat): T; }

Class: JsonSerializer

class JsonSerializer implements Serializer { constructor(); /** Serialize a value to Uint8Array with type preservation. */ serialize<T>(value: T, format?: SerializationFormat): Uint8Array; /** Deserialize a Uint8Array back to the original value. */ deserialize<T>(data: Uint8Array, format?: SerializationFormat): T; }
Type Preservation: JsonSerializer delegates to @zudojs/serialization's JSONSerializer with preserveTypes: true. This handles BigInt, Date, Map, Set, and Uint8Array correctly — values that standard JSON.parse loses.

ERROR HIERARCHY

All error types are defined in @zudojs/errors. Storage uses StorageError as its base error class.

Error Code When Thrown
StorageError—Base error for all storage issues
NotFoundError—Entity not found in repository
StorageErrorSTORAGE_CONNECTION_POOL_CLOSEDAcquiring from a drained pool
NotFoundErrorSTORAGE_ENTITY_NOT_FOUNDUpdate called with non-existent ID
StorageErrorSTORAGE_PATH_TRAVERSALKey resolves outside basePath
StorageErrorSTORAGE_LOCK_ACQUIRE_TIMEOUTLock not acquired within timeout
StorageErrorSTORAGE_LIFECYCLE_INVALID_PHASEInvalid lifecycle phase transition

Error Handling Pattern

import { StorageError, NotFoundError } from "@zudojs/errors"; try { await repo.update("non-existent", { name: "updated" }); } catch (error) { if (error instanceof NotFoundError) { console.error("Entity not found:", error.message); } else if (error instanceof StorageError) { console.error("Storage error:", error.code, error.message); } }

FULL INTEGRATION EXAMPLE

Complete example: connection pool, repository, object storage, locking, lifecycle, and health checking.

import { ConnectionPool, BaseRepository, LocalObjectStorage, InMemoryLockManager, StorageLifecycleManager, HealthChecker, JsonSerializer, } from "@zudojs/storage"; import type { Database, ObjectStorage } from "@zudojs/storage"; // 1. Create connection pool const pool = new ConnectionPool( async () => await createPostgresConnection(), { min: 2, max: 10, acquireTimeout: 5000 } ); await pool.initialize(); // 2. Use repository pattern interface User { id: string; name: string; email: string; } class UserRepository extends BaseRepository<User> { async findByEmail(email: string): Promise<User | null> { const result = await this.database.query<User>({ text: `SELECT * FROM users WHERE email = $1`, parameters: [email], }); return result.rows[0] ?? null; } } const userRepo = new UserRepository(database, { tableName: "users" }); const user = await userRepo.create({ id: "1", name: "Alice", email: "alice@example.com" }); const found = await userRepo.findById("1"); const exists = await userRepo.exists("1"); // 3. Object storage operations const storage = new LocalObjectStorage("./data"); const meta = await storage.put("uploads/photo.jpg", imageBytes, { contentType: "image/jpeg", }); const obj = await storage.get("uploads/photo.jpg"); const buffer = await obj!.arrayBuffer(); const listed = await storage.list("uploads/"); // 4. Acquire and release locks const lockManager = new InMemoryLockManager(); const lock = await lockManager.acquire("resource:123", { timeout: 5000, ttl: 30000, }); try { // Do protected work await processData(); } finally { await lock.release(); } // 5. Lifecycle management const lifecycle = new StorageLifecycleManager(); lifecycle.register(pool); lifecycle.register(lockManager); await lifecycle.initialize(); // uninitialized → initializing → ready await lifecycle.start(); // ready → ready (components started) // 6. Health checking const checker = new HealthChecker(); checker.register("pool", pool); checker.register("lifecycle", lifecycle); const report = await checker.checkAll(); console.log(report.healthy); // true or false // 7. Graceful shutdown await lifecycle.drain(); // ready → draining → drained await lifecycle.shutdown(); // drained → shutdown await pool.drain(); // Close all connections
