Adapters

Boundary layer between Zudo and external platforms.

ADAPTERS BOUNDARY PLATFORM

Overview

Adapters are Zudo's boundary layer for integrating with external platforms, services, and transports. They follow the adapter pattern — translating between Zudo's internal interfaces and the specific APIs of external systems.

The adapter system makes your application code platform-agnostic. Swap HTTP frameworks, databases, or message brokers without changing business logic.

ADAPTER PATTERN

  • • Interface — Standardized adapter contract defined by Zudo
  • • Implementation — Platform-specific adapter (Express, Redis, RabbitMQ)
  • • Registry — Central registration for runtime adapter resolution
  • • Capabilities — Feature negotiation between Zudo and adapters

Adapter Pattern

Every adapter implements the Adapter interface, which defines the contract for connecting to and interacting with external systems:

interface Adapter<TConfig> { name: string; version: string; // Lifecycle connect(config: TConfig): Promise<void>; disconnect(): Promise<void>; isConnected(): boolean; // Capabilities getCapabilities(): AdapterCapability[]; // Health healthCheck(): Promise<AdapterHealth>; }

Adapter Registration

Adapters are registered with the adapter registry before the runtime starts. Multiple adapters of the same type can be registered with different names.

import { createAdapterRegistry } from "@zudojs/adapters"; import { ExpressHttpAdapter } from "./adapters/express.js"; import { RedisCacheAdapter } from "./adapters/redis.js"; const registry = createAdapterRegistry(); // Register adapters registry.register("http", new ExpressHttpAdapter()); registry.register("cache", new RedisCacheAdapter()); // Connect all adapters await registry.connectAll(); // Resolve a specific adapter const http = registry.get("http");

Adapter Capabilities

Capabilities declare what features an adapter supports. The runtime uses capabilities to negotiate features and enable/disable functionality.

type AdapterCapability = | "streaming" // Supports streaming responses | "websockets" // Supports WebSocket connections | "server-sent-events" // Supports SSE | "file-upload" // Supports multipart file uploads | "compression" // Supports response compression | "caching" // Supports response caching | "batching" // Supports request batching | "retry"; // Supports automatic retries // Check capabilities at runtime const caps = adapter.getCapabilities(); if (caps.includes("streaming")) { // Use streaming API }

Transport Abstractions

Zudo provides transport abstractions for common communication patterns. Adapters implement these abstractions for specific platforms.

HTTP Transport

Request/response communication over HTTP. Adapters: Express, Fastify, Hono, Node.js native.

REST GraphQL RPC

Message Transport

Asynchronous messaging between services. Adapters: Redis, RabbitMQ, Kafka, in-memory.

Pub/Sub Queue Stream

Storage Transport

Data persistence and retrieval. Adapters: PostgreSQL, MongoDB, S3, file system.

SQL NoSQL Object

Cache Transport

Caching layer. Adapters: Memory, Redis, Memcached.

In-Memory Distributed CDN

Creating Custom Adapters

To create a custom adapter, implement the Adapter interface and register it with the registry:

import { Adapter, AdapterHealth, AdapterCapability } from "@zudojs/adapters"; class PostgresAdapter implements Adapter<PostgresConfig> { readonly name = "postgres"; readonly version = "1.0.0"; private pool: Pool | null = null; async connect(config: PostgresConfig): Promise<void> { this.pool = new Pool(config); await this.pool.connect(); } async disconnect(): Promise<void> { await this.pool?.end(); this.pool = null; } isConnected(): boolean { return this.pool !== null; } getCapabilities(): AdapterCapability[] { return ["batching", "retry"]; } async healthCheck(): Promise<AdapterHealth> { try { await this.pool?.query("SELECT 1"); return { healthy: true, adapter: this.name }; } catch (e) { return { healthy: false, adapter: this.name, error: e }; } } } // Register with the registry registry.register("database", new PostgresAdapter());
