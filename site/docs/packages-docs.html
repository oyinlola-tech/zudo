@zudojs/docs

Documentation infrastructure for the Zudojs framework — structured document model, registry, validation, navigation, frontmatter parsing, and multi-format output generation.

DOCUMENT MODEL REGISTRY VALIDATION NAVIGATION GENERATORS

INSTALLATION

// npm npm install @zudojs/docs // pnpm pnpm add @zudojs/docs
Peer Dependencies: @zudojs/docs depends on @zudojs/errors (v0.0.1). No external dependencies required.

WHAT IT DOES

@zudojs/docs provides the infrastructure for building and maintaining documentation systems:

  • → Document Model — structured AST nodes (headings, paragraphs, code, tables, links, callouts) plus markdown, MDX, and HTML content types
  • → Document Builder — fluent API for creating validated, immutable documentation documents
  • → Frontmatter Parser — YAML-like metadata extraction from markdown files with type coercion
  • → Document Registry — O(1) lookup by ID with category and tag filtering
  • → Validation — document structure, link integrity, duplicate detection, and full validation pipeline
  • → Navigation — breadcrumb generation, tree flattening, sibling lookup, and item search
  • → Examples — first-class code example modeling with validation and rendering
  • → Generators — markdown output with frontmatter, JSON export, and index generation
  • → Utilities — ID normalization, path-to-ID conversion, link resolution, heading extraction, markdown stripping
Core Principle: Documents are immutable value objects. The registry is the single source of truth. Validation runs before publication. Navigation is derived from structure, not hardcoded.

WHERE IT SITS

GENERATORS (Markdown, JSON, HTML)
DOCS LAYER (@zudojs/docs)
CONTENT SOURCES (Files, CMS, Git)
CONSUMERS (Documentation Sites, API Docs)

The docs package sits between your content sources and your documentation site. It reads content, structures it, validates it, and generates output for your documentation platform.

DOCUMENT MODEL

The core of @zudojs/docs is the DocumentationDocument — an immutable value object representing a documentation page.

interface DocumentationDocument { readonly id: string; // Stable dot-separated ID readonly title: string; // Display title readonly description?: string; // Short description readonly content: DocumentationContent; // Markdown, MDX, HTML, or Structured readonly category?: DocumentationCategory; readonly tags?: readonly string[]; readonly version?: string; readonly status?: DocumentationStatus; readonly metadata?: DocumentationMetadata; readonly deprecated?: boolean; readonly deprecatedMessage?: string; readonly visibility?: "SERVER" | "CLIENT"; }

Content Types

Documents support four content formats:

Type Interface Description
"markdown"MarkdownContentRaw markdown string
"mdx"MDXContentMDX string with JSX components
"html"HTMLContentRaw HTML string
"structured"StructuredContentAST nodes for multi-format rendering

AST Node Types

Structured content uses typed AST nodes:

type DocumentationNode = | HeadingNode // { type: "heading", level: 1-6, value: string } | ParagraphNode // { type: "paragraph", value: string } | CodeNode // { type: "code", language?: string, value: string } | ListNode // { type: "list", ordered: boolean, items: string[] } | LinkNode // { type: "link", href: string, value: string } | TableNode // { type: "table", headers: string[], rows: string[][] } | QuoteNode // { type: "quote", value: string } | CalloutNode; // { type: "callout", kind: "note"|"warning"|"tip"|"danger", value: string }

Categories & Status

type DocumentationCategory = | "introduction" | "guide" | "tutorial" | "reference" | "api" | "architecture" | "configuration" | "deployment" | "security" | "migration" | "examples"; type DocumentationStatus = | "stable" | "experimental" | "beta" | "deprecated" | "internal";

DOCUMENT BUILDER

Fluent API for creating validated, immutable documentation documents.

// Full builder import { createDocument } from "@zudojs/docs"; const doc = createDocument({ id: "guides.http.routing", title: "HTTP Routing", description: "How to define routes in Zudo", content: { type: "markdown", value: "# Routing\n\nDefine routes..." }, category: "guide", tags: ["http", "routing"], version: "0.0.1", status: "stable", }); // Markdown shorthand import { createMarkdownDocument } from "@zudojs/docs"; const md = createMarkdownDocument( "guides.config", "Configuration", "# Configuration\n\nUse layered sources...", { category: "guide", tags: ["config"] }, ); // Structured (AST nodes) import { createStructuredDocument } from "@zudojs/docs"; const structured = createStructuredDocument( "api.container", "Container API", [ { type: "heading", level: 1, value: "Container" }, { type: "paragraph", value: "The DI container manages dependencies." }, { type: "code", language: "typescript", value: "const c = createContainer()" }, ], { category: "api" }, );

Validation

Throws on Invalid Input: createDocument() throws if ID, title, or content is missing. Use try/catch or validate first with validateDocument().

FRONTMATTER PARSER

Parses YAML-like frontmatter delimited by --- markers from markdown content.

import { parseFrontmatter } from "@zudojs/docs"; const raw = `--- title: HTTP Routing description: How to define routes category: guide tags: - http - routing version: "0.0.1" --- # Routing Define routes with the HTTP adapter.`; const { metadata, content } = parseFrontmatter(raw); console.log(metadata.title); // "HTTP Routing" console.log(metadata.category); // "guide" console.log(metadata.tags); // ["http", "routing"] console.log(content); // "# Routing\n\nDefine routes..."

Supported Fields

interface FrontmatterMetadata { readonly title?: string; readonly description?: string; readonly category?: string; readonly tags?: readonly string[]; readonly version?: string; readonly status?: string; readonly deprecated?: boolean; readonly deprecatedMessage?: string; readonly visibility?: string; readonly [key: string]: unknown; // Extensible }

Type Coercion

  • "true" / "false" → boolean
  • Numeric strings → number
  • YAML arrays (lines starting with -) → string arrays
  • Everything else → string

DOCUMENT REGISTRY

DocumentRegistry provides O(1) lookup by ID with category and tag filtering. Prevents duplicate IDs.

class DocumentRegistry implements DocumentationProvider { register(document: DocumentationDocument): void; registerAll(documents: readonly DocumentationDocument[]): void; get(id: string): DocumentationDocument | undefined; getAll(): readonly DocumentationDocument[]; has(id: string): boolean; delete(id: string): boolean; clear(): void; ids(): readonly string[]; byCategory(category: string): readonly DocumentationDocument[]; byTag(tag: string): readonly DocumentationDocument[]; get size(): number; } function createDocumentRegistry(): DocumentRegistry;

Methods

Method Signature Returns
register() register(doc): void Registers document. Throws on duplicate ID.
get() get<T>(id): T | undefined O(1) lookup by dot-separated ID
byCategory() byCategory(cat): Document[] Filters all documents by category
byTag() byTag(tag): Document[] Filters all documents by tag
ids() ids(): string[] Returns all registered document IDs

Example

import { createDocumentRegistry, createDocument } from "@zudojs/docs"; const registry = createDocumentRegistry(); registry.register(createDocument({ id: "guides.http.routing", title: "HTTP Routing", content: { type: "markdown", value: "# Routing\n\n..." }, category: "guide", tags: ["http", "routing"], })); // O(1) lookup const doc = registry.get("guides.http.routing"); // Filter const guides = registry.byCategory("guide"); const httpDocs = registry.byTag("http"); // Stats console.log(registry.size); // 1 console.log(registry.ids()); // ["guides.http.routing"]

VALIDATION

Multi-level validation: document structure, link integrity, duplicate detection, and full pipeline.

// Validate a single document import { validateDocument } from "@zudojs/docs"; const result = validateDocument(doc); if (!result.valid) { result.issues.forEach(i => console.error(`[${i.code}] ${i.message}`)); } // Check for duplicate IDs import { validateNoDuplicateIds } from "@zudojs/docs"; const dupes = validateNoDuplicateIds(registry.getAll()); // Validate internal links import { validateLinks } from "@zudojs/docs"; const links = validateLinks(doc, new Set(registry.ids())); // Full validation pipeline import { validateAll, validateNavigation } from "@zudojs/docs"; const all = validateAll(registry.getAll()); const nav = validateNavigation(navigationItems, registry);

interface ValidationResult { readonly valid: boolean; readonly issues: readonly ValidationIssue[]; } interface ValidationIssue { readonly severity: "error" | "warning"; readonly code: string; // e.g. "MISSING_ID", "BROKEN_LINK" readonly message: string; readonly documentId?: string; }

NAVIGATION

Tree-based navigation with breadcrumb generation, flattening, sibling lookup, and item search.

import { getBreadcrumbs, flattenNavigation, findNavigationItem, getSiblings, } from "@zudojs/docs"; const navigation: DocumentationNavigationItem[] = [ { title: "Getting Started", children: [ { title: "Installation", documentId: "getting-started.installation" }, { title: "First App", documentId: "getting-started.first-app" }, ], }, { title: "Guides", children: [ { title: "HTTP Routing", documentId: "guides.http.routing" }, ], }, ]; // Breadcrumbs for a document const crumbs = getBreadcrumbs("guides.http.routing", navigation); // [{ title: "Guides" }, { title: "HTTP Routing", documentId: "..." }] // Flatten to ordered list of IDs const flat = flattenNavigation(navigation); // ["getting-started.installation", "getting-started.first-app", "guides.http.routing"] // Find specific item const item = findNavigationItem("guides.http.routing", navigation); // Get siblings const siblings = getSiblings("guides.http.routing", navigation);

Navigation Types

interface DocumentationNavigationItem { readonly title: string; readonly documentId?: string; readonly children?: readonly DocumentationNavigationItem[]; } interface DocumentationBreadcrumb { readonly title: string; readonly documentId?: string; } interface SearchDocument { readonly id: string; readonly title: string; readonly content: string; readonly tags: readonly string[]; readonly path: string; } interface SearchResult { readonly id: string; readonly title: string; readonly path: string; readonly excerpt?: string; readonly score?: number; }

CODE EXAMPLES

First-class code example modeling with validation, markdown rendering, and JSON serialization.

import { DocumentationExample, validateExample, renderExampleMarkdown, exampleToJSON, } from "@zudojs/docs"; const example: DocumentationExample = { id: "basic-container", title: "Creating a Container", language: "typescript", code: `const container = createContainer(); container.register("config", () => loadConfig());`, description: "Set up a basic DI container", }; // Validate const result = validateExample(example); if (!result.valid) { result.errors.forEach(console.error); } // Render as markdown const md = renderExampleMarkdown(example); // ### Creating a Container\n// Set up a basic DI container\n// ```typescript\n// const container = ...\n// ``` // Serialize to JSON const json = exampleToJSON(example);

OUTPUT GENERATORS

Generate markdown, JSON, or index output from documents and registries.

Markdown Generator

import { generateMarkdown, nodesToMarkdown } from "@zudojs/docs"; // Full document with frontmatter const md = generateMarkdown(doc); // ---\n// title: HTTP Routing\n// category: guide\n// ---\n// # Routing\n// ... // Without frontmatter const body = generateMarkdown(doc, { includeFrontmatter: false }); // With metadata footer const full = generateMarkdown(doc, { includeMeta: true }); // AST nodes to markdown const fromNodes = nodesToMarkdown([ { type: "heading", level: 1, value: "Title" }, { type: "paragraph", value: "Some text." }, { type: "code", language: "ts", value: "const x = 1" }, ]);

UTILITIES

Helper functions for document ID management, link resolution, and content extraction.

import { normalizeDocumentId, documentIdFromPath, resolveDocumentLink, extractTitleFromMarkdown, extractHeadings, stripMarkdown, } from "@zudojs/docs"; // Normalize IDs normalizeDocumentId("..guides..http..routing.."); // "guides.http.routing" // Path to ID documentIdFromPath("guides/http/routing.md"); // "guides.http.routing" // Resolve relative links resolveDocumentLink("guides.http", "./routing"); // "guides.http.routing" resolveDocumentLink("guides.http.routing", "../config"); // "guides.config" // Extract from markdown extractTitleFromMarkdown("# Hello World\n\nContent"); // "Hello World" extractHeadings("# H1\n## H2\n### H3"); // [{ level: 1, text: "H1" }, { level: 2, text: "H2" }, ...] // Strip formatting stripMarkdown("**bold** and *italic* and `code`"); // "bold and italic and code"

import { describe, it, expect } from "vitest"; import { createDocument, createDocumentRegistry, validateDocument, validateAll, } from "@zudojs/docs"; describe("DocumentationRegistry", () => { it("registers and retrieves documents", () => { const registry = createDocumentRegistry(); const doc = createDocument({ id: "test.doc", title: "Test", content: { type: "markdown", value: "# Test" }, }); registry.register(doc); expect(registry.has("test.doc")).toBe(true); expect(registry.get("test.doc")?.title).toBe("Test"); }); it("validates all documents", () => { const registry = createDocumentRegistry(); registry.register(createDocument({ id: "valid.doc", title: "Valid", content: { type: "markdown", value: "# Valid" }, })); const result = validateAll(registry.getAll()); expect(result.valid).toBe(true); }); });

FULL INTEGRATION EXAMPLE

Complete example: parse frontmatter, register, validate, generate output.

import { createDocument, createDocumentRegistry, parseFrontmatter, generateMarkdown, generateIndex, validateAll, validateLinks, getBreadcrumbs, flattenNavigation, } from "@zudojs/docs"; // 1. Parse markdown files with frontmatter const files = ["routing.md", "config.md", "auth.md"]; const registry = createDocumentRegistry(); for (const file of files) { const raw = await readFile(file, "utf-8"); const { metadata, content } = parseFrontmatter(raw); registry.register(createDocument({ id: documentIdFromPath(file), title: metadata.title ?? file, content: { type: "markdown", value: content }, category: metadata.category, tags: metadata.tags, })); } // 2. Validate everything const validation = validateAll(registry.getAll()); if (!validation.valid) { validation.issues.forEach(i => console.error(i.message)); } // 3. Check link integrity const ids = new Set(registry.ids()); for (const doc of registry.getAll()) { const links = validateLinks(doc, ids); if (!links.valid) { links.issues.forEach(i => console.warn(i.message)); } } // 4. Build navigation const navigation = [ { title: "Guides", children: [ { title: "Routing", documentId: "routing" }, { title: "Config", documentId: "config" }, ]}, ]; const crumbs = getBreadcrumbs("routing", navigation); const flat = flattenNavigation(navigation); // 5. Generate output for (const doc of registry.getAll()) { const md = generateMarkdown(doc); await writeFile(`dist/${doc.id}.md`, md); } // 6. Generate search index const index = generateIndex(registry.getAll()); await writeFile("dist/search-index.json", JSON.stringify(index));
