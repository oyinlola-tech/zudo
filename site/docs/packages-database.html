@zudojs/database

Database infrastructure for Zudo — Prisma-backed clients, generic repositories, query builders, managed transactions, unit-of-work, pagination, migrations, seeding, advisory locks, caching, health checks, and relation definitions.

PRISMA REPOSITORY PATTERN TRANSACTIONS MIGRATIONS CONNECTION POOLING

INSTALLATION

// npm npm install @zudojs/database // pnpm pnpm add @zudojs/database
Peer Dependencies: @zudojs/database depends on @zudojs/errors (v0.1.0) and @prisma/client. You must have a working Prisma setup with a schema.prisma file.

WHAT IT DOES

@zudojs/database provides the full data-access layer for Zudo applications:

  • → DatabaseClient — Prisma-backed client with connection lifecycle, health checks, and raw query support
  • → Database Facade — singleton interface for connect, disconnect, transactions, and repository access
  • → ConnectionManager — connection lifecycle tracking, readiness gating, event-driven health monitoring
  • → BaseRepository — generic CRUD with typed pagination, sorting, and soft-delete support
  • → QueryBuilder — database-neutral filter and sort clause construction with 25+ filter functions
  • → TransactionManager — managed transactions with automatic retry and rollback
  • → DatabaseUnitOfWork — tracks dirty entities across a transaction boundary
  • → Pagination — offset-based and cursor-based pagination with metadata
  • → MigrationRunner — versioned migrations with advisory locks and history tracking
  • → SeedRunner — tracked seed execution with advisory locks and idempotent seeding
  • → Advisory Locks — database-level locking for single-execution coordination
  • → In-Memory Cache — TTL-based cache with getOrSet pattern and tag-based invalidation
  • → Relation Definitions — typed one-to-one, one-to-many, many-to-one, many-to-many relation registry
  • → Health Checks — database health, readiness probes, and latency monitoring
Core Principle: Your application code works with BaseRepository and QueryBuilder. It never touches Prisma directly. The database layer handles connection management, transaction coordination, and caching transparently.

WHERE IT SITS

APPLICATION LAYER (Services, Handlers, CQRS)
DATABASE LAYER (@zudojs/database)
PRISMA CLIENT (@prisma/client)
DATABASE ENGINE (PostgreSQL, MySQL, SQLite)

The database package sits between your application code and Prisma. Services call repositories; repositories build queries; the client executes them against the database engine.

CORE API — DATABASE CLIENT

The DatabaseClient wraps a Prisma client with connection lifecycle, health checks, and raw query support. It implements the Adapter contract from @zudojs/adapters.

interface DatabaseClientOptions { readonly provider: string; // "postgresql" | "mysql" | "sqlite" readonly url: string; // DATABASE_URL readonly log?: DatabaseLogger; readonly maxRetries?: number; // default: 3 readonly retryDelay?: number; // default: 1000ms } class DatabaseClient { readonly name: string; readonly version: string; readonly capabilities: AdapterCapabilities; constructor(options: DatabaseClientOptions); initialize(): Promise<void>; connect(): Promise<void>; disconnect(): Promise<void>; getClient(): PrismaClient; execute<T>(fn: (client: PrismaClient) => Promise<T>): Promise<T>; queryRaw(query: string, ...args: unknown[]): Promise<unknown[]>; executeRaw(query: string, ...args: unknown[]): Promise<number>; healthCheck(): Promise<DatabaseHealth>; isConnected(): boolean; connectionCount(): number; }

Methods

Method Signature Returns
connect() connect(): Promise<void> Establishes connection with retry logic. Throws ConnectionError on failure.
disconnect() disconnect(): Promise<void> Gracefully closes connection pool.
getClient() getClient(): PrismaClient Returns raw Prisma client. Throws if not connected.
execute() execute<T>(fn): Promise<T> Executes callback with Prisma client. Validates connection first.
queryRaw() queryRaw(query, ...args): Promise<unknown[]> Executes raw SQL query. Returns row results.
executeRaw() executeRaw(query, ...args): Promise<number> Executes raw SQL statement. Returns affected row count.
healthCheck() healthCheck(): Promise<DatabaseHealth> Returns health status with latency, pool stats, and provider info.
isConnected() isConnected(): boolean Returns true if connection pool is active.
connectionCount() connectionCount(): number Returns number of active connections in pool.

Example: Using the Client

import { DatabaseClient } from "@zudojs/database"; const client = new DatabaseClient({ provider: "postgresql", url: process.env.DATABASE_URL!, maxRetries: 5, retryDelay: 2000, }); // Connect with retries await client.connect(); // Execute queries via callback const users = await client.execute(async (prisma) => { return prisma.user.findMany({ where: { active: true } }); }); // Raw queries const rows = await client.queryRaw("SELECT * FROM users WHERE id = $1", userId); const affected = await client.executeRaw("UPDATE users SET active = false WHERE id = $1", userId); // Health check const health = await client.healthCheck(); console.log(health.status); // "healthy" | "unhealthy" console.log(health.latency); // 12

DATABASE FACADE

The Database class provides a high-level singleton interface for managing connections, repositories, and transactions.

interface DatabaseConfig { readonly provider: string; readonly url: string; readonly cache?: CacheConfig; readonly migrations?: MigrationConfig; } class Database { static createDatabase(config: DatabaseConfig): Database; static createDatabaseFromClient(client: DatabaseClient): Database; connect(): Promise<void>; disconnect(): Promise<void>; getClient(): DatabaseClient; getRepository<T>(model: string): BaseRepository<T>; execute<T>(fn: (client: PrismaClient) => Promise<T>): Promise<T>; transaction<T>(fn: (tx: PrismaClient) => Promise<T>): Promise<T>; healthCheck(): Promise<DatabaseHealth>; }

Example: Full Database Lifecycle

import { createDatabase } from "@zudojs/database"; const db = createDatabase({ provider: "postgresql", url: process.env.DATABASE_URL!, }); // Connect await db.connect(); // Get typed repository const users = db.getRepository<User>("user"); // Use repository const user = await users.findById("clx1234..."); await users.create({ name: "Alice", email: "alice@example.com" }); // Transaction await db.transaction(async (tx) => { await tx.user.update({ where: { id }, data: { balance: { decrement: 100 } } }); await tx.transaction.create({ data: { userId: id, amount: 100 } }); }); // Health check const health = await db.healthCheck(); // Disconnect await db.disconnect();

CONNECTION MANAGER

DatabaseConnectionManager tracks connection lifecycle, emits events, and provides readiness gating and health monitoring.

interface ConnectionManagerConfig { readonly healthCheckInterval?: number; // default: 30000ms readonly readinessTimeout?: number; // default: 5000ms readonly maxRetries?: number; // default: 3 } class DatabaseConnectionManager { constructor(client: DatabaseClient, config?: ConnectionManagerConfig); connect(): Promise<void>; disconnect(): Promise<void>; waitForReady(timeout?: number): Promise<void>; waitForHealthy(timeout?: number): Promise<void>; isReady(): boolean; isHealthy(): boolean; on(event: string, handler: Function): () => void; removeListener(event: string, handler: Function): void; healthCheck(): Promise<DatabaseHealth>; startHealthChecks(): void; stopHealthChecks(): void; getHealthHistory(): readonly DatabaseHealth[]; }

Events

Event Payload Description
connectedvoidEmitted when connection pool is established
disconnectedvoidEmitted when connection pool is closed
errorErrorEmitted on connection errors
healthChangeDatabaseHealthEmitted when health status changes
retrying{attempt, maxRetries}Emitted during reconnection attempts
readyvoidEmitted when connection is ready for queries

Example: Event-Driven Monitoring

import { DatabaseConnectionManager } from "@zudojs/database"; const manager = new DatabaseConnectionManager(client, { healthCheckInterval: 15000, readinessTimeout: 3000, }); manager.on("healthChange", (health) => { if (health.status === "unhealthy") { alertOps("Database unhealthy!", health); } }); manager.on("retrying", ({ attempt, maxRetries }) => { console.log(`Retrying connection ${attempt}/${maxRetries}`); }); await manager.connect(); await manager.waitForReady(); // Blocks until ready manager.startHealthChecks(); // Periodic background checks

BASE REPOSITORY

BaseRepository<T> provides generic CRUD operations with typed pagination, sorting, and soft-delete support.

class BaseRepository<T extends Record<string, unknown>> { constructor(client: DatabaseClient, model: string); // CRUD findById(id: string): Promise<T | null>; findFirst(where: Partial<T>): Promise<T | null>; findMany(options?: FindManyOptions<T>): Promise<T[]>; create(data: CreateInput<T>): Promise<T>; createMany(items: CreateInput<T>[]): Promise<number>; update(id: string, data: UpdateInput<T>): Promise<T>; upsert(where: Partial<T>, create: CreateInput<T>, update: UpdateInput<T>): Promise<T>; delete(id: string): Promise<void>; deleteMany(where: Partial<T>): Promise<number>; // Aggregation count(where?: Partial<T>): Promise<number>; exists(where: Partial<T>): Promise<boolean>; // Pagination paginate(options: PaginateOptions<T>): Promise<PaginatedResult<T>>; paginateCursor(options: CursorPaginateOptions<T>): Promise<CursorPaginatedResult<T>>; // Soft delete softDelete(id: string): Promise<void>; restore(id: string): Promise<void>; findDeleted(options?: FindManyOptions<T>): Promise<T[]>; }

Example: Custom Repository

import { BaseRepository } from "@zudojs/database"; interface User { id: string; name: string; email: string; active: boolean; createdAt: Date; } class UserRepository extends BaseRepository<User> { async findByEmail(email: string): Promise<User | null> { return this.findFirst({ email }); } async findActiveUsers(): Promise<User[]> { return this.findMany({ where: { active: true }, orderBy: [{ field: "createdAt", direction: "desc" }], }); } } const userRepo = new UserRepository(client, "user"); const alice = await userRepo.findByEmail("alice@example.com"); const active = await userRepo.findActiveUsers();

QUERY BUILDER

QueryBuilder constructs database-neutral filter and sort clauses that repositories translate into provider-specific queries.

class QueryBuilder<T> { where(condition: QueryCondition<T>): this; and(...conditions: QueryCondition<T>[]): this; or(...conditions: QueryCondition<T>[]): this; not(condition: QueryCondition<T>): this; orderBy(field: keyof T, direction?: "asc" | "desc"): this; limit(n: number): this; offset(n: number): this; select(...fields: (keyof T)[]): this; include(relation: string): this; build(): QueryFilter<T>; reset(): this; }

Example: Building Queries

import { QueryBuilder } from "@zudojs/database"; // Simple filter const query = new QueryBuilder<User>() .where({ field: "active", operator: "equals", value: true }) .where({ field: "age", operator: "gte", value: 18 }) .orderBy("createdAt", "desc") .limit(20) .build(); // Complex filter const complex = new QueryBuilder<User>() .and( { field: "role", operator: "equals", value: "admin" }, { field: "active", operator: "equals", value: true }, ) .or( { field: "email", operator: "contains", value: "@company.com" }, { field: "role", operator: "equals", value: "superadmin" }, ) .orderBy("name", "asc") .build();

QUERY FILTERS

25+ filter factory functions for building typed query conditions.

Comparison Filters

import { equals, not, gt, gte, lt, lte, inList, notInList, between, } from "@zudojs/database"; equals("status", "active"); // { field: "status", op: "equals", value: "active" } not("role", "guest"); // { field: "role", op: "not", value: "guest" } gt("age", 18); // { field: "age", op: "gt", value: 18 } gte("score", 90); // { field: "score", op: "gte", value: 90 } lt("price", 50); // { field: "price", op: "lt", value: 50 } lte("attempts", 3); // { field: "attempts", op: "lte", value: 3 } inList("status", ["active", "pending"]); // { field: "status", op: "in", value: [...] } notInList("role", ["banned", "deleted"]); between("price", 10, 100); // Combined gt + lt

String Filters

import { contains, startsWith, endsWith, matchesPattern, isEmpty, isNotEmpty, } from "@zudojs/database"; contains("name", "john"); // LIKE %john% startsWith("email", "admin@"); // LIKE admin@% endsWith("email", "@company.com"); // LIKE %@company.com matchesPattern("phone", "^\\+1"); // Regex match isEmpty("bio"); // IS NULL OR = "" isNotEmpty("bio"); // IS NOT NULL AND != ""

Date Filters

import { dateRange, dateOnly, timeOnly, timestamp, isBefore, isAfter, isBetween, } from "@zudojs/database"; dateRange("createdAt", startDate, endDate); dateOnly("birthDate", "2000-01-15"); isBefore("expiresAt", new Date()); isAfter("createdAt", lastWeek); isBetween("createdAt", startOfMonth, endOfMonth);

Logical Composition

import { and, or, notCondition } from "@zudojs/database"; const filter = and( equals("active", true), or( equals("role", "admin"), gte("permissionLevel", 5), ), notCondition(equals("banned", true)), );

Relational Filters

import { relational } from "@zudojs/database"; // Filter through relations const filter = relational("orders", gt("total", 100)); const nested = relational("orders.items", equals("category", "electronics"));
Tip: All filter functions return typed QueryCondition objects. They compose naturally with QueryBuilder and can be combined with and() / or() logical filters.

TRANSACTION MANAGER

TransactionManager provides managed transactions with automatic retry, rollback, and isolation level configuration.

interface TransactionOptions { readonly isolationLevel?: "read-uncommitted" | "read-committed" | "repeatable-read" | "serializable"; readonly timeout?: number; readonly maxRetries?: number; } class TransactionManager { constructor(client: DatabaseClient); execute<T>( fn: (tx: PrismaClient) => Promise<T>, options?: TransactionOptions, ): Promise<T>; savepoint<T>( name: string, fn: (tx: PrismaClient) => Promise<T>, ): Promise<T>; }

Example: Managed Transactions

import { TransactionManager } from "@zudojs/database"; const txManager = new TransactionManager(client); // Automatic retry on transient failures const result = await txManager.execute(async (tx) => { const user = await tx.user.update({ where: { id: userId }, data: { balance: { decrement: 50 } }, }); await tx.payment.create({ data: { userId, amount: 50, status: "completed" }, }); return user; }, { isolationLevel: "serializable", timeout: 10000, maxRetries: 2, }); // Savepoints for partial rollback await txManager.execute(async (tx) => { await tx.order.create({ data: orderData }); try { await txManager.savepoint("inventory-check", async (sp) => { await sp.inventory.update({ where: { id }, data: { stock: { decrement: 1 } } }); }); } catch { // Inventory update failed, but order is still created } });

UNIT OF WORK

DatabaseUnitOfWork tracks dirty entities across a transaction boundary and flushes all changes atomically.

class DatabaseUnitOfWork { constructor(client: DatabaseClient); registerNew(entity: unknown): void; registerDirty(entity: unknown): void; registerDeleted(entity: unknown): void; commit(): Promise<void>; rollback(): Promise<void>; clear(): void; hasChanges(): boolean; }

Example: Unit of Work

import { DatabaseUnitOfWork } from "@zudojs/database"; const uow = new DatabaseUnitOfWork(client); // Track entities uow.registerNew({ model: "order", data: { userId, total: 100 } }); uow.registerDirty({ model: "user", id: userId, data: { balance: { decrement: 100 } } }); uow.registerDeleted({ model: "cart", id: cartId }); // Flush all changes atomically if (uow.hasChanges()) { await uow.commit(); }

PAGINATION

Two strategies: offset-based for simple cases, cursor-based for large datasets and infinite scroll.

Offset-Based Pagination

interface PaginatedResult<T> { readonly data: T[]; readonly meta: { readonly page: number; readonly limit: number; readonly total: number; readonly totalPages: number; readonly hasNext: boolean; readonly hasPrev: boolean; }; }

Cursor-Based Pagination

interface CursorPaginatedResult<T> { readonly data: T[]; readonly meta: { readonly nextCursor?: string; readonly prevCursor?: string; readonly hasNext: boolean; readonly hasPrev: boolean; readonly limit: number; }; }

Example

// Offset pagination const page1 = await userRepo.paginate({ page: 1, limit: 20, where: { active: true }, orderBy: [{ field: "createdAt", direction: "desc" }], }); // page1.meta.totalPages → 5 // Cursor pagination const cursor1 = await userRepo.paginateCursor({ limit: 20, orderBy: [{ field: "createdAt", direction: "desc" }], }); const cursor2 = await userRepo.paginateCursor({ cursor: cursor1.meta.nextCursor, limit: 20, orderBy: [{ field: "createdAt", direction: "desc" }], });

MIGRATIONS

MigrationRunner manages versioned database migrations with advisory locks.

interface Migration { readonly version: string; readonly name: string; up(client: PrismaClient): Promise<void>; down(client: PrismaClient): Promise<void>; } class MigrationRunner { constructor(client: DatabaseClient, config?: MigrationConfig); run(): Promise<MigrationResult>; rollback(steps?: number): Promise<MigrationResult>; status(): Promise<MigrationStatus>; getHistory(): Promise<readonly MigrationRecord[]>; createTable(): Promise<void>; }

Example: Running Migrations

import { MigrationRunner } from "@zudojs/database"; const runner = new MigrationRunner(client, { migrations: [{ version: "001", name: "create-users", async up(prisma) { await prisma.executeRaw`CREATE TABLE users ( id TEXT PRIMARY KEY, name TEXT NOT NULL, email TEXT UNIQUE NOT NULL )`; }, async down(prisma) { await prisma.executeRaw`DROP TABLE users`; }, }], }); const status = await runner.status(); const result = await runner.run(); await runner.rollback(1);

SEEDS

SeedRunner manages idempotent seed execution with advisory locks and tracking.

interface Seed { readonly name: string; readonly dependencies?: string[]; run(client: PrismaClient): Promise<void>; } class SeedRunner { constructor(client: DatabaseClient, config?: SeedConfig); run(seedNames?: string[]): Promise<SeedResult>; status(): Promise<SeedStatus>; getHistory(): Promise<readonly SeedRecord[]>; reset(): Promise<void>; }

Example: Seeding

import { SeedRunner } from "@zudojs/database"; const seeder = new SeedRunner(client, { seeds: [ { name: "roles", async run(prisma) { await prisma.role.createMany({ data: [ { name: "admin", permissions: ["read", "write", "delete"] }, { name: "user", permissions: ["read"] }, ], }); }, }, { name: "admin-user", dependencies: ["roles"], async run(prisma) { await prisma.user.create({ data: { name: "Admin", email: "admin@example.com", role: "admin" }, }); }, }, ], }); await seeder.run();

ADVISORY LOCKS

DatabaseLockManager provides database-level advisory locks for coordinating single-execution tasks.

class DatabaseLockManager { constructor(client: DatabaseClient); acquireLock(lockName: string, timeout?: number): Promise<Lock>; tryLock(lockName: string): Promise<Lock | null>; releaseLock(lock: Lock): Promise<void>; withLock<T>(lockName: string, fn: () => Promise<T>, timeout?: number): Promise<T>; }

Example

import { DatabaseLockManager } from "@zudojs/database"; const lockManager = new DatabaseLockManager(client); // Ensure only one process runs this at a time await lockManager.withLock("daily-report", async () => { const report = await generateDailyReport(); await sendReport(report); }); // Explicit lock management const lock = await lockManager.acquireLock("data-sync", 30000); try { await syncData(); } finally { await lock.release(); }

IN-MEMORY CACHE

MemoryDatabaseCache provides TTL-based caching with getOrSet pattern and tag-based invalidation.

class MemoryDatabaseCache { constructor(config?: CacheConfig); get<T>(key: string): T | undefined; set<T>(key: string, value: T, ttl?: number, tags?: string[]): void; getOrSet<T>(key: string, factory: () => Promise<T>, ttl?: number): Promise<T>; delete(key: string): boolean; invalidateTag(tag: string): number; clear(): void; size(): number; has(key: string): boolean; }

Example

import { MemoryDatabaseCache } from "@zudojs/database"; const cache = new MemoryDatabaseCache({ defaultTTL: 30000 }); // Cache expensive query const users = await cache.getOrSet( "active-users", async () => userRepo.findMany({ where: { active: true } }), 60000, ["users", "list"], ); // Invalidate by tag await userRepo.update(id, { name: "New Name" }); cache.invalidateTag("users");

RELATIONS

Typed relation definitions for one-to-one, one-to-many, many-to-one, and many-to-many relationships.

type RelationType = "one-to-one" | "one-to-many" | "many-to-one" | "many-to-many"; interface RelationDefinition { readonly type: RelationType; readonly from: string; readonly to: string; readonly foreignKey?: string; readonly joinTable?: string; readonly through?: string; } class RelationRegistry { register(definition: RelationDefinition): void; get(from: string, to: string): RelationDefinition | undefined; getAll(model: string): readonly RelationDefinition[]; has(from: string, to: string): boolean; clear(): void; }

Example

import { RelationRegistry } from "@zudojs/database"; const relations = new RelationRegistry(); // One-to-many: User has many Posts relations.register({ type: "one-to-many", from: "User", to: "Post", foreignKey: "authorId" }); // Many-to-many: Post has many Tags relations.register({ type: "many-to-many", from: "Post", to: "Tag", joinTable: "PostTag" }); // One-to-one: User has one Profile relations.register({ type: "one-to-one", from: "User", to: "Profile", foreignKey: "userId" }); // Query const userRelations = relations.getAll("User");

ERROR HIERARCHY

All error types are defined in @zudojs/errors and re-exported by this package.

Error When Thrown
DatabaseErrorBase error for all database issues
ConnectionErrorConnection pool exhausted, timeout, or refused
QueryErrorInvalid query, constraint violation, or SQL syntax error
TransactionErrorTransaction commit/rollback failure or deadlock
MigrationErrorMigration execution or version conflict
LockErrorAdvisory lock acquisition timeout or failure
SeedErrorSeed execution failure or dependency cycle

Error Handling Pattern

import { isDatabaseError, ConnectionError, QueryError, TransactionError } from "@zudojs/database"; try { await userRepo.create(data); } catch (error) { if (isDatabaseError(error)) { if (error instanceof ConnectionError) { // Retry or fail gracefully } else if (error instanceof QueryError) { // Log invalid query } else if (error instanceof TransactionError) { // Handle deadlock } } }

FULL INTEGRATION EXAMPLE

Complete example: repository, query builder, transactions, pagination, and health monitoring.

import { createDatabase, BaseRepository, QueryBuilder, equals, gte, contains, TransactionManager, MemoryDatabaseCache, } from "@zudojs/database"; // 1. Get typed repository const orders = db.getRepository<Order>("order"); // 3. Graceful shutdown process.on("SIGTERM", async () => { await db.disconnect(); });
