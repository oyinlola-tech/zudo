@zudojs/rpc

Transport-agnostic remote procedure call infrastructure. Typed handlers, middleware pipelines, request/response lifecycle, metadata propagation, streaming, retry, timeout, and cancellation — all in one package.

RPC REMOTE PROCEDURE CLIENT SERVER

INSTALLATION

// npm npm install @zudojs/rpc // pnpm pnpm add @zudojs/rpc // yarn yarn add @zudojs/rpc
Peer Dependencies: @zudojs/rpc depends on @zudojs/errors, @zudojs/constants, @zudojs/types, and @zudojs/schema. All at version 0.0.1.

WHAT IT DOES

@zudojs/rpc provides a complete RPC abstraction layer:

  • → Procedure-based RPC with typed handlers and input/output generics
  • → Request/response lifecycle — typed request and response messages with unique IDs
  • → Metadata propagation — requestId, correlationId, traceId, tenantId, userId, deadline
  • → Middleware pipeline — composable middleware stack for auth, logging, validation
  • → Transport abstraction — swap underlying transport without changing handler code
  • → Streaming procedures — async iterable handlers for real-time data
  • → Retry with backoff — fixed, linear, and exponential backoff strategies
  • → Timeout and deadline support — configurable per-call and per-procedure
  • → Cancellation — AbortSignal-based cancellation throughout the pipeline
  • → 16 error classes — comprehensive RPC error hierarchy from @zudojs/errors
  • → Testing utilities — mock transport and test helpers

WHERE IT SITS

APPLICATION CODE (CQRS, Services, Handlers)
@zudojs/rpc — Procedures, Middleware, Dispatcher
TRANSPORT LAYER (HTTP, WebSocket, IPC)
EXTERNAL PLATFORM (Node.js, Edge, Serverless)

RPC sits between your application logic and the transport layer. Client sends requests through a transport, server receives and dispatches through middleware to registered procedures.

RPCProcedureRegistry

Method Signature Returns
register() register(procedure: RPCProcedure): void void. Throws RPCDuplicateProcedureError on duplicate.
get() get(name: string): RPCProcedure | undefined Procedure or undefined
has() has(name: string): boolean true if registered
require() require(name: string): RPCProcedure Procedure. Throws RPCProcedureNotFoundError if missing.
list() list(): readonly string[] Array of registered procedure names
unregister() unregister(name: string): boolean true if removed, false if not found
clear() clear(): void Removes all procedures

RPCProcedureRouter

Groups procedures by namespace. Same API as RPCProcedureRegistry plus returns RPCProcedure[] from list().

Example

import { createRPCProcedure, RPCProcedureRegistry } from "@zudojs/rpc"; interface GetUserInput { readonly id: string; } interface GetUserOutput { readonly id: string; readonly name: string; } const getUser = createRPCProcedure<GetUserInput, GetUserOutput>( "users.getUser", async (input, context) => { const user = await db.findUser(input.id); if (!user) throw new Error("User not found"); return { id: user.id, name: user.name }; }, { idempotent: true, timeout: 5000 }, ); const registry = new RPCProcedureRegistry(); registry.register(getUser); console.log(registry.list()); // ["users.getUser"]

CONTEXT

RPCContext

interface RPCContext { readonly request: RPCRequest; readonly metadata: RPCMetadata; readonly signal: AbortSignal; readonly state: Map<string, unknown>; get<T>(key: string): T | undefined; set<T>(key: string, value: T): void; }

createRPCContext()

function createRPCContext( request: RPCRequest, signal: AbortSignal, ): RPCContext;

Creates a frozen context with a state map for middleware-to-handler communication.

Example

const handler = async (input, context) => { // Access metadata console.log(context.metadata.requestId); console.log(context.metadata.tenantId); // Use state to share data between middleware context.set("user", { id: "123", role: "admin" }); const user = context.get<{ id: string }>("user"); // Check cancellation if (context.signal.aborted) { throw new Error("Request cancelled"); } return { result: "ok" }; };

MIDDLEWARE

RPCMiddleware

type RPCMiddleware = ( context: RPCContext, next: () => Promise<unknown>, ) => Promise<unknown>;

RPCMiddlewareStack

class RPCMiddlewareStack { constructor(middleware?: RPCMiddleware[]); async execute(context: RPCContext, handler: () => Promise<unknown>): Promise<unknown>; }

Example: Auth Middleware

import { RPCMiddlewareStack } from "@zudojs/rpc"; import type { RPCMiddleware } from "@zudojs/rpc"; const authMiddleware: RPCMiddleware = async (context, next) => { const token = context.metadata.userId; if (!token) { throw new Error("Unauthorized"); } return next(); }; const loggingMiddleware: RPCMiddleware = async (context, next) => { const start = Date.now(); const result = await next(); console.log(`[RPC] ${context.request.procedure} took ${Date.now() - start}ms`); return result; }; const stack = new RPCMiddlewareStack([authMiddleware, loggingMiddleware]);

DISPATCHER

RPCDispatcher

class RPCDispatcher { constructor( registry: { require(name: string): RPCProcedure }, middleware: RPCMiddlewareStack, ); async dispatch(request: RPCRequest): Promise<RPCResponse>; }

Looks up the procedure from the registry, creates context, runs middleware, and returns the response. Used internally by RPCServer.

SERVER

RPCServer

class RPCServer { constructor(registry?: RPCProcedureRegistry, middleware?: RPCMiddlewareStack); register(procedure: RPCProcedure): this; async handle(request: RPCRequest): Promise<RPCResponse>; getRegistry(): RPCProcedureRegistry; }

Example

import { RPCServer, createRPCProcedure, RPCMiddlewareStack } from "@zudojs/rpc"; const server = new RPCServer(); server.register(createRPCProcedure("users.list", async () => { return [{ id: "1", name: "Alice" }]; })); const response = await server.handle({ id: "req-1", procedure: "users.list", payload: {}, metadata: {}, timestamp: Date.now(), }); console.log(response.success); // true console.log(response.result); // [{ id: "1", name: "Alice" }]

CLIENT

RPCCallOptions

interface RPCCallOptions { readonly timeout?: number; readonly signal?: AbortSignal; readonly metadata?: Record<string, string | number | boolean | undefined>; }

RPCClient

class RPCClient { constructor(transport: RPCTransport); async call<TInput, TOutput>( procedure: string, input: TInput, options?: RPCCallOptions, ): Promise<TOutput>; }

Sends a request via the transport, races against timeout, and resolves with the result or throws on error.

Example

import { RPCClient } from "@zudojs/rpc"; const client = new RPCClient(myTransport); try { const user = await client.call<GetUserInput, GetUserOutput>( "users.getUser", { id: "123" }, { timeout: 5000 }, ); console.log(user.name); } catch (error) { console.error(error.message); }

import type { RPCTransport, RPCRequest, RPCResponse } from "@zudojs/rpc"; function createMemoryTransport( handler: (req: RPCRequest) => Promise<RPCResponse>, ): RPCTransport { return { async send(request) { return handler(request); }, }; } // Wire client → server via memory transport const transport = createMemoryTransport((req) => server.handle(req)); const client = new RPCClient(transport);

Error Handling Pattern

import { isRPCError, RPCTimeoutError, RPCProcedureNotFoundError, } from "@zudojs/rpc"; try { const result = await client.call("users.getUser", { id: "123" }); } catch (error) { if (isRPCError(error)) { if (error instanceof RPCTimeoutError) { // Retry or fail gracefully } else if (error instanceof RPCProcedureNotFoundError) { // Procedure doesn't exist } } }

FULL INTEGRATION EXAMPLE

Complete working example: create procedures, server, middleware, transport, and client.

import { RPCServer, RPCClient, RPCMiddlewareStack, createRPCProcedure, createRPCMetadata, retry, RPCTimeoutError, } from "@zudojs/rpc"; import type { RPCMiddleware, RPCTransport, RPCRequest, RPCResponse, } from "@zudojs/rpc"; // 1. Define typed procedures interface CreateUserInput { readonly name: string; readonly email: string; } interface CreateUserOutput { readonly id: string; readonly name: string; } const createUser = createRPCProcedure<CreateUserInput, CreateUserOutput>( "users.createUser", async (input, context) => { console.log(`Creating user: ${input.name}`); return { id: "usr_123", name: input.name }; }, { idempotent: false, description: "Create a new user" }, ); // 2. Create middleware const authMiddleware: RPCMiddleware = async (context, next) => { if (!context.metadata.userId) { throw new Error("Unauthorized"); } return next(); }; const loggingMiddleware: RPCMiddleware = async (context, next) => { const start = Date.now(); const result = await next(); const duration = Date.now() - start; console.log(`[RPC] ${context.request.procedure} — ${duration}ms`); return result; }; // 3. Create server with middleware const stack = new RPCMiddlewareStack([loggingMiddleware, authMiddleware]); const server = new RPCServer(undefined, stack); server.register(createUser); // 4. Create transport (memory for example) const memoryTransport: RPCTransport = { async send(request: RPCRequest): Promise<RPCResponse> { return server.handle(request); }, }; // 5. Create client const client = new RPCClient(memoryTransport); // 6. Call with metadata and retry const user = await retry( () => client.call<CreateUserInput, CreateUserOutput>( "users.createUser", { name: "Alice", email: "alice@example.com" }, { timeout: 5000, metadata: createRPCMetadata({ requestId: "req_001", userId: "usr_admin", tenantId: "tenant_acme", }), }, ), { attempts: 3, delay: 500, backoff: "exponential" }, ); console.log(user); // { id: "usr_123", name: "Alice" }
