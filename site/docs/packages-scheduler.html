@zudojs/scheduler

Time and recurring execution engine for the Zudojs framework. Provides job definitions, schedules, triggers, priority queue, cron support, retry strategies, and execution history.

SCHEDULER CRON JOBS SCHEDULES TIMER

INSTALLATION

// npm npm install @zudojs/scheduler // pnpm pnpm add @zudojs/scheduler // yarn yarn add @zudojs/scheduler
Peer Dependencies: @zudojs/scheduler depends on @zudojs/errors, @zudojs/constants, and @zudojs/types. All at version 0.1.0.

WHAT IT DOES

@zudojs/scheduler is the time-based execution engine for the Zudojs ecosystem. It defines:

  • → Cron-like scheduling with once, delay, interval, and cron expression support
  • → Job definitions with typed handlers, timeouts, and retry policies
  • → Schedule management — pause, resume, and cancel schedules at runtime
  • → Overlap policies — allow, skip, queue, or replace concurrent executions
  • → Misfire policies — skip, run-once, or catch-up when executions are missed
  • → Retry with backoff — fixed, linear, or exponential strategies with jitter
  • → Priority queue for ordered execution scheduling
  • → Abort signal support for graceful job cancellation
  • → Execution history tracking with configurable retention
  • → 17 error classes from @zudojs/errors for precise error handling
  • → Test utilities for deterministic clock mocking and scheduler testing

APPLICATION LAYER (Modules, Services)

The Scheduler sits at the boundary between application logic and the event loop. It consumes job definitions from modules, manages schedules through a priority queue, and executes jobs via the executor with clock-driven precision.

TRIGGERS

Triggers calculate the next execution time for a schedule.

Interface: Trigger

interface Trigger { next(after: Date): Date | null; }

Class: DateTrigger

Fires once at a specific date. Returns null if the date has already passed.

class DateTrigger implements Trigger { constructor(date: Date); next(after: Date): Date | null; } const trigger = new DateTrigger(new Date("2026-06-15T09:00:00Z")); trigger.next(new Date()); // Date(2026-06-15T09:00:00Z) or null

Class: DelayTrigger

Fires once after a fixed delay from the given date.

class DelayTrigger implements Trigger { constructor(delayMs: number); next(after: Date): Date; } const trigger = new DelayTrigger(5_000); // 5 seconds trigger.next(new Date()); // now + 5s

Class: IntervalTrigger

Fires at fixed intervals indefinitely.

class IntervalTrigger implements Trigger { constructor(intervalMs: number); next(after: Date): Date; } const trigger = new IntervalTrigger(60_000); // Every minute trigger.next(new Date()); // now + 60s

Class: CronTrigger

Fires according to a cron expression with optional timezone support.

class CronTrigger implements Trigger { constructor(expression: string, timezone?: string); next(after: Date): Date | null; } // Run every day at 2am UTC const trigger = new CronTrigger("0 2 * * *"); // Run every Monday at 9am in New York const nycTrigger = new CronTrigger("0 9 * * 1", "America/New_York");

JOB EXECUTOR

Executes job handlers with timeout support and abort signal handling.

Class: JobExecutor

class JobExecutor { constructor(clock: Clock); async execute( job: JobDefinition, executionId: string, scheduledAt: Date, attempt: number, signal: AbortSignal, ): Promise<JobExecutionResult>; }

Execution Flow

  1. Creates a frozen JobContext with job metadata, timestamps, and the abort signal
  2. Wraps the handler call with a timeout using setTimeout
  3. On success, returns { success: true }
  4. On timeout, throws SchedulerJobTimeoutError
  5. On abort, throws SchedulerJobCancelledError
  6. On other errors, wraps in SchedulerJobExecutionError

Example

import { JobExecutor, createSystemClock } from "@zudojs/scheduler"; const executor = new JobExecutor(createSystemClock()); const signal = new AbortController().signal; const result = await executor.execute( job, "exec-001", new Date(), 1, signal, ); console.log(result.success); // true

PRIORITY QUEUE

Min-heap priority queue for ordered schedule execution. Orders by nextRunAt timestamp.

Class: PriorityQueue

Method Signature Returns
enqueue() enqueue(schedule: Schedule): void void. Inserts into heap. O(log n).
dequeue() dequeue(): Schedule | undefined Removes and returns earliest schedule. O(log n).
peek() peek(): Schedule | undefined Returns earliest without removing. O(1).
remove() remove(id: string): boolean Removes schedule by ID. O(n).
size get size(): number Number of schedules in queue
isEmpty get isEmpty(): boolean true if queue is empty
clear() clear(): void Removes all schedules
Min-Heap: The queue uses a binary min-heap ordered by nextRunAt. The schedule with the earliest next execution time is always at the top.

SCHEDULER

The main entry point. Manages job definitions, scheduling, and the tick loop.

Class: Scheduler

Method Signature Description
start() start(): void Starts the scheduler tick loop
stop() stop(): void Stops the scheduler and clears the timer
define() define(job: JobDefinition): void Registers a job definition
after() after(delay: string, jobId: string): ScheduleHandle Schedules a job to run once after a delay
at() at(date: Date, jobId: string): ScheduleHandle Schedules a job to run at a specific date
every() every(interval: string, jobId: string): ScheduleHandle Schedules a job at a fixed interval
cron() cron(expression: string, jobId: string): ScheduleHandle Schedules a job using a cron expression

Constructor

import { Scheduler, JobRegistry, JobExecutor, PriorityQueue, createSystemClock } from "@zudojs/scheduler"; // Default (all internal) const scheduler = new Scheduler(); // Custom dependencies const clock = createSystemClock(); const scheduler = new Scheduler( new JobRegistry(), new JobExecutor(clock), new PriorityQueue(), clock, );

Scheduling Flow

  1. Call define() to register job definitions
  2. Use after(), at(), every(), or cron() to create schedules
  3. Each method creates a Trigger and inserts the schedule into the PriorityQueue
  4. Returns a ScheduleHandle for control (pause, resume, cancel)
  5. Call start() to begin the tick loop

Tick Loop

  1. Peek at the next schedule in the priority queue
  2. If nextRunAt is in the future, calculate delay and set timer
  3. If due, dequeue and execute via JobExecutor
  4. Repeat until the queue is empty or scheduler is stopped
  5. Timer delay is clamped to MAX_TIMER_DELAY (2^31 - 1 ms)

Example

import { Scheduler } from "@zudojs/scheduler"; const scheduler = new Scheduler(); // Define a job scheduler.define({ id: "cleanup", name: "Cleanup expired sessions", handler: async (ctx) => { console.log(`Running ${ctx.jobId} (attempt ${ctx.attempt})`); }, }); // Schedule it const handle = scheduler.cron("0 2 * * *", "cleanup"); // Start scheduler.start(); // Pause later await handle.pause(); // Resume await handle.resume(); // Stop scheduler.stop();

FULL INTEGRATION EXAMPLE

Complete working example: create scheduler, define jobs, schedule with cron/delay/interval, handle execution, use ScheduleHandle, retry with backoff, and graceful shutdown.

import { Scheduler, createJobDefinition, createSystemClock, } from "@zudojs/scheduler"; // 1. Create scheduler const clock = createSystemClock(); const scheduler = new Scheduler(undefined, undefined, undefined, clock); // 2. Define jobs scheduler.define(createJobDefinition( "cleanup", "Cleanup expired sessions", async (ctx) => { console.log(`[cleanup] Execution ${ctx.executionId}`); console.log(`[cleanup] Scheduled at ${ctx.scheduledAt.toISOString()}`); console.log(`[cleanup] Attempt ${ctx.attempt}`); // Check abort signal if (ctx.signal.aborted) { console.log("[cleanup] Cancelled"); return; } await deleteExpiredSessions(); console.log("[cleanup] Done"); }, { timeout: 15_000, retry: { attempts: 3, strategy: "exponential", delay: 1_000, maxDelay: 30_000, jitter: true, }, overlap: "skip", }, )); scheduler.define(createJobDefinition( "report", "Generate daily report", async (ctx) => { console.log(`[report] Generating report...`); await generateDailyReport(); }, )); scheduler.define(createJobDefinition( "health-check", "Health check ping", async (ctx) => { console.log(`[health-check] Pinging services...`); }, )); // 3. Schedule jobs // Run cleanup every day at 2am const cleanupHandle = scheduler.cron("0 2 * * *", "cleanup"); console.log(`Cleanup schedule: ${cleanupHandle.id}`); // Run report every Monday at 9am scheduler.cron("0 9 * * 1", "report"); // Run health check every 30 seconds const healthHandle = scheduler.every("30s", "health-check"); // Run a one-time task after 5 minutes scheduler.after("5m", "health-check"); // Run at a specific date scheduler.at(new Date("2026-06-15T09:00:00Z"), "report"); // 4. Control schedules await cleanupHandle.pause(); console.log(`Cleanup state: ${cleanupHandle.state}`); // "paused" await cleanupHandle.resume(); console.log(`Cleanup state: ${cleanupHandle.state}`); // "active" // 5. Start the scheduler scheduler.start(); console.log("Scheduler started"); // 6. Graceful shutdown process.on("SIGTERM", async () => { console.log("Shutting down scheduler..."); await healthHandle.cancel(); scheduler.stop(); console.log("Scheduler stopped"); process.exit(0); });
