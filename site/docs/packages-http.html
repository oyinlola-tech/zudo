@zudojs/http

HTTP primitives, request/response handling, routing, middleware pipeline, HTTP client, headers management, CORS, CSP, security headers, caching, streaming, validation, content negotiation, multipart, cookies, proxy, compression, HSTS, and more.

HTTP SERVER ROUTING MIDDLEWARE

INSTALLATION

// npm npm install @zudojs/http // pnpm pnpm add @zudojs/http // yarn yarn add @zudojs/http
Peer Dependencies: @zudojs/http depends on @zudojs/core, @zudojs/errors, @zudojs/logger, and @zudojs/security. Install them if not already present.

WHAT IT DOES

@zudojs/http is the complete HTTP layer for the Zudo framework. It provides:

  • → HTTP server — create, start, stop, restart with lifecycle management
  • → Request/response handling — typed HTTPRequest, HTTPResponse, HTTPContext
  • → Routing — tree-based route matching with parameters, wildcards, and compilation
  • → Middleware pipeline — composable middleware with timing, logging, security, CORS, static file serving
  • → HTTP client — request/response with interceptors, retry, abort, and error normalization
  • → Headers management — typed HTTPHeaders class with constants, authorization helpers, cache control, ETag, date, forwarded, and security headers
  • → CORS — policy-based cross-origin resource sharing with origin matching
  • → CSP — Content Security Policy directives, nonce generation, and nonce sources
  • → Security headers — HSTS, X-Frame-Options, Referrer-Policy, Permissions-Policy, and more
  • → Caching — Cache-Control parsing, formatting, freshness calculation, response storable checks
  • → Streaming — read, pipe, copy, consume, progress tracking, drain waiting
  • → Validation — HTTP method, header name, URL, status code, content type, content length validators
  • → Content negotiation — content type, language, and encoding negotiation
  • → Multipart — file upload parsing with field handling
  • → Cookies — CookieCollection with options, parsing, and value management
  • → Proxy — trust proxy configuration, client IP resolution, protocol detection
  • → Compression — encoding negotiation and compression decisions
  • → HSTS — HTTP Strict Transport Security parsing and formatting
  • → Keep-alive — connection keep-alive configuration and defaults
  • → Conditional requests — ETag and If-None-Match handling
  • → Interceptors — request/response/error interceptors with priority ordering
  • → Content disposition — inline and attachment disposition types with parameters
  • → Query method — convenience method for GET requests with query string building

FULL INTEGRATION EXAMPLE

Complete working example: HTTP server with routes, middleware, CORS, and security headers.

import { createHttpServer, startServer, stopServer, createRouteDispatcher, executePipeline, createSecurityHeaders, createRecommendedSecurityHeaders, generateCSPNonce, createCacheControl, formatCacheControl, parseRequestBody, getClientIp, compileTrustProxy, HTTPMethod, HTTPHeaders, HTTPContext, } from "@zudojs/http"; // 1. Configure trust proxy const trust = compileTrustProxy(1); // 2. Security headers middleware const securityMiddleware = async (ctx, next) => { const headers = createRecommendedSecurityHeaders(); for (const [key, value] of Object.entries(headers)) { ctx.response.header(key, value); } await next(); }; // 3. Logging middleware const loggingMiddleware = async (ctx, next) => { const start = Date.now(); const ip = getClientIp(ctx.request, trust); console.log(`→ ${ctx.method} ${ctx.url.pathname} from ${ip}`); await next(); const duration = Date.now() - start; console.log(`← ${ctx.response.statusCode} (${duration}ms)`); }; // 4. Define routes const routes = [ { method: "GET" as HTTPMethod, path: "/api/users", handler: async (ctx) => { const cache = createCacheControl({ public: true, maxAge: 60 }); ctx.response .header("Cache-Control", formatCacheControl(cache)) .json({ users: [{ id: 1, name: "Alice" }] }); }, }, { method: "POST" as HTTPMethod, path: "/api/users", handler: async (ctx) => { const body = await parseRequestBody(ctx.request); ctx.response.status(201).json({ id: 2, ...body }); }, }, { method: "GET" as HTTPMethod, path: "/api/health", handler: async (ctx) => { ctx.response.json({ status: "ok", timestamp: new Date().toISOString() }); }, }, ]; // 5. Create dispatcher const dispatcher = createRouteDispatcher(routes); // 6. Create and start server const server = createHttpServer({ port: 3000, host: "0.0.0.0", trustProxy: trust, timeout: 30000, }); server.use(securityMiddleware); server.use(loggingMiddleware); server.use(dispatcher); await startServer(server); console.log("Server listening on http://localhost:3000"); // Graceful shutdown process.on("SIGTERM", async () => { await stopServer(server); process.exit(0); });
