@zudojs/types

Runtime type guards, advanced utility types, safe type converters, and injectable Clock/Random interfaces. Zero runtime dependencies. Fully tree-shakeable.

TYPES TYPE GUARDS UTILITIES CONVERTERS RUNTIME

INSTALLATION

// npm npm install @zudojs/types // pnpm pnpm add @zudojs/types // yarn yarn add @zudojs/types
Zero Runtime Dependencies: @zudojs/types has no dependencies at all. It is a pure TypeScript package — type guards are the only runtime code, and they are fully tree-shakeable.

WHAT IT DOES

@zudojs/types is the shared type utilities layer for the Zudojs ecosystem. It provides:

  • → 14 runtime type guards for common JavaScript values (isPlainObject, isEmail, isUrl, isUuid, isDate, etc.)
  • → 19 advanced TypeScript utility types (DeepReadonly, DeepPartial, Prettify, NestedKeyOf, Maybe, etc.)
  • → 7 safe type converters with fallback values (safeJsonParse, toNumber, toBoolean, toArray, etc.)
  • → String case conversion functions (snakeToCamel, camelToSnake, kebabToCamel, camelToKebab)
  • → Map/Object conversion utilities (mapToObject, objectToMap)
  • → Injectable Clock and Random interfaces for testability
  • → Deterministic FixedClock and SeededRandom for testing
  • → Zero runtime dependencies — pure TypeScript, fully tree-shakeable

DEPENDENCIES

Zero Runtime Dependencies: @zudojs/types has no runtime dependencies whatsoever. The only dev dependencies are TypeScript, Vitest, and @types/node for type definitions.

TYPE GUARDS

14 runtime type guard functions for validating common JavaScript values. Each returns a TypeScript predicate type for automatic narrowing.

isPlainObject

function isPlainObject( value: unknown, ): value is Record<string, unknown>

Check if a value is a plain object (not an array, null, or class instance).

isNonNullObject

function isNonNullObject( value: unknown, ): value is Record<string, unknown>

Check if a value is a non-null object (includes arrays, class instances, etc.).

isNonEmptyString

function isNonEmptyString(value: unknown): value is string

Check if a value is a string with length > 0.

isPositiveNumber

function isPositiveNumber(value: unknown): value is number

Check if a value is a number > 0 and not NaN.

isInteger

function isInteger(value: unknown): value is number

Check if a value is a valid integer.

isDate

function isDate(value: unknown): value is Date

Check if a value is a valid Date object (not Invalid Date).

isUrl

function isUrl(value: unknown): value is string

Check if a value is a valid HTTP or HTTPS URL string.

isEmail

function isEmail(value: unknown): value is string

Check if a value matches a standard email pattern.

isUuid

function isUuid(value: unknown): value is string

Check if a value is a valid UUID v4 string.

isIsoDateString

function isIsoDateString(value: unknown): value is string

Check if a value is a valid ISO 8601 date string.

isArrayOfType

function isArrayOfType<T>( value: unknown, guard: (item: unknown) is T, ): value is T[]

Check if a value is an array where every element passes a type guard.

isDefined

function isDefined<T>(value: T | null | undefined): value is T

Check if a value is not null or undefined. Ideal for array.filter(isDefined).

isFunction

function isFunction( value: unknown, ): value is (...args: unknown[]) => unknown

Check if a value is a function.

isPromise

function isPromise(value: unknown): value is Promise<unknown>

Check if a value is a Promise (instanceof or thenable).

UTILITY TYPES

19 advanced TypeScript utility types for deep transformations, path extraction, and common patterns.

DeepReadonly

type DeepReadonly<T> = T extends (infer U)[] ? ReadonlyArray<DeepReadonly<U>> : T extends Map<infer K, infer V> ? ReadonlyMap<DeepReadonly<K>, DeepReadonly<V>> : T extends Set<infer U> ? ReadonlySet<DeepReadonly<U>> : T extends object ? { readonly [K in keyof T]: DeepReadonly<T[K]> } : T;

Make all properties deeply readonly. Handles arrays, Maps, Sets, and nested objects recursively.

DeepPartial

type DeepPartial<T> = T extends (infer U)[] ? DeepPartial<U>[] : T extends Map<infer K, infer V> ? Map<DeepPartial<K>, DeepPartial<V>> : T extends Set<infer U> ? Set<DeepPartial<U>> : T extends object ? { [K in keyof T]?: DeepPartial<T[K]> } : T;

Make all properties deeply optional. Useful for partial config objects.

DeepRequired

type DeepRequired<T> = T extends (infer U)[] ? DeepRequired<U>[] : T extends Map<infer K, infer V> ? Map<DeepRequired<K>, DeepRequired<V>> : T extends Set<infer U> ? Set<DeepRequired<U>> : T extends object ? { [K in keyof T]-?: DeepRequired<T[K]> } : T;

Make all properties deeply required. Inverse of DeepPartial.

Prettify

type Prettify<T> = { [K in keyof T]: T[K] } & {};

Flatten nested object types into a single level for better IDE hover display.

StringKeysOf / NumberKeysOf

type StringKeysOf<T> = Extract<keyof T, string>; type NumberKeysOf<T> = Extract<keyof T, number>;

Extract only string or number keys from a type.

PartialExcept / RequiredExcept

type PartialExcept<T, K extends keyof T> = Partial<Omit<T, K>> & Pick<T, K>; type RequiredExcept<T, K extends keyof T> = Required<Omit<T, K>> & Pick<T, K>;

Make all properties optional except specific keys (or all required except specific keys).

OptionalKeys / RequireKeys

type OptionalKeys<T, K extends keyof T> = Omit<T, K> & Partial<Pick<T, K>>; type RequireKeys<T, K extends keyof T> = Omit<T, K> & Required<Pick<T, K>>;

Make specific keys optional or required while keeping the rest unchanged.

AsyncReturnType

type AsyncReturnType< T extends (...args: unknown[]) => Promise<unknown>, > = T extends (...args: unknown[]) => Promise<infer R> ? R : never;

Extract the resolved type of an async function's return value.

Nullable / Undefinable / Maybe / MaybePromise

type Nullable<T> = T | null; type Undefinable<T> = T | undefined; type Maybe<T> = T | null | undefined; type MaybePromise<T> = T | Promise<T>;

Convenience types for nullable, undefinable, maybe-null-undefined, and sync-or-async values.

NestedKeyOf / NestedValueOf

type NestedKeyOf<T> = T extends object ? { [K in StringKeysOf<T>]: K | `${K}.${NestedKeyOf<T[K]>}`; }[StringKeysOf<T>] : never; type NestedValueOf< T, P extends string, > = P extends `${infer Head}.${infer Tail}` ? Head extends keyof T ? NestedValueOf<T[Head], Tail> : never : P extends keyof T ? T[P] : never;

Extract all nested property paths as dot-notation strings and resolve the type at any path.

OmitByValue / PickByValue

type OmitByValue<T, ValueType> = Pick< T, { [K in keyof T]: T[K] extends ValueType ? never : K }[keyof T] >; type PickByValue<T, ValueType> = Pick< T, { [K in keyof T]: T[K] extends ValueType ? K : never }[keyof T] >;

Omit or pick properties by their value type instead of by key name.

TYPE CONVERTERS

Safe type conversion functions with fallback values. Never throw — always return the fallback on failure.

safeJsonParse

function safeJsonParse<T>(json: string, fallback: T): T

Safely parse JSON with a fallback value on failure.

toString

function toString(value: unknown, fallback = ""): string

Convert any value to a string. Handles null, undefined, numbers, booleans, and objects (via JSON.stringify).

toNumber

function toNumber(value: unknown, fallback = NaN): number

Convert any value to a number. Returns fallback if conversion produces NaN.

toBoolean

function toBoolean(value: unknown, fallback = false): boolean

Convert any value to a boolean. Recognizes "true", "1", "yes" as true; "false", "0", "no", "" as false.

toArray

function toArray<T>(value: T | T[]): T[]

Wrap a value in an array if it isn't already one.

mapToObject

function mapToObject<K extends string | number | symbol, V>( map: Map<K, V>, ): Record<K, V>

Convert a Map to a plain object.

objectToMap

function objectToMap<K extends string | number | symbol, V>( obj: Record<K, V>, ): Map<K, V>

Convert a plain object to a Map.

RUNTIME

Injectable Clock and Random interfaces for testable code. Depend on interfaces, not on Date.now() or Math.random().

Clock

interface Clock { now(): number; }

Returns the current time in milliseconds since the Unix epoch.

ClockSeconds

interface ClockSeconds { nowSeconds(): number; }

Returns the current time in seconds since the Unix epoch.

Random

interface Random { /** Returns a random UUID v4 string. */ uuid(): string; /** Returns a random integer in [0, max). */ int(max: number): number; /** Returns a random alphanumeric string of the given length. */ string(length: number): string; /** Returns a random string of the given length from the given alphabet. */ custom(length: number, alphabet: string): string; }

Cryptographically-secure random value generation interface.

SYSTEM IMPLEMENTATIONS

Production-ready implementations backed by real system APIs. Use these as defaults in your application code.

systemClock

const systemClock: Clock = { now: (): number => Date.now(), };

Default Clock backed by Date.now().

systemClockSeconds

const systemClockSeconds: ClockSeconds = { nowSeconds(): number { return Math.floor(Date.now() / 1000); }, };

Default ClockSeconds backed by Math.floor(Date.now() / 1000).

systemRandom

const systemRandom: Random = { uuid(): string { return globalThis.crypto.randomUUID(); }, int(max: number): number { const buf = new Uint32Array(1); globalThis.crypto.getRandomValues(buf); return buf[0]! % max; }, string(length: number): string { /* ... */ }, custom(length: number, alphabet: string): string { /* ... */ }, };

Default Random backed by globalThis.crypto (or node:crypto fallback).

TEST IMPLEMENTATIONS

Deterministic implementations for testing. Import from @zudojs/types directly.

FixedClock

class FixedClock implements Clock { private current: number; constructor(initial: number = 0) { this.current = initial; } now(): number { return this.current; } set(time: number): void { this.current = time; } advance(deltaMs: number): void { this.current += deltaMs; } }

Deterministic clock for tests. Set exact time or advance by delta.

SeededRandom

class SeededRandom implements Random { private state: number; constructor(seed: number = 1) { this.state = seed; } uuid(): string { const hex = this.state.toString(16).padStart(8, "0"); this.state = (this.state * 1103515245 + 12345) & 0x7fffffff; return `${hex}-...`; } int(max: number): number { this.state = (this.state * 1103515245 + 12345) & 0x7fffffff; return this.state % max; } string(length: number): string { /* ... */ } custom(length: number, alphabet: string): string { /* ... */ } }

Deterministic PRNG for tests. Same seed always produces the same sequence.

FULL INTEGRATION EXAMPLE

Complete example: validate data with type guards, use utility types for immutability, convert safely, and inject Clock/Random for testability.

import { // Type guards isPlainObject, isNonEmptyString, isEmail, isUrl, isDate, isDefined, // Utility types type DeepReadonly, type Maybe, type NestedKeyOf, // Converters safeJsonParse, toNumber, toBoolean, snakeToCamel, camelToSnake, // Runtime type Clock, type Random, systemClock, systemRandom, FixedClock, SeededRandom, } from "@zudojs/types"; // --- 1. Type Guards: Validate incoming data --- interface UserInput { name: string; email: string; website?: string; age: number; } function validateUserInput(raw: unknown): UserInput | null { if (!isPlainObject(raw)) return null; const name = raw.name; const email = raw.email; const website = raw.website; const age = raw.age; if (!isNonEmptyString(name)) return null; if (!isEmail(email)) return null; if (website !== undefined && !isUrl(website)) return null; if (!toNumber(age)) return null; return { name, email, website: website as string | undefined, age: toNumber(age), }; } // --- 2. Utility Types: Deep immutability --- type AppConfig = { database: { host: string; port: number }; features: string[]; }; type FrozenConfig = DeepReadonly<AppConfig>; const config: FrozenConfig = { database: { host: "localhost", port: 5432 }, features: ["auth", "logging"], }; // config.database.port = 3306; // Type error! // --- 3. Converters: Safe parsing --- const rawJson = '{"timeout": "30", "enabled": "true"}'; const parsed = safeJsonParse(rawJson, {}); if (isPlainObject(parsed)) { const timeout = toNumber(parsed.timeout, 10); const enabled = toBoolean(parsed.enabled, false); console.log({ timeout, enabled }); // { timeout: 30, enabled: true } } // --- 4. String conversion --- const dbField = camelToSnake("createdAt"); // "created_at" const jsProp = snakeToCamel("user_name"); // "userName" const cssClass = camelToKebab("primaryButton"); // "primary-button" const methodName = kebabToCamel("get-user-data"); // "getUserData" // --- 5. Clock/Random: Testable code --- function createSessionToken( clock: Clock = systemClock, random: Random = systemRandom, ): string { const ts = clock.now(); const id = random.uuid(); return `session_${ts}_${id}`; } // Production: uses systemClock + systemRandom const token = createSessionToken(); // Test: deterministic output const clock = new FixedClock(1700000000000); const random = new SeededRandom(42); const testToken = createSessionToken(clock, random); // Always: "session_1700000000000_..." // --- 6. Array filtering with isDefined --- const items: (string | null)[] = ["a", null, "b", null, "c"]; const filtered = items.filter(isDefined); // filtered: string[] = ["a", "b", "c"] // --- 7. Nested path types --- type Settings = { app: { name: string; debug: boolean }; db: { host: string }; }; type SettingsPath = NestedKeyOf<Settings>; // "app" | "app.name" | "app.debug" | "db" | "db.host"
