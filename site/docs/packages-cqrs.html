@zudojs/cqrs

Command Query Responsibility Segregation — separate read and write models with typed handlers.

CQRS COMMANDS QUERIES

OVERVIEW

@zudojs/cqrs implements the Command Query Responsibility Segregation pattern. Write operations (commands) and read operations (queries) are handled by separate pipelines with their own buses, handlers, middleware, and result types.

Architecture

// Two parallel pipelines // // Command Pipeline: // Command → Middleware → CommandHandler → CommandResult // // Query Pipeline: // Query → Middleware → QueryHandler → QueryResult // // Event Extensions: // CqrsEvent → EventBus → CqrsEventHandler → EventResult

INSTALLATION

npm install @zudojs/cqrs // Import everything import { CommandBus, QueryBus, createCommandBus } from "@zudojs/cqrs"; // Import specific submodules import { Command, CommandHandler } from "@zudojs/cqrs"; import { Query, QueryHandler } from "@zudojs/cqrs"; import { timingMiddleware } from "@zudojs/cqrs";

COMMANDS

Commands represent write operations that mutate application state.

Creating Commands

// Option 1: Simple factory function (recommended) import { createCommand } from "@zudojs/cqrs"; const cmd = createCommand("CreateUser", { name: "Alice", email: "alice@example.com", }); // → { type: "CreateUser", name: "Alice", email: "alice@example.com" } // Option 2: Abstract class import { Command } from "@zudojs/cqrs"; class CreateUserCommand extends Command<"CreateUser"> { readonly type = "CreateUser" as const; constructor( readonly name: string, readonly email: string, ) { super("CreateUser"); } } // Option 3: Type-safe utility import { CommandOf } from "@zudojs/cqrs"; type CreateUser = CommandOf<"CreateUser", { name: string; email: string }>;

Command Interface

interface Command<TType extends string = string> { readonly type: TType; }

QUERIES

Queries represent read operations that return data without mutation.

Creating Queries

// Option 1: Simple factory function (recommended) import { createQuery } from "@zudojs/cqrs"; const q = createQuery("GetUser", { userId: "usr_123" }); // → { type: "GetUser", userId: "usr_123" } // Option 2: Abstract class import { Query } from "@zudojs/cqrs"; class GetUserQuery extends Query<"GetUser"> { readonly type = "GetUser" as const; constructor(readonly userId: string) { super("GetUser"); } } // Option 3: Type-safe utility import { QueryOf } from "@zudojs/cqrs"; type GetUser = QueryOf<"GetUser", { userId: string }>;

Query Interface

interface Query<TType extends string = string> { readonly type: TType; }

HANDLERS

Handlers contain the business logic. Two styles: class-based (abstract class) or function-based (factory).

Command Handlers

// Class-based (recommended for complex logic) import { CommandHandler } from "@zudojs/cqrs"; class CreateUserHandler extends CommandHandler<CreateUserCommand, User> { readonly commandType = "CreateUser"; async execute(command: CreateUserCommand): Promise<User> { return this.repo.CREATE({ name: command.name, email: command.email }); } } // Function-based (recommended for simple logic) import { createCommandHandler } from "@zudojs/cqrs"; const handler = createCommandHandler("CreateUser", async (cmd) => { return repo.CREATE({ name: cmd.name, email: cmd.email }); });

Query Handlers

// Class-based import { QueryHandler } from "@zudojs/cqrs"; class GetUserHandler extends QueryHandler<GetUserQuery, User> { readonly queryType = "GetUser"; async execute(query: GetUserQuery): Promise<User> { return this.repo.findById(query.userId); } } // Function-based import { createQueryHandler } from "@zudojs/cqrs"; const handler = createQueryHandler("GetUser", async (q) => { return repo.findById(q.userId); });

Handler Type Guards

import { isCommandHandler, isQueryHandler, isCommandHandlerLike, isQueryHandlerLike } from "@zudojs/cqrs"; isCommandHandler(handler) // true if CommandHandler instance isQueryHandler(handler) // true if QueryHandler instance isCommandHandlerLike(fn) // true if function or object with execute() isQueryHandlerLike(fn) // true if function or object with execute()

BUSES

The CommandBus and QueryBus route requests to their registered handlers through a middleware pipeline.

CommandBus

import { createCommandBus } from "@zudojs/cqrs"; const bus = createCommandBus({ middleware: [timingMiddleware(), errorMiddleware()], contextFactory: () => ({ userId: "usr_123" }), }); // Register handlers bus.register("CreateUser", createUserHandler); bus.registerMany([ { commandType: "DeleteUser", handler: deleteUserHandler }, ]); // Execute a command const result = await bus.execute(createCommand("CreateUser", { name: "Alice" })); // Query methods bus.has("CreateUser") // boolean bus.size() // number of registered handlers bus.getCommandTypes() // string[] bus.clear() // remove all handlers

QueryBus

import { createQueryBus } from "@zudojs/cqrs"; const bus = createQueryBus({ middleware: [timingMiddleware()], }); bus.register("GetUser", getUserHandler); const user = await bus.execute(createQuery("GetUser", { userId: "usr_123" }));

RESULTS

Structured result types with status, timing, and metadata.

CommandResult

interface CommandResult<TResult, TCommand> { readonly status: "success" | "failure"; readonly result: TResult; readonly commandType: string; readonly executedAt: Date; readonly durationMs?: number; readonly metadata?: Readonly<Record<string, unknown>>; } // Create results import { createCommandResult, createFailedCommandResult } from "@zudojs/cqrs"; const ok = createCommandResult(user, { command: cmd, durationMs: 42 }); const fail = createFailedCommandResult(null, { command: cmd }); // Check status import { isSuccessfulCommandResult, unwrapCommandResult } from "@zudojs/cqrs"; isSuccessfulCommandResult(ok) // true unwrapCommandResult(ok) // the user object

QueryResult

interface QueryResult<TResult, TQuery> { readonly status: "success" | "failure"; readonly result: TResult; readonly queryType: string; readonly executedAt: Date; readonly durationMs?: number; readonly metadata?: Readonly<Record<string, unknown>>; } import { createQueryResult, isSuccessfulQueryResult, unwrapQueryResult } from "@zudojs/cqrs"; const ok = createQueryResult(user, { query: q }); isSuccessfulQueryResult(ok) // true unwrapQueryResult(ok) // the user object

MIDDLEWARE

Middleware wraps command/query execution. 11 built-in middleware factories included.

Built-in Middleware

MIDDLEWAREPurpose
timingMiddleware()Measures execution time; reports it via onTiming and exposes lastTiming
errorMiddleware()Catches exceptions, normalizes into BaseError
validationMiddleware()Validates CQRS request structure before execution
contextMiddleware()Adds execution metadata to the CQRS context
lockMiddleware(lock)Prevents concurrent execution of same request type
commandMiddleware(fn)Adapts command-specific middleware to generic middleware
queryMiddleware(fn)Adapts query-specific middleware to generic middleware
composeMiddleware([])Combines multiple middleware into a single pipeline
beforeMiddleware(fn)Runs callback before execution
afterMiddleware(fn)Runs callback after successful execution
onErrorMiddleware(fn)Runs callback when execution fails

Using Middleware

import { createCommandBus, timingMiddleware, errorMiddleware, validationMiddleware, beforeMiddleware, afterMiddleware } from "@zudojs/cqrs"; const bus = createCommandBus({ middleware: [ timingMiddleware(), errorMiddleware(), validationMiddleware(), beforeMiddleware((req) => console.log("Before:", req.type)), afterMiddleware((req, result) => console.log("After:", req.type)), ], }); // Add middleware at runtime bus.use(onErrorMiddleware((req, err) => console.error(req.type, err)));

Custom Middleware

import { CqrsMiddleware } from "@zudojs/cqrs"; const authMiddleware: CqrsMiddleware = async (request, context, next) => { if (!context?.userId) { throw new CqrsValidationError("Authentication required"); } return next(request, context); };

HANDLER REGISTRY

Central registry for both command and query handlers.

import { createHandlerRegistry } from "@zudojs/cqrs"; const registry = createHandlerRegistry(); // Register registry.registerCommand("CreateUser", createUserHandler); registry.registerQuery("GetUser", getUserHandler); // Query registry.hasCommand("CreateUser") // true registry.hasQuery("GetUser") // true registry.commandCount() // 1 registry.queryCount() // 1 registry.size() // 2 registry.getCommandTypes() // ["CreateUser"] registry.getQueryTypes() // ["GetUser"] // Replace registry.replaceCommand("CreateUser", newHandler); // Unregister registry.unregisterCommand("CreateUser") // boolean registry.clearCommands() // remove all command handlers registry.clear() // remove everything

EXECUTION CONTEXT

Propagates request metadata (user, tenant, correlation) through the pipeline.

import { createExecutionContext, createChildExecutionContext, withUser, withTenant, withSource, withContextMetadata, getUserId, getTenantId, sharesCorrelation, serializeExecutionContext } from "@zudojs/cqrs"; // Create context const ctx = createExecutionContext({ userId: "usr_123", tenantId: "tenant_abc", source: "http", correlationId: "corr_001", }); // Immutable transformations const ctx2 = withUser(ctx, "usr_456"); const ctx3 = withSource(ctx, "rpc"); // Child context (preserves correlation chain) const child = createChildExecutionContext(ctx, { source: "event" }); // Getters getUserId(ctx) // "usr_123" getTenantId(ctx) // "tenant_abc" sharesCorrelation(ctx, child) // true // Serialize for logging/transport const plain = serializeExecutionContext(ctx);

CQRS-specific event types for event-sourced aggregates.

import { createCqrsEvent, isCqrsEvent, isAggregateEvent, getAggregateId, createCqrsEventHandler } from "@zudojs/cqrs"; // Create a CQRS event with aggregate info const event = createCqrsEvent({ type: "UserCreated", payload: { name: "Alice", email: "alice@example.com" }, aggregateId: "usr_123", aggregateType: "User", version: 1, }); isCqrsEvent(event) // true isAggregateEvent(event) // true getAggregateId(event) // "usr_123" // Create event handler registration const registration = createCqrsEventHandler("UserCreated", (event) => { console.log("User created:", event.payload.name); });

DECORATORS

TypeScript decorators for metadata-driven handler registration.

import { CommandHandlerFor, QueryHandlerFor, getCqrsHandlerMetadata } from "@zudojs/cqrs"; @CommandHandlerFor("CreateUser") class CreateUserHandler { async execute(command: CreateUserCommand) { // ... } } @QueryHandlerFor("GetUser") class GetUserHandler { async execute(query: GetUserQuery) { // ... } } // Read metadata const meta = getCqrsHandlerMetadata(CreateUserHandler); // → { kind: "command", type: "CreateUser" }

TESTING

import { describe, it, expect, beforeEach } from "vitest"; import { createCommandBus, createQueryBus, createCommand, createQuery, createCommandHandler, createQueryHandler, timingMiddleware } from "@zudojs/cqrs"; describe("CommandBus", () => { let bus: CommandBus; beforeEach(() => { bus = createCommandBus(); bus.register("CreateUser", createCommandHandler("CreateUser", async (cmd) => { return { id: "usr_123", name: cmd.name }; })); }); it("should execute commands", async () => { const result = await bus.execute(createCommand("CreateUser", { name: "Alice" })); expect(result).toEqual({ id: "usr_123", name: "Alice" }); }); it("should run middleware", async () => { const bus = createCommandBus({ middleware: [timingMiddleware()] }); bus.register("CreateUser", createCommandHandler("CreateUser", async () => "ok")); const result = await bus.execute(createCommand("CreateUser")); expect(result).toBe("ok"); }); });

POTENTIAL IMPROVEMENTS

  • Auto-registration: Scan decorated classes and register handlers automatically
  • Command/query versioning: Support multiple handler versions for backward compatibility
  • Distributed bus: Redis/RabbitMQ-backed bus for microservice CQRS
  • Saga support: Long-running process managers spanning multiple commands
  • Dead letter queue: Persist failed commands for retry
