@zudojs/observability

Structured logging, metrics, distributed tracing, context propagation, and telemetry exporters for the Zudojs framework. Provides the instrumentation abstraction layer without coupling to any specific telemetry provider.

OBSERVABILITY LOGGING METRICS TRACING EXPORTERS

INSTALLATION

// npm npm install @zudojs/observability // pnpm pnpm add @zudojs/observability // yarn yarn add @zudojs/observability
Peer Dependencies: @zudojs/observability depends on @zudojs/errors at version 0.1.0.

WHAT IT DOES

@zudojs/observability is the single entry point for all telemetry in a Zudojs application. It provides:

  • → Structured logging with level filtering, child loggers, and persistent context
  • → Metrics — counters, gauges, and histograms with label support
  • → Distributed tracing with spans, attributes, events, and error recording
  • → Context propagation using AsyncLocalStorage for request-scoped IDs
  • → Console exporters for spans, logs, and metrics (development & debugging)
  • → Batch span processing with configurable batch size and flush interval
  • → Sensitive data redaction — passwords, tokens, and credentials are never logged
  • → Sampling strategies — always-on, always-off, probability, and parent-based
  • → Resource attributes — service name, version, environment, and custom tags
Core Principle: Application code depends on the Observability facade — logger, metrics, tracer, and propagation manager — never on specific telemetry providers. Exporters for OpenTelemetry, Prometheus, Datadog, etc. can be added as separate packages.

LOGGING

LogRecord Interface

interface LogRecord { readonly level: LogLevel; readonly levelName: LogLevelName; readonly message: string; readonly timestamp: Date; readonly loggerName: string; readonly context?: Record<string, unknown>; readonly error?: { readonly name: string; readonly message: string; readonly stack?: string; readonly cause?: unknown; }; }

Logger Interface

interface Logger { readonly name: string; readonly level: LogLevel; trace(message: string, context?: Record<string, unknown>): void; debug(message: string, context?: Record<string, unknown>): void; info(message: string, context?: Record<string, unknown>): void; warn(message: string, context?: Record<string, unknown>): void; error(message: string, context?: Record<string, unknown>): void; fatal(message: string, context?: Record<string, unknown>): void; /** Creates a child logger with persistent context. */ child(name: string, context?: Record<string, unknown>): Logger; /** Checks if a level would be logged. */ isLevelEnabled(level: LogLevel): boolean; /** Flushes any buffered log records. */ flush(): Promise<void>; }

LoggerOptions & LogTransport

interface LoggerOptions { readonly name: string; readonly level?: LogLevel; readonly context?: Record<string, unknown>; readonly transport?: LogTransport; } interface LogTransport { readonly name: string; write(record: LogRecord): void | Promise<void>; }

StructuredLogger & Factory

import { StructuredLogger, createStructuredLogger } from "@zudojs/observability"; const logger = createStructuredLogger({ name: "my-app", level: LogLevel.DEBUG, context: { service: "api" }, }); logger.info("Server started", { port: 3000 }); const child = logger.child("auth", { module: "auth" }); child.debug("Token validated");

Log Level Utilities

import { logLevelToName, logLevelFromName, shouldLog, getLogLevelNames, } from "@zudojs/observability"; logLevelToName(LogLevel.INFO); // "info" logLevelFromName("warn"); // LogLevel.WARN (3) shouldLog(LogLevel.INFO, LogLevel.ERROR); // true getLogLevelNames(); // ["trace","debug","info","warn","error","fatal","off"]

Log Record Factories

import { createLogRecord, createErrorLogRecord } from "@zudojs/observability"; const record = createLogRecord({ level: LogLevel.INFO, message: "User signed up", loggerName: "app", context: { userId: "abc-123" }, }); const errorRecord = createErrorLogRecord( new Error("Connection refused"), LogLevel.ERROR, "db", );

Gauge Interface

interface Gauge { readonly name: string; setValue(value: number): void; increment(value?: number): void; decrement(value?: number): void; getValue(): number; reset(): void; }

Histogram Interface

interface Histogram { readonly name: string; record(value: number): void; getValue(): { readonly count: number; readonly sum: number; readonly min: number; readonly max: number; }; reset(): void; }

MetricsRegistry Interface

interface MetricsRegistry { counter(name: string, labels?: Record<string, string>): Counter; gauge(name: string, labels?: Record<string, string>): Gauge; histogram(name: string, labels?: Record<string, string>): Histogram; getCounter(name: string): Counter | undefined; getGauge(name: string): Gauge | undefined; getHistogram(name: string): Histogram | undefined; getAll(): MetricSnapshot[]; reset(): void; }

MetricSnapshot & MetricExporter

interface MetricSnapshot { readonly name: string; readonly type: "counter" | "gauge" | "histogram"; readonly value: number | { readonly count: number; readonly sum: number; readonly min: number; readonly max: number; }; readonly labels?: Record<string, string>; } interface MetricExporter { export(snapshots: readonly MetricSnapshot[]): Promise<void>; shutdown(): Promise<void>; }

Default Implementations & Factories

import { DefaultCounter, createCounter, DefaultGauge, createGauge, DefaultHistogram, createHistogram, DefaultMetricsRegistry, createMetricsRegistry, } from "@zudojs/observability"; const registry = createMetricsRegistry(); // Counter — monotonically increasing const requests = registry.counter("http.requests.total", { method: "GET", path: "/api/users", }); requests.increment(); requests.increment(5); console.log(requests.getValue()); // 6 // Gauge — can go up and down const connections = registry.gauge("db.connections.active"); connections.setValue(10); connections.decrement(); console.log(connections.getValue()); // 9 // Histogram — distribution of values const latency = registry.histogram("http.request.duration"); latency.record(120); latency.record(340); latency.record(85); console.log(latency.getValue()); // { count: 3, sum: 545, min: 85, max: 340 }

import { DefaultSpan, createSpan, DefaultTracer, createTracer, createSpanContext, createChildSpanContext, } from "@zudojs/observability"; // Create a span directly const span = createSpan("handle-request", { kind: SpanKind.SERVER, attributes: { "http.method": "GET" }, }); span.setAttribute("http.url", "/api/users"); span.addEvent("cache.miss"); span.setStatus(SpanStatus.OK); span.end(); console.log(span.getDuration()); // milliseconds // Create a tracer const tracer = createTracer(); const span2 = tracer.startSpan("db.query"); // ... do work span2.end();

Span Context Factories

// New root span context with random IDs const ctx = createSpanContext(); // Child span context sharing the same traceId const childCtx = createChildSpanContext(ctx); // childCtx.traceId === ctx.traceId // childCtx.parentSpanId === ctx.spanId

SAMPLING

SamplingResult & Sampler Interface

interface SamplingResult { readonly decision: "RECORD_AND_SAMPLE" | "RECORD_ONLY" | "DO_NOT_RECORD"; readonly attributes?: Record<string, unknown>; } interface Sampler { shouldSample(parentContext?: SpanContext, traceId?: string): SamplingResult; }

Built-in Samplers

Sampler Behavior
AlwaysOnSampler Always records and samples — every span is exported
AlwaysOffSampler Never records or samples — no spans are exported
ProbabilitySampler Samples a percentage of traces based on traceId hash (deterministic)
ParentBasedSampler Follows parent span's sampling decision; falls back to root sampler for root spans

Factory Functions

import { createAlwaysOnSampler, createAlwaysOffSampler, createProbabilitySampler, createParentBasedSampler, } from "@zudojs/observability"; // Sample 10% of traces const sampler = createProbabilitySampler(0.1); // Follow parent, root uses 50% sampling const parentBased = createParentBasedSampler( createProbabilitySampler(0.5), );

PROCESSING

Span processors sit between span creation and export. They can batch, filter, enrich, or transform spans before they reach the exporter.

SpanProcessor Interface

interface SpanProcessor { onStart(span: Span): void; onEnd(span: ReadableSpan): void; shutdown(): Promise<void>; }

BatchSpanProcessor

Collects completed spans and exports them in batches. Flushes on batch size or interval, whichever comes first.

import { BatchSpanProcessor, createBatchSpanProcessor } from "@zudojs/observability"; // Default: batch size 512, flush every 5 seconds const processor = createBatchSpanProcessor({ exporter: myExporter, batchSize: 512, // default flushIntervalMs: 5000, // default }); // Flush manually await processor.flush(); // Shut down (flushes remaining, stops timer) await processor.shutdown();

EXPORTERS

Console exporters output telemetry as JSON to stdout/stderr. Use for development and debugging. Production systems should implement custom exporters for OpenTelemetry, Prometheus, Datadog, etc.

import { ConsoleSpanExporter, ConsoleLogExporter, ConsoleMetricExporter, createConsoleSpanExporter, createConsoleLogExporter, createConsoleMetricExporter, } from "@zudojs/observability"; // Spans → console.log (JSON) const spanExporter = createConsoleSpanExporter(); // Logs → console.log/warn/error (JSON) const logExporter = createConsoleLogExporter(); // Metrics → console.log (JSON) const metricExporter = createConsoleMetricExporter(); // Export manually await spanExporter.export([readableSpan]); await logExporter.export([logRecord]); await metricExporter.export([snapshot]);

CONTEXT PROPAGATION

Context propagation uses AsyncLocalStorage to carry trace, span, request, and correlation IDs through async call chains without manual threading.

PropagationContext & Options

interface PropagationContext { readonly traceId: string; readonly spanId: string; readonly parentSpanId?: string; readonly requestId?: string; readonly correlationId?: string; readonly userId?: string; readonly service?: string; readonly baggage?: Record<string, string>; } interface PropagationContextOptions { readonly traceId?: string; readonly spanId?: string; readonly parentSpanId?: string; readonly requestId?: string; readonly correlationId?: string; readonly userId?: string; readonly service?: string; readonly baggage?: Record<string, string>; }

PropagationManager Interface

interface PropagationManager { /** Gets the current context (from AsyncLocalStorage). */ current(): PropagationContext; /** Runs a function with a new propagation context. */ run<T>(context: PropagationContext, fn: () => T | Promise<T>): Promise<T>; /** Creates a new context derived from the current one. */ derive(overrides?: Partial<PropagationContext>): PropagationContext; }

AsyncPropagationManager & Factories

import { AsyncPropagationManager, createPropagationContext, derivePropagationContext, getCurrentContext, createPropagationManager, } from "@zudojs/observability"; const manager = createPropagationManager(); // Create a new context const ctx = createPropagationContext({ requestId: "req-abc", userId: "user-123", }); // Run code within the context await manager.run(ctx, async () => { // Inside here, getCurrentContext() returns ctx const current = getCurrentContext(); console.log(current.requestId); // "req-abc" // Derive a child context const child = manager.derive({ userId: "user-456" }); // child.traceId === current.traceId // child.userId === "user-456" });

REDACTION

Redacts sensitive fields from log contexts and trace attributes. Pass a redaction config to createObservability and the logger applies it to every record before any transport sees it; the default field list covers passwords, tokens, cookies, keys and card numbers, matched as substrings.

RedactionConfig

interface RedactionConfig { /** Field names to redact (case-insensitive). */ readonly fields: readonly string[]; /** Custom redaction function. */ readonly customRedactor?: (key: string, value: unknown) => unknown; /** Replacement text. */ readonly replacement?: string; }

Default Sensitive Fields

Field Name
password, secret, token, authorization
cookie, access_token, refresh_token
api_key, apiKey, accessToken, refreshToken
credit_card, creditCard, ssn, social_security

Factory Functions

import { createRedactor, redactObject, isSensitiveField } from "@zudojs/observability"; // Create a redactor function const redact = createRedactor({ fields: ["password", "secret", "token"], replacement: "***", }); redact("password", "hunter2"); // "***" redact("username", "alice"); // "alice" // Redact an entire object recursively const safe = redactObject({ username: "alice", password: "hunter2", nested: { token: "abc-123" }, }); // { username: "alice", password: "[REDACTED]", nested: { token: "[REDACTED]" } } // Check if a field is sensitive isSensitiveField("password"); // true isSensitiveField("username"); // false

OBSERVABILITY FUSION

The Observability interface is the central facade that coordinates logging, metrics, tracing, and context propagation. Other Zudojs packages depend on this abstraction.

Observability Interface

interface Observability { readonly logger: Logger; readonly metrics: MetricsRegistry; readonly tracer: Tracer; readonly propagation: PropagationManager; /** Creates a scoped instance with resource attributes. */ resource(attributes: Record<string, unknown>): Observability; /** Shuts down all exporters and processors. */ shutdown(): Promise<void>; }

ObservabilityConfig

interface ObservabilityConfig { readonly serviceName: string; readonly serviceVersion?: string; readonly environment?: string; readonly logLevel?: LogLevel; readonly logExporter?: LogExporter; readonly spanExporter?: SpanExporter; readonly metricExporter?: MetricExporter; readonly sampler?: Sampler; readonly processors?: readonly SpanProcessor[]; readonly redaction?: RedactionConfig; readonly resource?: Record<string, unknown>; }

DefaultObservability & Factory

import { DefaultObservability, createObservability, } from "@zudojs/observability"; const obs = createObservability({ serviceName: "my-api", serviceVersion: "1.0.0", environment: "production", logLevel: LogLevel.INFO, }); // Use the unified API obs.logger.info("Server started", { port: 3000 }); obs.metrics.counter("http.requests.total").increment(); const span = obs.tracer.startSpan("handle-request"); span.end(); // Create a scoped instance const scoped = obs.resource({ "team.name": "backend" }); // Shut down all telemetry await obs.shutdown();

NOOP SINGLETONS

No-op implementations that discard all telemetry. Allows instrumented code to remain simple without null checks. Use when observability is disabled.

Singleton Type Behavior
noopLogger Logger Discards all log calls; level set to OFF
noopCounter Counter Increments silently; getValue() always returns 0
noopGauge Gauge Accepts all operations; getValue() always returns 0
noopHistogram Histogram Records silently; getValue() returns {count:0, sum:0, min:0, max:0}
noopMetricsRegistry MetricsRegistry Returns noop metrics; getAll() returns empty array
noopSpan Span No-op on all methods; isRecording() returns false
noopTracer Tracer startSpan() returns noopSpan
noopPropagationManager PropagationManager current() returns empty context; run() executes function directly

NoopObservability

import { NoopObservability, createNoopObservability, } from "@zudojs/observability"; const noop = createNoopObservability(); // All properties are noop singletons noop.logger.info("ignored"); // no-op noop.metrics.counter("x").increment(); // no-op noop.tracer.startSpan("x").end(); // no-op // resource() returns itself (no-op) const scoped = noop.resource({ "key": "val" });

FULL INTEGRATION EXAMPLE

Complete working example: create observability, use logging, metrics, tracing, context propagation, and redaction together.

import { createObservability, createProbabilitySampler, createBatchSpanProcessor, createConsoleSpanExporter, createConsoleLogExporter, createConsoleMetricExporter, redactObject, LogLevel, SpanKind, SpanStatus, } from "@zudojs/observability"; // 1. Create the observability system const obs = createObservability({ serviceName: "my-api", serviceVersion: "1.0.0", environment: "production", logLevel: LogLevel.DEBUG, logExporter: createConsoleLogExporter(), spanExporter: createConsoleSpanExporter(), metricExporter: createConsoleMetricExporter(), sampler: createProbabilitySampler(0.5), processors: [ createBatchSpanProcessor({ batchSize: 256, flushIntervalMs: 10000, }), ], redaction: { fields: ["password", "token", "secret"], }, }); // 2. Create a child logger const logger = obs.logger.child("http", { module: "api" }); // 3. Set up metrics const requestCounter = obs.metrics.counter("http.requests.total"); const requestDuration = obs.metrics.histogram("http.request.duration"); const activeConnections = obs.metrics.gauge("http.connections.active"); // 4. Redact sensitive data before logging const safePayload = redactObject({ username: "alice", password: "hunter2", token: "abc-123", }); logger.info("Login attempt", { payload: safePayload }); // 5. Handle a request with full observability async function handleRequest(req: unknown) { const span = obs.tracer.startSpan("handle-request", { kind: SpanKind.SERVER, attributes: { "http.method": "GET", "http.url": "/api/users" }, }); activeConnections.increment(); requestCounter.increment(); const start = Date.now(); try { span.addEvent("db.query.start"); // ... database work ... span.setAttribute("db.rows", 42); span.setStatus(SpanStatus.OK); logger.info("Request completed", { duration: Date.now() - start }); } catch (error) { span.recordError(error as Error); span.setStatus(SpanStatus.ERROR, (error as Error).message); logger.error("Request failed", { error: (error as Error).message }); } finally { span.end(); requestDuration.record(Date.now() - start); activeConnections.decrement(); } } // 6. Graceful shutdown process.on("SIGTERM", async () => { await obs.shutdown(); process.exit(0); });
