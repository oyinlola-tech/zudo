@zudojs/errors

Shared error base class, error codes, error categories, severity levels, and error handling utilities. Every package in the ZudoLib framework depends on this foundation.

ERROR HIERARCHY LEAF PACKAGE ZERO DEPENDENCIES

INSTALLATION

// npm npm install @zudojs/errors // pnpm pnpm add @zudojs/errors // yarn yarn add @zudojs/errors
Zero Dependencies: @zudojs/errors is a leaf package with no external or internal dependencies. Every other package in the monorepo imports from this package.

WHAT IT DOES

@zudojs/errors is the foundation of error handling across the entire ZudoLib framework. It provides:

  • → A BaseError class that all ZudoLib errors extend
  • → An ErrorCode enum with 200+ stable string codes across every domain
  • → An ErrorCategory enum with 40 categories for classification
  • → An ErrorSeverity enum with 5 levels for alerting and monitoring
  • → Error metadata with creation, merging, sanitization, and serialization
  • → Domain-specific error classes (auth, validation, not-found, conflict, etc.)
  • → Infrastructure errors (database, HTTP, network, cache, storage, middleware, adapter)
  • → System errors (crypto, runtime, logging)
  • → Utility functions for error normalization, serialization, type checking, and transformation
Core Principle: Every package in the monorepo imports its error types from @zudojs/errors. No package should create its own error classes that extend Error or BaseError directly.

CORE API — BASEERROR

Class: BaseError

Every ZudoLib error extends this class. It provides a consistent structure for error handling, logging, HTTP responses, monitoring, and serialization.

class BaseError extends Error { readonly code: ErrorCode | string; readonly category: ErrorCategory; readonly severity: ErrorSeverity; readonly statusCode: number; readonly expose: boolean; readonly isOperational: boolean; readonly metadata: Readonly<ErrorMetadata>; readonly cause: unknown; constructor(message: string, options?: BaseErrorOptions); isPublic(): boolean; isOperationalError(): boolean; getMetadata(key: string): ErrorMetadataValue | undefined; withMetadata(metadata: ErrorMetadata): this; toJSON(): SerializedBaseError; toLogObject(): SerializedBaseError; toString(): string; }

Constructor Options

Option Type Default Description
code ErrorCode | string ErrorCode.UNKNOWN Machine-readable error code
category ErrorCategory UNKNOWN High-level error classification
severity ErrorSeverity ERROR How seriously to treat this error
statusCode number 500 HTTP status code (100-599)
expose boolean statusCode < 500 Whether message is safe for clients
isOperational boolean true Expected vs programming error
metadata ErrorMetadata {} Serializable diagnostic data
cause unknown undefined Original error that caused this one

Example: Creating a BaseError

import { BaseError, ErrorCode, ErrorCategory, ErrorSeverity } from "@zudojs/errors"; const error = new BaseError("Payment processing failed", { code: ErrorCode.OPERATION_FAILED, category: ErrorCategory.OPERATION, severity: ErrorSeverity.ERROR, statusCode: 500, expose: false, isOperational: true, metadata: { orderId: "ord_123", amount: 99.99 }, cause: originalError, }); // Check properties error.isPublic(); // false error.isOperationalError(); // true error.getMetadata("orderId"); // "ord_123" // Serialize for logging console.log(error.toJSON()); // { name: "BaseError", message: "Payment processing failed", // code: "ERR_OPERATION_FAILED", category: "operation", // severity: "error", statusCode: 500, expose: false, // isOperational: true, metadata: { orderId: "ord_123", amount: 99.99 } }

ERROR METADATA

Metadata is JSON-compatible diagnostic data attached to errors. It flows through logs, APIs, queues, and monitoring systems.

type ErrorMetadataPrimitive = string | number | boolean | null; type ErrorMetadataValue = | ErrorMetadataPrimitive | readonly ErrorMetadataValue[] | { readonly [key: string]: ErrorMetadataValue }; interface ErrorMetadata { readonly [key: string]: ErrorMetadataValue | undefined; }

Metadata Utilities

import { createErrorMetadata, mergeErrorMetadata, getErrorMetadataValue, hasErrorMetadata, omitErrorMetadata, pickErrorMetadata, serializeErrorMetadata, isErrorMetadataValue, sanitizeErrorMetadata, } from "@zudojs/errors"; // Create immutable metadata const meta = createErrorMetadata({ userId: "u_123", action: "login" }); // Merge multiple sources (later overrides earlier) const merged = mergeErrorMetadata(meta, { requestId: "req_456" }); // Read a value getErrorMetadataValue(meta, "userId"); // "u_123" // Check existence hasErrorMetadata(meta, "userId"); // true // Omit sensitive keys const safe = omitErrorMetadata(meta, "password", "token"); // Pick specific keys const picked = pickErrorMetadata(meta, ["userId"]); // Sanitize arbitrary data const clean = sanitizeErrorMetadata({ password: "secret", name: "John" }); // { name: "John" } — password removed

TESTING

Examples for testing error creation, type guards, and serialization with vitest.

import { describe, it, expect } from "vitest"; import { BaseError, ErrorCode, ErrorCategory, ErrorSeverity, AuthenticationError, NotFoundError, ValidationError, isBaseError, isAuthenticationError, isNotFoundError, isValidationError, toBaseError, getErrorMessage, tryCatch, tryCatchAsync, ErrorSerializer, } from "@zudojs/errors"; describe("@zudojs/errors", () => { it("creates BaseError with defaults", () => { const error = new BaseError("test"); expect(error.message).toBe("test"); expect(error.code).toBe(ErrorCode.UNKNOWN); expect(error.statusCode).toBe(500); expect(error.expose).toBe(false); expect(error.isOperational).toBe(true); }); it("creates AuthenticationError with 401", () => { const error = new AuthenticationError(); expect(error.statusCode).toBe(401); expect(error.expose).toBe(true); expect(isAuthenticationError(error)).toBe(true); }); it("creates ValidationError with issues", () => { const error = new ValidationError("Invalid", { issues: [{ field: "email", message: "Required" }], }); expect(error.issueCount).toBe(1); expect(error.issuesForField("email")).toHaveLength(1); }); it("serializes error safely", () => { const serializer = new ErrorSerializer(); const error = new BaseError("test", { expose: false }); const public_ = serializer.serializePublic(error); expect(public_.message).toBe("An unexpected error occurred"); }); it("normalizes unknown errors", () => { const result = tryCatch(() => { throw "string error"; }); expect(result.success).toBe(false); expect(isBaseError(result.error)).toBe(true); }); it("handles async errors", async () => { const result = await tryCatchAsync(async () => { throw new NotFoundError("User not found"); }); expect(result.success).toBe(false); expect(isNotFoundError(result.error)).toBe(true); }); });

FULL INTEGRATION EXAMPLE

Complete example: HTTP error handler, CQRS error handling, and event error handling.

import { BaseError, ErrorCode, ErrorCategory, ErrorSeverity, AuthenticationError, AuthorizationError, NotFoundError, ValidationError, ConflictError, RateLimitError, HttpError, EventError, isBaseError, toBaseError, getErrorMessage, ErrorHandler, ErrorSerializer, } from "@zudojs/errors"; // 1. HTTP error handler middleware const errorHandler = new ErrorHandler({ reporter: async (error) => { if (!error.expose) { await reportToMonitoring(error); } }, includeStack: false, }); async function handleRequest(req, res) { try { const user = await authenticateUser(req); if (!user) throw new AuthenticationError("Invalid token"); const order = await createOrder(req.body); res.json({ success: true, order }); } catch (error) { const result = await errorHandler.handle(error, { requestId: req.headers["x-request-id"], }); res.status(result.statusCode).json(result); } } // 2. Domain-specific error creation async function createOrder(data) { if (!data.items?.length) { throw new ValidationError("Order must have items", { issues: [{ field: "items", message: "Required", code: ErrorCode.MISSING_FIELD }], }); } const existing = await findOrder(data.id); if (existing) { throw new ConflictError(`Order ${data.id} already exists`, { code: ErrorCode.ALREADY_EXISTS, metadata: { orderId: data.id }, }); } return await saveOrder(data); } // 3. Event error handling async function handleEvent(event) { try { await processEvent(event); } catch (error) { throw new EventError(getErrorMessage(error), { eventType: event.type, eventId: event.id, cause: error, }); } } // 4. Rate limiting function checkRateLimit(userId) { const count = getRequestCount(userId); if (count > 100) { throw new RateLimitError("Rate limit exceeded", { retryAfterSeconds: 60, metadata: { userId, requestCount: count }, }); } } // 5. Error serialization for API responses const serializer = new ErrorSerializer({ redactSensitiveData: true, safeMessage: "An unexpected error occurred", }); // Public API response (safe for clients) const publicResponse = serializer.serializePublic(error); // Internal log entry (includes full details) const logEntry = serializer.serialize(error);
