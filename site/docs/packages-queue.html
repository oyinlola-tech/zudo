@zudojs/queue

Background job and asynchronous task infrastructure. Provides an in-memory queue with processors, workers, retry policies, dead letter handling, middleware, serialization, and event emission.

QUEUE JOBS WORKERS BACKGROUND RETRY

INSTALLATION

// npm npm install @zudojs/queue // pnpm pnpm add @zudojs/queue // yarn yarn add @zudojs/queue
Peer Dependencies: @zudojs/queue depends on @zudojs/errors, @zudojs/constants, and @zudojs/serialization. All at version 0.1.0.

WHAT IT DOES

@zudojs/queue provides a complete background job processing system. It handles the full lifecycle of asynchronous work:

  • → Background job processing with an in-memory queue
  • → Job priority and scheduling — delayed jobs and priority queues
  • → Retry with backoff — fixed or exponential backoff strategies
  • → Dead letter queue for jobs that exhaust all retries
  • → Worker concurrency control — configurable parallelism
  • → Middleware pipeline — logging, timeout, and custom middleware
  • → Event system — 10 event types for job and worker lifecycle
  • → Job deduplication — prevent duplicate jobs via keys
  • → Progress tracking — report job progress with percent and step info
  • → Queue manager — manage multiple named queues from one manager
Core Principle: Jobs are first-class objects with typed data, lifecycle states, and metadata. Workers poll queues, run processors, and handle retries automatically.

JOB

A Job is a unit of work in the queue system. Jobs carry typed data, lifecycle state, retry info, and metadata.

Interface: Job

interface Job<TData = unknown> { readonly id: JobId; readonly name: JobName; readonly queueName: string; readonly data: TData; readonly state: JobState; readonly attempt: number; readonly maxAttempts: number; readonly priority: number; readonly createdAt: Timestamp; readonly updatedAt: Timestamp; readonly scheduledAt?: Timestamp; readonly startedAt?: Timestamp; readonly completedAt?: Timestamp; readonly failedAt?: Timestamp; readonly error?: string; readonly timeoutMs?: number; readonly deduplicationKey?: string; readonly metadata?: Record<string, unknown>; readonly backoff?: { readonly type: BackoffType; readonly delay: number; readonly maxDelay?: number; readonly multiplier?: number; }; }

Interface: JobInput

interface JobInput<TData = unknown> { readonly name: JobName; readonly queueName: string; readonly data: TData; readonly options?: JobOptions; }

JOB OPTIONS

Interface: JobOptions

interface JobOptions { readonly attempts?: number; // default: 1 (no retries) readonly backoff?: BackoffOptions; // retry strategy readonly delay?: number; // ms before job becomes active readonly priority?: number; // higher = higher priority readonly timeout?: number; // ms before job times out readonly deduplicationKey?: string; readonly scheduledAt?: Date; readonly metadata?: Record<string, unknown>; }

Interface: BackoffOptions

interface BackoffOptions { readonly type: BackoffType; // FIXED or EXPONENTIAL readonly delay: number; // initial delay in ms readonly maxDelay?: number; // max delay cap (exponential) readonly multiplier?: number; // default: 2 }

Defaults

PROCESSOR

A Processor is a function that handles a specific job type. Processors are registered per job name and invoked by workers.

Type: Processor

type Processor<TData = unknown, TResult = unknown> = ( job: Job<TData>, context: JobContext<TData>, ) => Promise<JobResult<TResult>> | Promise<void>;

Interface: ProcessorRegistry

interface ProcessorRegistry { register<TData, TResult>( jobName: string, processor: Processor<TData, TResult>, options?: { description?: string }, ): void; get<TData, TResult>(jobName: string): Processor<TData, TResult> | undefined; has(jobName: string): boolean; getAll(): ProcessorInfo[]; unregister(jobName: string): boolean; clear(): void; }

Example

import { createProcessorRegistry } from "@zudojs/queue"; const registry = createProcessorRegistry(); registry.register<EmailData>("send-email", async (job, ctx) => { ctx.log("Sending email", { to: job.data.to }); // ... send email logic }, { description: "Sends transactional emails" }); registry.has("send-email"); // true

QUEUE INTERFACE

A Queue is a named stream of jobs. Jobs are added to the queue and processed by workers.

Interface: Queue

interface Queue<TData = unknown> { readonly name: QueueName; add(name: string, data: TData, options?: JobOptions): Promise<Job<TData>>; process(name: string, processor: Processor<TData>): void; getJob(jobId: JobId): Promise<Job<TData> | null>; getNextJob(): Promise<Job<TData> | null>; getProcessor(name: string): Processor<TData> | undefined; getStats(): Promise<QueueStats>; pause(): Promise<void>; resume(): Promise<void>; isPaused(): boolean; close(): Promise<void>; }

Interface: QueueOptions

interface QueueOptions { readonly concurrency?: number; readonly defaultJobOptions?: Partial<JobOptions>; readonly serializer?: Serializer; readonly middleware?: QueueMiddleware[]; readonly pollInterval?: number; readonly eventEmitter?: QueueEventEmitter; }

Interface: QueueStats

interface QueueStats { readonly waiting: number; readonly active: number; readonly completed: number; readonly failed: number; readonly delayed: number; readonly retrying: number; }

IN-MEMORY QUEUE

InMemoryQueue is the default queue implementation. Jobs are stored in memory and processed synchronously by workers.

import { createInMemoryQueue } from "@zudojs/queue"; const queue = createInMemoryQueue<EmailData>("emails", { concurrency: 5, pollInterval: 200, }); // Register a processor queue.process("send-email", async (job, ctx) => { ctx.log(`Sending to ${job.data.to}`); }); // Add a job const job = await queue.add("send-email", { to: "user@example.com" }, { attempts: 3, backoff: { type: BackoffType.EXPONENTIAL, delay: 1000 }, }); // Get stats const stats = await queue.getStats();

QUEUE MANAGER

QueueManager manages multiple named queues from a single entry point. Queues are lazily created on first access.

Interface: QueueManager

interface QueueManager { getQueue<TData>(name: QueueName, options?: QueueOptions): Queue<TData>; getExistingQueue<TData>(name: QueueName): Queue<TData> | undefined; hasQueue(name: QueueName): boolean; getQueueNames(): QueueName[]; closeAll(): Promise<void>; }

Example

import { createQueueManager } from "@zudojs/queue"; const manager = createQueueManager(); // Get or create queues const emailQueue = manager.getQueue("emails"); const reportQueue = manager.getQueue("reports"); // Check existence manager.hasQueue("emails"); // true // List all queues manager.getQueueNames(); // ["emails", "reports"] // Close all on shutdown await manager.closeAll();

Interface: QueueRegistry

Registry for queue instances, providing lookup and lifecycle management.

interface QueueRegistry { register<TData>(queue: Queue<TData>): void; get<TData>(name: QueueName): Queue<TData> | undefined; has(name: QueueName): boolean; getAll(): QueueInfo[]; unregister(name: QueueName): boolean; clear(): void; }

WORKERS

A Worker polls a queue for jobs and executes registered processors with configurable concurrency.

Interface: Worker

interface Worker<TData = unknown> { readonly id: string; readonly queue: Queue<TData>; readonly queueName: string; readonly state: WorkerState; start(): Promise<void>; stop(): Promise<void>; forceStop(): Promise<void>; isRunning(): boolean; getStats(): WorkerStats; }

Interface: WorkerOptions

interface WorkerOptions { readonly concurrency?: number; readonly pollInterval?: number; readonly maxStalledCount?: number; readonly timeoutMs?: number; readonly middleware?: QueueMiddleware[]; }

Interface: WorkerStats

interface WorkerStats { readonly processed: number; readonly succeeded: number; readonly failed: number; readonly concurrency: number; readonly state: WorkerState; }

Example

import { createWorker, createInMemoryQueue } from "@zudojs/queue"; const queue = createInMemoryQueue("emails"); queue.process("send-email", emailProcessor); const worker = createWorker("worker-1", queue, { concurrency: 5, pollInterval: 100, }); await worker.start(); console.log(worker.getStats()); // { processed: 0, succeeded: 0, failed: 0, concurrency: 5, state: "running" } // Graceful shutdown await worker.stop();

FULL INTEGRATION EXAMPLE

Complete working example: create a queue, register processors, add jobs, create workers, handle events, and use retry with dead letter.

import { createInMemoryQueue, createWorker, createInMemoryQueueEventEmitter, createLoggingMiddleware, createTimeoutMiddleware, createExponentialBackoff, createInMemoryDeadLetterStore, moveToDeadLetter, createQueueManager, } from "@zudojs/queue"; import type { Job, JobContext } from "@zudojs/queue"; // 1. Define job data types interface EmailData { readonly to: string; readonly subject: string; readonly body: string; } // 2. Create event emitter and dead letter store const emitter = createInMemoryQueueEventEmitter(); const deadLetterStore = createInMemoryDeadLetterStore<EmailData>(); // 3. Create queue with middleware const queue = createInMemoryQueue<EmailData>("emails", { concurrency: 5, pollInterval: 100, eventEmitter: emitter, middleware: [ createLoggingMiddleware(), createTimeoutMiddleware(30000), ], defaultJobOptions: { attempts: 3, backoff: createExponentialBackoff(1000, { maxDelay: 30000 }), }, }); // 4. Register processor queue.process("send-email", async ( job: Job<EmailData>, ctx: JobContext<EmailData>, ) => { ctx.log("Sending email", { to: job.data.to, attempt: job.attempt, }); // Simulate email sending if (job.data.to === "fail@example.com") { throw new Error("SMTP connection refused"); } // Report progress await ctx.updateProgress({ percent: 100, step: "sent", message: "Email delivered", timestamp: new Date().toISOString(), }); return { success: true, data: null, durationMs: 150, timestamp: new Date().toISOString() }; }); // 5. Listen for events emitter.on("job:completed", (data) => { console.log("Job completed:", data.job.id); }); emitter.on("job:failed", async (data) => { console.error("Job failed:", data.job.id, data.error.message); // Move to dead letter after max attempts if (data.job.attempt >= data.job.maxAttempts) { await moveToDeadLetter(deadLetterStore, data.job, data.error); console.log("Moved to dead letter:", data.job.id); } }); // 6. Create worker const worker = createWorker("email-worker-1", queue, { concurrency: 5, pollInterval: 100, }); await worker.start(); // 7. Add jobs await queue.add("send-email", { to: "user@example.com", subject: "Hello", body: "Welcome!", }); await queue.add("send-email", { to: "fail@example.com", subject: "Will fail", body: "...", }); // 8. Check stats const stats = await queue.getStats(); console.log("Queue stats:", stats); // 9. Check dead letter const deadJobs = await deadLetterStore.getAll(); console.log("Dead letter jobs:", deadJobs.length); // 10. Graceful shutdown await worker.stop(); await queue.close();
