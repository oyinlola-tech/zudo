@zudojs/core

Application lifecycle, context propagation, runtime orchestrator, and module system.

CORE LIFECYCLE RUNTIME

OVERVIEW

@zudojs/core is the heart of the Zudo framework. It ties together the container, configuration, logging, modules, and runtime into a cohesive application lifecycle. Every Zudo application starts and stops through this package.

Submodule Architecture

// @zudojs/core re-exports 8 submodules contracts ← Adapter, Handler, Disposable interfaces errors ← FrameworkError and core exception types logging ← Logger interface, BaseLogger, ConsoleLogger lifecycle ← LifecycleManager, hooks, scopes context ← ExecutionContext, ContextProvider, snapshots configuration ← ConfigurationManager, sources, schemas modules ← Module system (definition, registry, loader, lifecycle, deps) runtime ← Runtime state machine, bootstrap, shutdown, environment

INSTALLATION

npm install @zudojs/core // Import everything import { Application, createRuntime } from "@zudojs/core"; // Import specific submodules import { Logger, LogLevel } from "@zudojs/core/logging"; import { Module, BaseModule } from "@zudojs/core/modules"; import { Runtime, RuntimeState } from "@zudojs/core/runtime";

APPLICATION

The top-level entry point. Manages the full application lifecycle from creation to disposal.

ApplicationState

type ApplicationState = | "created" // just instantiated | "initializing" // lifecycle.initialize() in progress | "initialized" // ready to start | "starting" // lifecycle.start() in progress | "running" // fully operational | "stopping" // lifecycle.stop() in progress | "stopped" // gracefully shut down | "failed"; // unrecoverable error

Creating & Using an Application

import { Application } from "@zudojs/core"; // Static factory — creates and initializes const app = await Application.CREATE({ context: applicationContext, lifecycle: lifecycleManager, runtime: runtime, }); console.log(app.state); // "initialized" // Start the application await app.start(); console.log(app.state); // "running" // Stop gracefully await app.stop(); console.log(app.state); // "stopped" // Or use shutdown (calls stop internally) await app.shutdown();

State Transitions

Current StateAllowed Transitions
created→ initializing
initializing→ initialized, failed
initialized→ starting
starting→ running, failed
running→ stopping
stopping→ stopped, failed
stopped—
failed→ stopping

CONTRACTS

Core interfaces that define the boundaries between Zudo and external systems.

Adapter

interface Adapter<TOptions = unknown> extends Disposable { readonly name: string; readonly options?: TOptions; initialize(): Promise<void> | void; start(): Promise<void> | void; stop(): Promise<void> | void; }

Examples: Fastify adapter, Prisma adapter, Redis adapter, Kafka adapter.

Handler

interface Handler<TInput = unknown, TOutput = unknown> { handle(input: TInput): Promise<TOutput> | TOutput; } // Convert a function into a Handler const handler = createHandler(async (req) => { return { status: 200, body: "ok" }; });

Disposable

interface Disposable { dispose(): void; }

LOGGING

Structured logging interface with child context support.

Logger Interface

type LogLevel = "trace" | "debug" | "info" | "warn" | "error" | "fatal"; interface Logger { trace(message: string, context?: LogContext): void; debug(message: string, context?: LogContext): void; INFO(message: string, context?: LogContext): void; warn(message: string, context?: LogContext): void; error(message: string, error?: unknown, context?: LogContext): void; fatal(message: string, error?: unknown, context?: LogContext): void; child(context: LogContext): Logger; } type LogContext = Record<string, unknown>;

BaseLogger (Abstract)

// Extend BaseLogger to create custom transports class ConsoleLogger extends BaseLogger { protected write(level: LogLevel, msg: string, ctx?: LogContext, err?: unknown): void { console[level](`[${level}]`, msg, ctx ?? {}, err ?? ""); } protected createChild(context: LogContext): Logger { return new ConsoleLogger(context); } }

LogEntry

interface LogEntry { readonly level: LogLevel; readonly message: string; readonly context?: LogContext; readonly timestamp: Date; readonly error?: unknown; }

EXECUTION CONTEXT

Propagates request-scoped data through async call chains using AsyncLocalStorage.

Context Types

type ContextType = | "http" | "rpc" | "message" | "job" | "cli" | "worker" | "unknown";

Creating & Using Context

import { createContext, ContextProvider } from "@zudojs/core/context"; // Create a context for an HTTP request const ctx = createContext({ application: appContext, type: "http", id: "req_abc123", // optional — auto-generated UUID if omitted }); console.log(ctx.getId()); // "req_abc123" console.log(ctx.getType()); // "http" // Store request-scoped values ctx.set("userId", "usr_123"); const userId = ctx.get<string>("userId"); // "usr_123"

ContextProvider

import { createContextProvider } from "@zudojs/core/context"; const provider = createContextProvider(); // Run code within a context provider.run(ctx, () => { // Context is available here const current = provider.require(); console.log(current.getId()); }); // Check if context is active provider.has() // false (outside run)

Context Snapshot

LIFECYCLE

State machine for managing component lifetimes with hooks and dependency ordering.

Lifecycle Phases

PhaseDescription
initializeComponent is being set up
startComponent begins accepting work
readyComponent is fully operational
stopComponent is shutting down
disposeComponent is being destroyed

LifecycleManager

// The LifecycleManager orchestrates startup/shutdown order import { LifecycleManager } from "@zudojs/core/lifecycle"; // Components register with the manager manager.register(componentA); manager.register(componentB); // Initialize in dependency order await manager.initialize(); // Start in dependency order await manager.start(); // Stop in reverse dependency order await manager.stop();

MODULE SYSTEM

The module system lets you split your application into independently manageable units with their own lifecycle, dependencies, and configuration.

Module Interface

interface Module extends ModuleLifecycle { readonly id: ModuleId; // unique string identifier readonly name: string; // human-readable name readonly version?: string; // semantic version readonly dependencies?: readonly ModuleId[]; // other module IDs readonly options?: ModuleOptions; readonly scope?: LifecycleScope; attach?(application: unknown): void; } interface ModuleLifecycle { onInitialize?(context: ModuleContext): void | Promise<void>; onReady?(context: ModuleContext): void | Promise<void>; onShutdown?(context: ModuleContext): void | Promise<void>; onDestroy?(context: ModuleContext): void | Promise<void>; }

BaseModule (Abstract Class)

import { BaseModule, ModuleContext } from "@zudojs/core/modules"; class AuthModule extends BaseModule { readonly id = "auth"; readonly name = "Authentication Module"; readonly dependencies = ["config", "logger"]; async onInitialize(ctx: ModuleContext): Promise<void> { // Set up JWT provider, session store } async onReady(ctx: ModuleContext): Promise<void> { // Start accepting auth requests } async onShutdown(ctx: ModuleContext): Promise<void> { // Flush session store } }

ModuleDefinition

import { defineModule } from "@zudojs/core/modules"; const AuthModuleDef = defineModule({ id: "auth", name: "Authentication", version: "0.0.1", factory: (opts) => new AuthModule(opts), dependencies: ["config", "logger"], autoLoad: true, multiInstance: false, metadata: { author: "Zudo Team", description: "Handles JWT and session authentication", }, });

Module Lifecycle States

type ModuleLifecyclePhase = | "created" | "initializing" | "initialized" | "starting" | "started" | "stopping" | "stopped" | "destroying" | "destroyed" | "failed";

Module Registry

import { ModuleRegistry } from "@zudojs/core/modules"; // Register modules registry.register(AuthModuleDef); registry.registerMany([UserModuleDef, PaymentModuleDef]); // Query registry.get("auth") // → ModuleRegistration | undefined registry.has("auth") // true registry.getLoadedModules() // all loaded Module instances // Subscribe to changes registry.subscribe((event) => { console.log(event.type); // "registered" | "replaced" | "unregistered" | "state-changed" });

Module Dependency Graph

// Automatic topological sorting of module dependencies // A → B → C means C initializes first, A starts first // Invalid dependencies are caught: // - Circular dependencies // - Missing dependencies // - Duplicate dependency declarations // - Self-dependency

CONFIGURATION

Layered configuration with multiple sources, schemas, and validation.

ConfigurationManager

import { ConfigurationManager, createConfigurationManager } from "@zudojs/core/configuration"; const config = createConfigurationManager(); // Load from multiple sources await config.load(); // Access typed values const port = config.get<number>("server.port"); const dbUrl = config.get<string>("database.url");

Configuration Sources

// Environment variables // JSON/YAML files // Remote config services // Command-line arguments // Default values // Sources have priority ordering — later sources override earlier ones

Schema Validation

// Configuration is validated against schemas // Invalid config fails fast at startup // Sensitive values (password, secret, token) are auto-redacted

RUNTIME

The runtime orchestrates the full application lifecycle — from bootstrap to shutdown — managing modules, configuration, and logging.

RuntimeState

enum RuntimeState { CREATED = "created", BOOTSTRAPPING= "bootstrapping", READY = "ready", STOPPING = "stopping", STOPPED = "stopped", FAILED = "failed", }

Runtime Transitions

FromTo
created→ bootstrapping
bootstrapping→ ready, failed
ready→ stopping
stopping→ stopped, failed
stopped— (terminal)
failed— (terminal)

RUNTIME UTILITIES

import { isRuntimeReady, isRuntimeFailed, isRuntimeTerminal, isRuntimeTransitioning, canStartRuntime, canStopRuntime, getRuntimeStateLabel, getNextRuntimeStates } from "@zudojs/core/runtime"; isRuntimeReady(RuntimeState.READY) // true isRuntimeTerminal(RuntimeState.STOPPED) // true canStartRuntime(RuntimeState.CREATED) // true canStopRuntime(RuntimeState.READY) // true getRuntimeStateLabel(RuntimeState.BOOTSTRAPPING) // "Bootstrapping" getNextRuntimeStates(RuntimeState.CREATED) // [BOOTSTRAPPING]

Runtime Context & Environment

import { createRuntimeContext, createRuntimeEnvironment, detectRuntimeEngine, detectPlatform, detectCI, detectContainer } from "@zudojs/core/runtime"; const ctx = createRuntimeContext({ /* deps */ }); const env = createRuntimeEnvironment(); detectRuntimeEngine() // "node" | "deno" | "bun" | "browser" detectPlatform() // "linux" | "darwin" | "win32" | ... detectCI() // true if running in CI detectContainer() // true if running in Docker/K8s

Runtime Options

import { resolveRuntimeOptions, RuntimeMode } from "@zudojs/core/runtime"; const options = resolveRuntimeOptions({ mode: RuntimeMode.PRODUCTION, startup: { timeout: 30000 }, shutdown: { timeout: 15000, graceful: true }, signal: { handlers: ["SIGTERM", "SIGINT"] }, });

Bootstrap & Shutdown Pipelines

// Bootstrap pipeline: register → load → initialize → start // Shutdown pipeline: stop → destroy → cleanup // Each phase has configurable timeout and error handling // Failures are aggregated into structured error objects

ERRORS

All errors extend FrameworkError (which extends ApplicationError from @zudojs/errors).

ErrorWhen Thrown
FrameworkErrorBase error for all core framework errors
InvalidArgumentErrorInvalid function arguments
InvalidStateErrorOperation invalid in current state
ProviderNotFoundErrorDI token not registered
ConfigurationNotFoundErrorConfig key not found
ExecutionContextNotFoundErrorNo active context in current async scope
AdapterNotFoundErrorRequested adapter not registered
RuntimeErrorRuntime startup/shutdown failure
