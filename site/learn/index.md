# Learn ZudoJS

Start with plain JavaScript, move to TypeScript, then build a real backend with ZudoJS. Every example runs in the terminal on this page, and every lesson shows you how to run it on your own computer and what you should see.

[Start lesson 1 →](https://zudojs.oyinlola.site/learn/setup)

## How this course works

You will build one thing from start to finish: a **Task API**, a backend that stores tasks and lets people create, update and complete them. Every lesson moves it one step forward.

Each lesson gives you two ways to run the code:

| Where | How | Good for |
| --- | --- | --- |
| **In your browser** | Press **Run in browser** on any example. A terminal opens at the bottom of the page and runs the code. You can edit it and run it again. | Trying ideas quickly, on any device, with nothing installed |
| **On your computer** | Each lesson lists the exact commands to type, and the output you should see. | Building the real project. A backend runs on a computer, so this is where you will end up |

The output under each example is the real output. It was produced by running that example with Node.js and in the browser terminal, and both print exactly the same thing.

> TIP
>
> You can also open the terminal at any time with the >_ button in the header, or with Ctrl + `.

## What you need

- A computer running Windows, macOS or Linux, where you can install programs.
- A code editor. [Visual Studio Code](https://code.visualstudio.com/) is free and works well with TypeScript.
- No programming experience with JavaScript is required. If you have written a little code in any language, you will move faster.

PART 1

## JavaScript for the backend

Install Node.js and learn the JavaScript a backend developer uses every day: values, functions, objects, JSON, async code and modules.

1. [1**Set up your computer**Install Node.js, run your first JavaScript file, and learn the two places you will run code in this course.15 min](https://zudojs.oyinlola.site/learn/setup)
2. [2**Values, variables and functions**Store values in variables, make decisions with if, repeat work with loops, and package logic into functions.25 min](https://zudojs.oyinlola.site/learn/js-values)
3. [3**Objects, arrays and JSON**Group related values into objects, keep lists in arrays, transform them with map and filter, and turn them into JSON, the format every API speaks.30 min](https://zudojs.oyinlola.site/learn/js-data)
4. [4**Asynchronous JavaScript**Learn why a backend waits without blocking, and how to write code that waits with promises, async and await.30 min](https://zudojs.oyinlola.site/learn/js-async)
5. [5**Modules and errors**Split a program into files with import and export, and handle things that go wrong with throw, try, catch and your own error classes.30 min](https://zudojs.oyinlola.site/learn/js-modules)

PART 2

## From JavaScript to TypeScript

Add types to the same code, let the compiler catch your mistakes before they run, and learn the TypeScript features ZudoJS is built on.

1. [6**From JavaScript to TypeScript**Install TypeScript, turn a JavaScript file into TypeScript, and watch the compiler catch a bug that JavaScript ran without complaint.25 min](https://zudojs.oyinlola.site/learn/ts-setup)
2. [7**Describing data with types**Annotate variables and functions, describe a task with type aliases and interfaces, and use optional, readonly and literal types to make wrong data impossible to write.30 min](https://zudojs.oyinlola.site/learn/ts-types)
3. [8**Unions, narrowing and generics**Handle values that can be one of several types, write functions that work for any type with generics, and discover the one thing types cannot do for a backend.30 min](https://zudojs.oyinlola.site/learn/ts-generics)

PART 3

## Meet ZudoJS

Install your first Zudo packages, check untrusted data at runtime, and create the Task API project you will build for the rest of the course.

1. [9**Your first Zudo code**Install your first ZudoJS packages, check untrusted data at runtime with @zudojs/schema, and report failures with the ready-made errors in @zudojs/errors.35 min](https://zudojs.oyinlola.site/learn/zudo-first-code)
2. [10**Create the Task API project**Install the ZudoJS command-line tool, create the Task API project, start its server, and find your way around every file it generated.30 min](https://zudojs.oyinlola.site/learn/zudo-create-project)
