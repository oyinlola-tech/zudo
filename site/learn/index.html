How this course works

You will build one thing from start to finish: a Task API, a backend that stores tasks and lets people create, update and complete them. Every lesson moves it one step forward.

Each lesson gives you two ways to run the code:

WhereHowGood for
In your browserPress Run in browser on any example. A terminal opens at the bottom of the page and runs the code. You can edit it and run it again.Trying ideas quickly, on any device, with nothing installed
On your computerEach lesson lists the exact commands to type, and the output you should see.Building the real project. A backend runs on a computer, so this is where you will end up

The output under each example is the real output. It was produced by running that example with Node.js and in the browser terminal, and both print exactly the same thing.

TIP

You can also open the terminal at any time with the >_ button in the header, or with Ctrl + `.

What you need

  • A computer running Windows, macOS or Linux, where you can install programs.
  • A code editor. Visual Studio Code is free and works well with TypeScript.
  • No programming experience with JavaScript is required. If you have written a little code in any language, you will move faster.

PART 1

JavaScript for the backend

Install Node.js and learn the JavaScript a backend developer uses every day: values, functions, objects, JSON, async code and modules.

  1. 1Set up your computerInstall Node.js, run your first JavaScript file, and learn the two places you will run code in this course.15 min
  2. 2Values, variables and functionsStore values in variables, make decisions with if, repeat work with loops, and package logic into functions.25 min
  3. 3Objects, arrays and JSONGroup related values into objects, keep lists in arrays, transform them with map and filter, and turn them into JSON, the format every API speaks.30 min
  4. 4Asynchronous JavaScriptLearn why a backend waits without blocking, and how to write code that waits with promises, async and await.30 min
  5. 5Modules and errorsSplit a program into files with import and export, and handle things that go wrong with throw, try, catch and your own error classes.30 min
