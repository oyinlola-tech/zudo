 What does the integrity field in package-lock.json protect against?

It is a SHA-512 hash of the tarball. npm refuses any download that does not match. It fixes the exact bytes of the version you locked; it cannot judge whether that version is safe.

npm ci gives every build the same tree you tested. Skipping dev dependencies needs --omit=dev, which a test build usually does not want.
