A command table is typed Record<string, (...args: any[]) => string>. What does that cost?

The handlers' parameter types only protect direct calls. Through a table typed with any[], the compiler checks nothing, so mistakes turn into wrong results at runtime, such as a refund of ₦NaN.

Overloads never split a union across signatures. A discriminated union argument keeps each method paired with its details, and callers holding a union of payment requests can pass it directly.

{ (id: string): Order | undefined; (ids: readonly string[]): Order[] } is how overloads are written as a type, for example for a parameter that receives an overloaded function.

 A registry stores payment gateway classes, to create instances by name later. Which type fits an element?

A construct signature describes something you call with new. PaymentGateway is the instance type, a call signature cannot be used with new, and an interface has no typeof because it is not a value.

Static members belong to the class value, so they appear next to the construct signature, not on the instance type. A class with static readonly provider = "paystack" then fits by shape.

Function behaves like an untyped callable. Use (...args: never) => unknown to accept any function, and a precise signature wherever you call it.
