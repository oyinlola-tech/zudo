What is the difference between Git and GitHub?

Git records history locally and works without any website. GitHub (like GitLab or Bitbucket) hosts copies of repositories so a team can share them.

 Why does the lesson run git config --global user.name and user.email first?

Git stamps each commit with who made it. --global saves the setting for every project on this computer.

 What does git init do?

After git init nothing is recorded yet: git status shows your files as untracked until you add and commit them.

 git status lists server.js under Untracked files. What does that mean?

An untracked file becomes part of the history only after git add and git commit. Ignored files are not listed as untracked at all.

 What are the two steps to record a change?

The staging area is the list of what goes into the next commit. This lets you choose exactly which changes a commit contains.

 Which is the best commit message?

A good message says what the commit does, in a few words. "stuff" and "fix" tell a reader nothing when they look back through the history.

 Why does the lesson say to commit small and often?

One commit per finished step means each commit has one clear purpose, and a bad change can be found and undone without touching the rest.

 Why does node_modules/ not belong in the repository?

Commit the two package files instead. Anyone who clones the repository runs npm install and gets the exact same packages.

 Why must .env never go into a repository?

A repository is copied to every developer, to GitHub and often to CI servers. Secrets stay in .env on your own computer, listed in .gitignore.

 When should you create .gitignore with node_modules/ and .env?

One careless git add . records everything Git is offering to track. With .gitignore in place first, those files never reach a commit.

 Should the .gitignore file itself be committed?

.gitignore is ordinary project configuration. Committing it protects every teammate from adding .env or node_modules/ by accident.

 A file does not show up in git status and you wonder why. Which command tells you which line of .gitignore hides it?

git check-ignore -v prints the .gitignore file, the line number and the pattern that matched, for example .gitignore:2:.env.

 What is a .env.example file for?

The example file documents what the app needs without leaking anything. The real values live only in each developer's own .env.

 Which of these should you commit in a Node.js project?

package-lock.json lets anyone reinstall the exact same package versions. node_modules/ is generated, .env is secret, and log files are local.

 What does git switch -c port-from-env do?

Without -c, git switch main moves to an existing branch. With -c it creates a new one first.

 You changed server.js (already tracked) and created a new file health.js. What does git commit -am "Update" record?

-a stages every tracked file that changed. Git does not know health.js yet, so it stays untracked.

 When does git merge stop with a merge conflict?

Changes to different lines merge by themselves. A conflict is normal, not an error: Git asks you to decide.

 You have a merge conflict in server.js. What are the steps to finish the merge?

git add marks the file as resolved. If the merge gets confusing, git merge --abort puts everything back as it was before the merge.

 After merging port-from-env you run git branch -d port-from-env. What happens to its commits?

A branch is just a name that points at a commit. After the merge, main contains those commits, so the name is no longer needed.

 You merge a branch into main, and main got no new commits in the meantime. What happens?

Nothing needs combining, so main simply moves to the branch's last commit and the graph stays a straight line.

 You committed .env by mistake, and have not pushed yet. What does the lesson do?

Nothing left your computer, so undoing the commit is enough. A new commit on top would still leave the secret in the history.

 A database password was pushed to GitHub. What must you do first?

Treat it as stolen: bots scan pushes within minutes, and others may already have pulled a copy. Only a new secret really protects you; cleaning the history comes after.

 What does git rm --cached .env do?

--cached means "only in Git". Add .env to .gitignore too, and remember the old value is still in the history.

 What does GitHub push protection do?

Secret scanning finds known secret formats in pushed code and alerts you; push protection goes further and stops the push. Neither replaces rotating a secret that leaked.

 What does -u do in git push -u origin main?

origin is the usual name of your main remote. After the first -u push, git push and git pull know where to go.

 Git asks you to log in the first time you push to GitHub. What does GitHub accept?

GitHub does not accept your account password for Git. Tokens and SSH keys can be limited and revoked on their own, without changing your password.

 You git clone the Task API onto a new computer. What else do you need before it runs?

The clone has the full history but, correctly, no generated packages and no secrets. .env.example shows which variables to fill in.

 What is a pull request?

Teams do not push straight to main. Teammates read the diff, automated tests run, and the branch is merged only when it is approved and the checks pass.
