What is a path?

A path like /home/ada/projects/notes.txt lists every folder from the top down to the file. The last part, notes.txt, is only the file's name.

 Ada uses a Mac. Where is her home folder, usually?

macOS keeps home folders under /Users. Linux uses /home/ada, and Windows uses C:\Users\ada.

 Which character separates folders in a path on Linux and macOS?

Linux and macOS use /. Windows uses \, but most tools accept / on Windows too.

 Why does the course focus on the commands used on Linux?

Most servers run Linux. macOS has almost the same commands, and Windows has PowerShell with many of the same names, so the skills carry over.

 What is the difference between the terminal and the shell?

The terminal is the window. The shell (bash, zsh or PowerShell) is the program in it that understands your commands and runs them.

 Which shell do you usually get by default on each system?

Windows uses PowerShell, macOS uses zsh and most Linux desktops use bash. bash and zsh are close cousins, so the course's commands work the same in both.

 The course writes commands like $ mkdir projects. What is the $?

The prompt (often $, % or >) is printed by the shell when it waits for a command. Type mkdir projects and press Enter.

 What is WSL on Windows?

WSL (Windows Subsystem for Linux) gives you Linux and bash on Windows. It is optional: everything in the course also works in PowerShell.

 You opened a terminal and are not sure which folder you are in. Which command tells you?

pwd ("print working directory") prints the current folder. ls lists what is inside it, which is a different question.

 You type mkdir projects and press Enter. Nothing is printed. What does that mean?

Most commands are silent on success. When something goes wrong, the shell prints an error message.

 You are in an empty folder and run these commands. What does the last ls print?
$ touch notes.txt
$ mkdir src
$ touch src/app.js
$ ls

ls lists only the current folder: one file and one folder. app.js is inside src, so you would see it with ls src.

 What does cat notes.txt print after these commands?
$ echo "Buy milk" > notes.txt
$ echo "Write report" > notes.txt
$ cat notes.txt

A single > replaces what was in the file. To add a line to the end instead, use >>.

 You want to add a line to the end of notes.txt and keep what is already in it. Which command do you use?

>> appends to the end of the file. > would replace everything in it. touch only creates empty files.

 You are in ~/projects/task-notes. You run cd .. and then pwd. What folder are you in?

.. means "the folder above this one", so cd .. goes up exactly one level, from task-notes to projects.

 What does a single . mean in a path, as in code .?

. is the current folder and .. is the folder above. So code . opens the folder you are standing in. Your home folder is ~.

 How do you see hidden files, whose names start with a dot, in bash?

ls -a ("all") also shows hidden files and the . and .. entries. In PowerShell the same is ls -Force.

 Which PowerShell command creates an empty file, like touch notes.txt in bash?

PowerShell uses New-Item. mkdir would make a folder called notes.txt, and type prints a file that already exists.

 In the command ls -a src, what is -a?

ls is the program, -a is an option (arguments starting with - or -- are options or flags) and src is a plain argument: the folder to list.

 You type nodee --version and bash says nodee: command not found. What is wrong?

"command not found" means the shell cannot find a program with that name. Here the name has an extra e. Read error messages: they nearly always say exactly what is wrong.

 On Linux you made a folder projects. Then cd Projects says No such file or directory. Why?

On Linux and macOS, capital letters matter in names. Run ls to see the real name, or type cd pro and press Tab to let the shell complete it.

 Your web server is running in the terminal and you want to stop it. What do you press?

Ctrl + C stops a running program. Tab completes names, and Up brings back the last command.

 What does the Tab key do when you have typed cd pro?

Tab completes file and folder names. It saves typing and also avoids spelling mistakes, like a wrong capital letter.

 What is a package manager like winget, brew or apt?

A package manager installs programs for you: for example brew install git on macOS or sudo apt install git on Ubuntu.

 You just installed a tool, but your open terminal says command not found. What should you try first?

The shell finds commands through the PATH, a list of folders. Installers add their folder to it, but a terminal that was already open keeps its old list.

 Which command shows where the node program is on Linux or macOS?

which node prints the path of the program, such as /usr/bin/node. In PowerShell, use Get-Command node. If nothing is found, it is not installed or not on your PATH.

 A forum post says "just run this sudo command to install Node faster". What is the safe choice?

Commands with sudo or "Run as administrator" can change anything on your computer. Only use the tool's official site or your package manager, and be careful with commands copied from the internet.

 Why should you open the whole project folder in VS Code (for example with code .), not a single file?

With the whole folder open, VS Code sees every file of the project. That is how it can show the file list, find code across files and warn about mistakes.

 Which devtools tab shows every request a page sends and every answer it gets back?

The Network tab lists requests and responses. The Console tab shows messages from the page's JavaScript and lets you run code.

 In the devtools Console you type console.log(2 + 3). It shows 5 and then undefined. What is the undefined?

console.log prints 5, but itself returns no value. The Console shows that returned value, undefined. It is not an error.

 What is the difference between Git and GitHub?

Git is the tool that saves commits: snapshots of how every file looked. GitHub is one place to keep those projects online, to back them up and work as a team.

 What does this print? console.log(2 + 3); console.log("Tasks:", ["Buy milk", "Write report"].length);

Without quotes, 2 + 3 is a sum. .length on a list counts its items: there are two tasks.

 What does this print? console.log("developer".toUpperCase()); console.log("developer".length);

toUpperCase() turns every letter into a capital. .length counts the characters: d-e-v-e-l-o-p-e-r is 9.

 What does this print? console.log("/home/" + "ada" + "/projects");

+ glues texts together exactly as they are, with nothing added in between. Here that builds the Linux path of Ada's projects folder.

 What does this print? console.log("src/app.js".length);

.length counts every character, including / and .: src (3) + / (1) + app (3) + . (1) + js (2) = 10.

 What does this print? console.log("projects".length, "src".length);

.length on text counts its characters: p-r-o-j-e-c-t-s is 8 and s-r-c is 3. console.log prints the two values on one line with a space between them, and does not print the comma.

 What does this print? console.log("PROJECTS".toLowerCase()); console.log("Task-Notes".toLowerCase());

toLowerCase() turns every capital letter into a small one and leaves everything else, such as the -, as it is.

 What does this print? console.log("~/projects" + "/" + "task-notes");

+ glues the three pieces of text together exactly, with nothing added in between. The / in the middle is a piece of text of its own, so it ends up between the folder names.

 Each console.log is like an echo in the shell. What does this print? console.log("Buy milk"); console.log("Write report");

Each call prints one line, in the order the lines are written. Nothing is replaced: that only happens with > when you write into a file.

 A command is a program name followed by arguments. What does this print? console.log("mkdir", "projects"); console.log("ls" + "-a");

With a comma, console.log prints two values with one space between them. With +, the two texts are glued with nothing in between, so ls-a has no space. In a real shell that would be one word, not the command ls with the option -a.

 Names are case-sensitive on Linux. What does this print? console.log("cd " + "Projects".toLowerCase());

"Projects".toLowerCase() gives projects, and + glues it after "cd ", which already ends with a space. The result is the command that works for a folder called projects.

 What does this print? console.log("Items:", ["archive", "list.txt"].length); console.log("Tasks:", ["Buy milk", "Write report", "Call Sam"].length);

.length on a list counts its items, not the characters inside them: two names in the first list, three tasks in the second.

 Most tools accept / in Windows paths too. What does this print? console.log("C:" + "/Users/" + "ada");

+ joins the three texts exactly as they are. Nothing turns / into \: the path keeps the slashes you typed.

 What does this print? console.log("git version", "2.53.0"); console.log("git version " + "2.53.0");

Both lines print the same text in two ways. The comma makes console.log add one space between the two values. With + nothing is added, but the first text already ends with a space inside its quotes.

Use + to join "/home/", "ada" and "/notes.txt", and print the result: /home/ada/notes.txt.

 // join the three pieces with + and print the result console.log("/home/" + "ada" + "/notes.txt"); /home/ada/notes.txt

+ glues texts exactly as they are. The slashes are already inside the pieces, so the result is the Linux path of Ada's notes.

macOS keeps home folders under /Users. Print the path of Ada's projects folder on a Mac, /Users/ada/projects, by joining "/Users/", "ada" and "/projects" with +.

 // print /Users/ada/projects by joining three texts with + console.log("/Users/" + "ada" + "/projects"); /Users/ada/projects

macOS uses /Users, not /home. The three pieces are glued in order with nothing added between them.

Print how many characters are in the file name notes.txt, using .length. The output must be 9.

 // print the number of characters in "notes.txt" console.log("notes.txt".length); 9

.length counts every character, the dot included: n-o-t-e-s (5), . (1), t-x-t (3).

Print the command that makes a folder called shopping, using one console.log with two values, "mkdir" and "shopping". The output must be mkdir shopping.

 // one console.log, two values console.log("mkdir", "shopping"); mkdir shopping

Two values separated by a comma are printed with one space between them, which is exactly how the shell expects a program name and its argument.

Print the word developer in capitals, and on the next line the number of letters in it. Use .toUpperCase() and .length. The output must be DEVELOPER and then 9.

 // print "developer" in capitals, then its number of letters console.log("developer".toUpperCase()); console.log("developer".length); DEVELOPER 9

"developer".toUpperCase() gives a new text in capitals, and "developer".length counts its characters. Print each with its own console.log.

Print how many tasks are in the list ["Buy milk", "Write report", "Call Sam"], after the text Tasks:. The output must be Tasks: 3.

 // print Tasks: followed by the number of items in the list console.log("Tasks:", ["Buy milk", "Write report", "Call Sam"].length); Tasks: 3

.length on a list counts its items. Giving console.log the text and the count as two values puts one space between them.
