bind does not call anything. It makes a new function that always runs with this set to list, so you can pass it as a callback safely.

An arrow takes this from the code around it. Here that is labelAll, called as list.labelAll(), so this is list. That is why arrows make great callbacks inside methods.

Arrows have no this of their own, so this comes from where the object is written (the module, where it is undefined). Use the short method form label() { } for methods and arrows for callbacks.
