Grace has no tasks. What happens to her in select users.name, tasks.title from users join tasks on tasks.user_id = users.id?

An inner join (join) keeps only pairs that match. Grace has no matching task, so she disappears. A left join would keep her with null on the task side.

 What does a left join do?

The left table is the one after from. Use a left join whenever "nothing on the right" is an answer you still want to see.

 What is the difference between where and having?

"Users with more than an hour of work" needs sum(...), which only exists after grouping, so it goes in having. "Only open tasks" is a row filter, so it goes in where.

 What does commit do?

begin starts a transaction, commit saves all of its changes together, and rollback undoes all of them.

 With the pg package and a Pool, how do you run a transaction correctly?

A transaction belongs to one connection. Two pool.query calls may use two different connections, so begin and your update could end up in different places.

 What is the difference between explain and explain analyze?

Because explain analyze really runs the query, be careful with it in front of an update or delete: the change happens too.

A pool reuses open connections. A server keeps it for its whole life; a script calls pool.end() so it can exit.
