Ada is logged in with a valid token and tries to delete Linus's task. The permission engine says no. Which status should the API answer?

401 means "I don't know who you are" (authentication failed). The server knows this is Ada; the answer to what she asked is no, so it is 403.

 What is a privilege escalation?

Authorization bugs that let someone do more than they should are among the most common serious security bugs in real APIs. Much of the lesson shows such attacks and how they are refused.

 In role-based access control (RBAC), how do users get their rights?

Roles keep rights manageable: change the member role once and every member changes with it.
