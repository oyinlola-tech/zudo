Write an iterative depthOf(value, limit) that returns the nesting depth of arrays and plain objects (primitives are 0, [] is 1), and stops and returns limit + 1 as soon as the depth passes limit. Use an explicit stack, not recursion, so hostile input cannot overflow the call stack.
