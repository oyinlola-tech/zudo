You write const limit = 10; and later limit = 20;. What happens when the code runs?

A const binding can never point at a new value. Assigning to it throws TypeError: Assignment to constant variable. Use let when the value must change.

 Which should you use by default for a new variable?

Start with const: it tells the reader (and you) that the value never changes. Use let for counters and values you update. Avoid var, whose scope rules cause bugs.

 Why does the lesson tell you to avoid var?

var belongs to the whole function, not the block { … } it is written in. That makes values leak out of loops and if blocks. let and const stay inside their block.

 Which of these is a valid variable name?

Names cannot start with a digit, cannot contain - (that is the minus operator), and cannot be a reserved word like let. JavaScript code uses camelCase: taskCount.

 A const variable holds an object. What does this print? const task = { title: "Buy milk", done: false }; task.done = true; console.log(task.done);

const stops the variable from pointing at another value. The object itself can still change, so setting task.done works.

 What does this print? console.log(typeof "42", typeof 42, typeof true, typeof undefined);

Quotes make a string, so "42" is a string even though it looks like a number. typeof undefined is the string "undefined".

 What does typeof null give? console.log(typeof null);

This is a famous mistake from the first version of JavaScript that can never be fixed. To check for null, compare directly: value === null.

 What does this print? const big = 9007199254740993n; console.log(typeof big, big + 1n);

The n at the end makes a bigint, a whole number of any size. You add bigints to bigints (1n), and Node prints them with the n.

 Which of these is not a primitive type in JavaScript?

The seven primitives are string, number, bigint, boolean, undefined, null and symbol. Arrays are objects: typeof [1, 2] is "object".

 A form sends the quantity as text. What does this print? const quantity = "2"; console.log(quantity + 1); console.log(quantity * 3);

+ with a string joins text, so "2" + 1 is "21". * only works on numbers, so JavaScript converts "2" to 2 and gets 6. This silent conversion is called coercion.

 What does this print? console.log(Number("42"), Number(""), Number("4 2"), Number(true));

Number() converts on purpose. An empty string becomes 0 (a common surprise), text that is not a number becomes NaN, and true becomes 1. Always check for empty input before converting.

 Which is the clearest way to turn the number price into a string on purpose?

String(price) says exactly what you mean. price + "" also works, but relies on coercion, which is easy to misread.

 What does this print? const name = "Ada"; const open = 3; console.log(`${name} has ${open * 2} tasks`);

Backticks make a template literal. Anything inside ${ } is evaluated, so open * 2 becomes 6.

 What does this print? const raw = " Buy Milk "; const clean = raw.trim().toLowerCase(); console.log(`[${clean}]`, clean.length);

trim() removes the spaces at both ends, toLowerCase() lowers every letter. "buy milk" is 8 characters long, counting the space in the middle.

 What does this print? let title = "draft"; title.toUpperCase(); console.log(title);

Strings never change. toUpperCase() returns a new string, and this code throws it away. Write title = title.toUpperCase(); to keep it.

 What does this print? const message = "Deploy finished"; console.log(message.includes("deploy"), message.startsWith("Deploy"), message.indexOf("x"));

Searches are case-sensitive, so "deploy" is not found. indexOf returns -1 when the text is missing, never null.

 What does this print? const tags = "home, work,urgent"; console.log(tags.split(",").map((t) => t.trim()).join("|"));

split(",") cuts the text at every comma, which leaves a space in front of " work". trim() removes it, and join("|") glues the pieces back together.

 What does this print? console.log(0.1 + 0.2 === 0.3); console.log((0.1 + 0.2).toFixed(2));

Numbers are stored in binary, and 0.1 and 0.2 cannot be stored exactly, so the sum is 0.30000000000000004. toFixed(2) rounds it for display and returns a string.

 You store prices for a shop. How should you avoid rounding errors like 0.1 + 0.2?

Whole numbers (up to about 9 quadrillion) are exact. Keep money in the smallest unit and convert only when you show it. Adding strings with + would join them.

 What does this print? console.log(parseInt("42px"), parseFloat("3.5kg"), parseInt("px42"));

parseInt and parseFloat read digits from the start and stop at the first character they do not understand. If the text does not start with a number, they return NaN.

 How do you check whether value is NaN?

NaN is the only value not equal to itself, so value === NaN is always false. Use Number.isNaN(value). typeof NaN is "number".

 What does this print? console.log(Math.round(2.5), Math.floor(2.9), Math.ceil(2.1), Math.max(3, 9, 4));

round goes to the nearest whole number (halves go up), floor always down, ceil always up, and max returns the largest argument.

 What does this print? console.log(10 / 0, -10 / 0, 0 / 0);

JavaScript does not throw on division by zero. It returns Infinity, -Infinity or NaN, so check your divisor yourself.

 Which of these values is truthy?

The falsy values are false, 0, -0, 0n, "", null, undefined and NaN. Everything else is truthy, including the string "0" and an empty array.

 What does this print? console.log(Boolean([]), Boolean(""), Boolean("false"), Boolean(0n));

An empty array is an object, and every object is truthy. The string "false" is not empty, so it is truthy too. 0n is the bigint zero, which is falsy.

 What is the usual difference between undefined and null?

JavaScript gives you undefined for a variable without a value, a missing property or a missing argument. You write null yourself, for example dueDate: null for "no due date".

 What does this print? const task = { title: "Buy milk", dueDate: null }; console.log(task.dueDate, task.owner);

dueDate exists and was set to null. owner does not exist, so reading it gives undefined. Reading a missing property is not an error; reading a property of undefined is.

 What does this print? const values = [null, undefined, 0, ""]; console.log(values.map((v) => v == null));

v == null is the one place loose equality is handy: it is true for exactly null and undefined, and false for other falsy values like 0 and "".
