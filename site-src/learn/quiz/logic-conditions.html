"Orders placed before 2 pm ship today, unless it is a public holiday." Which condition says when an order ships today?

"A unless B" means "A if not B", which is a && !b. The OR version would ship every order on a normal day, even one placed at 9 pm.

 "Neither suspended nor banned users may post." Which expression is true for a user who may post?

"Neither A nor B" is "not A and not B", which is also !(a || b). The OR version and !(a && b) would let a suspended-but-not-banned user post.

 "Free delivery on orders over ₦20,000, but only in Lagos." Logically, what does "but" mean here?

"But" signals a contrast in English, yet logically both parts must hold: a big order and a Lagos address.

 "A customer may withdraw only if the account is active." Which statement follows from this rule alone?

"Only if" states a necessary condition: without it, no withdrawal. It does not say being active is sufficient; other conditions can still apply.

 In the rule isAdmin || isOwner, what is isAdmin?

In an OR-rule, each part alone guarantees the result (sufficient), but none is required, because the other part can also satisfy it (not necessary).

 A rule says "customers over 18". Which operator is the literal meaning, and what should you do if you suspect the author meant 18 to count?

"Over" excludes the boundary. Boundary words are often used loosely, so asking is cheap; fixing a wrong boundary in production is not.

 By De Morgan's laws, what is !(bigOrder && inLagos)?

Negate each part and swap AND with OR. Failing either requirement is enough to lose free delivery.

 By De Morgan's laws, what is !(isAdmin || isOwner)?

To be refused by an OR-rule, you must fail every way in: not admin and not owner.

 What is the opposite of active && !locked && hasFunds?

Negate each part (!locked becomes locked) and turn every AND into OR. The opposite of a checklist is "at least one box is unticked".

 What is the exact opposite of balance >= amount?

When balance equals amount, the original is true, so the opposite must be false there. Only < does that.

 Nights must be from 1 to 30: nights >= 1 && nights <= 30. Which guard refuses exactly the invalid values?

De Morgan swaps AND for OR, and each comparison flips with its boundary: >= becomes <, <= becomes >. The AND version can never be true, since no number is below 1 and above 30.

 What is wrong with status !== "shipped" || status !== "delivered"?

"Neither shipped nor delivered" is !(shipped || delivered), which De Morgan turns into two !== checks joined with AND.

 Why does if (role === "admin" || "manager") let every user in?

Each side of || must be a complete condition: role === "admin" || role === "manager".

 What does !account.locked && account.active mean?

! binds tightest, so it applies only to account.locked. To negate a group, wrap the group in parentheses.

 What is the simplest equivalent of age >= 18 && age >= 21?

Anyone aged 21 or more is also 18 or more, so the stricter part implies the other and the looser part adds nothing to the AND.

 What is the simplest equivalent of isAdmin || (isAdmin && isOwner)?

Absorption: whenever the group isAdmin && isOwner is true, isAdmin is already true, so the group never changes the answer.

 Which is equivalent to (isMember && hasCoupon) || (isMember && isSale)?

Factor out the shared part, like 2×3 + 2×5 = 2×(3+5). Without the parentheses, a non-member during a sale would get the discount.

The condition already is the boolean you want to return. (!(balance <= amount) is balance > amount, which is wrong at the boundary.)

Three booleans have only 23 = 8 combinations. If old and new agree on all of them, they are equivalent: that is a proof, not a guess.

Comparisons can only disagree near their boundaries. Test just below, exactly on and just above each boundary, plus far values on both sides.

 How do guard clauses relate to De Morgan's laws?

!(a && b && c) is !a || !b || !c. Each guard is one of those negated parts, with its own message; the function says yes only after all of them are false.

 A locked account also has too little money. Why check locked before balance?

The final allowed/refused answer does not depend on guard order, but the reason does. Security and state checks go first; details about the request come after.

Business rules describe normal requests. Your code must also handle abnormal inputs, and in money code they are exactly what an attacker would try.

 What does "fail closed" mean for a guard-clause function?

The "yes" is the last line. Each guard can only refuse. Adding a guard can only make the function stricter, never accidentally more permissive.
