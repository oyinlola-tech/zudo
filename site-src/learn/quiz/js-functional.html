 What does referential transparency mean?

If vat(1000) always returns 75 and does nothing else, every vat(1000) could be replaced by 75. That only holds for pure functions.

Data flows from one return value into the next call. Extra settings, such as a VAT rate, are fixed in advance with currying or partial application.

 What is the difference between currying and partial application?

Curried functions make partial application trivial (call with the first argument), but you can partially apply any function with bind or a partial helper.
