Why does the migration script take pg_advisory_xact_lock(4242) first?

Two servers may start the migration at the same time. The lock makes the second one wait; when it gets the lock, it sees the migration is already recorded and skips it.

npm ci follows the lock file exactly, so the server gets the same versions you tested. --omit=dev leaves out tools that production never needs.

 Which ports should the firewall of your Linux server allow from the internet?

PostgreSQL's 5432 is never open to the internet. The app itself is reached through the proxy on 80 and 443, and SSH uses 22 with a key, not a password.

 Why does the lesson create a separate system user taskapi with no login and no admin rights?

Least privilege: the app never runs as root. A bug in the app then cannot change system files or read other users' data.

 In the unit file, what does Restart=on-failure with RestartSec=5 do?

A crash no longer means downtime until someone notices. The app comes back by itself after 5 seconds.

 The runtime's graceful shutdown can take up to 30 seconds. Why does the unit file set TimeoutStopSec=40?

After SIGTERM, systemd waits TimeoutStopSec and then kills the process. The platform's wait must be longer than the app's shutdown, or requests in flight are cut off.

 The secrets are in /etc/task-api/env. Which permissions does the lesson set?

Only root and the app need the secrets. Any other user on the server, or a process that breaks out of another service, cannot read them.

 What is the difference between a Docker image and a container?

You build an image once with a Dockerfile, then start as many containers from it as you need, on your laptop, in CI and on the server.

 Why does the Dockerfile use a multi-stage build?

In the lesson the build stage installed 85 packages and the final stage only 30. The 55 development tools never reach the image you ship.

 Why does the Dockerfile copy package.json and package-lock.json before src?

A step is rebuilt only when its inputs change. Dependencies change rarely, code changes often, so copy the dependency files first and the source code after.

 Why is CMD ["node", "dist/server.js"] written in the list form?

With the list form there is no shell in between, so the stop signal reaches Node.js directly and the graceful shutdown runs.
