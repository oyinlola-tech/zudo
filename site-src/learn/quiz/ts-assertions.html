What does const user = body as User; do at runtime?

A type assertion only changes what the compiler believes. It is erased completely, so user is exactly the same value as body, extra properties, missing properties and all.

 Why does const amount = "2500" as number; fail with error TS2352?

An assertion is allowed when one type is assignable to the other. string and number are unrelated, so TypeScript asks whether you really meant it, and suggests going through unknown if you did.

 What makes value as unknown as T compile for any T?

Each step passes the overlap rule on its own, so the pair can turn anything into anything. That is exactly why it should be rare and justified.

 Which sentence describes the difference between const x: T = value and const x = value as T?

An annotation asks the compiler to verify the value. An assertion tells the compiler to stop verifying. Neither exists at runtime.

The two forms are identical in meaning. as works everywhere, including .tsx, and reads unambiguously.
