How many members does EventName have? type Entity = "order" | "payment" | "stock" | "refund"; type Action = "created" | "updated" | "deleted"; type EventName = `${Entity}.${Action}`;

Union holes produce the cross product: one member for every combination, 4 × 3 = 12. Adding a third hole multiplies again, which is how unions explode.

 What is the difference between `ORD-${number}` and `ORD-${1 | 2 | 3}`?

A hole with a primitive type such as string or number makes a pattern. A hole with literal types makes a finite union of literals.

 Which string is not assignable to `${number}`?

`${number}` accepts strings that Number() can read as a number. Exponents, signs and hex all qualify. Numeric separators are only valid in source code: Number("1_500") is NaN.

 A checkout form types its amount field as `${number}`. Why is that not enough?

Types check the code you write, not the data users type. A money field needs a runtime check of its exact format, such as /^\d+(\.\d{1,2})?$/.

 What is `flag:${boolean}`?

boolean is the union true | false, and null and undefined are also spelled out, so the hole expands to their literal spellings.

 What is `on${Capitalize<"paid" | "shipped">}`?

Capitalize uppercases the first character, and like the other intrinsic string types it applies to each member of a union.

 Why does function upper<S extends string>(text: S): Uppercase<S> need as Uppercase<S> in its body?

Intrinsic types have no runtime part, and the standard library types toUpperCase() as string. The assertion is where you take responsibility for the runtime matching the type, so test it.

 Which value is assignable to Uppercase<string>?

On a non-literal string, Uppercase stays a pattern meaning "a string with no lowercase letters". Digits and dashes are unchanged by upper-casing, so "LAGOS-2" fits.

A template string expression is widened to string unless it is written with as const or in a place that expects a template literal type. `order.${status}` as const gives the precise union.
