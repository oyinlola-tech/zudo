How do you install the ZudoJS command-line tool, and what is the command called?

The CLI is published on npm as zudojs. It gives you two commands that do exactly the same thing: zudojs and the short zudo. There is no npm package called zudo (that is only a command name), and every framework package is named @zudojs/something.

 What does the -g in npm install -g zudojs do?

A global install puts the zudojs and zudo commands on your whole computer. -D, not -g, is the flag for a dev dependency.

 On Linux, npm install -g zudojs fails with a permission error (EACCES). What does the lesson recommend?

Don't fix it with sudo: that runs a package's install scripts with full system rights. npx zudojs@latest --version and npx zudojs@latest create … work for every command without a global install. The first time, npx asks Ok to proceed? (y); type y.

 Why does the lesson pass --package-manager npm?

The CLI supports pnpm, npm, Yarn and Bun, and defaults to pnpm. The course uses npm because it comes with Node.js.

 What does --capabilities "" mean when you create the project?

Capabilities such as Queue or Observability are optional. Starting with none keeps the project small; zudojs add brings each one in when the course needs it.

 What happens if you run zudojs create with no name and no options?

Every flag answers one of the questions (name, type, architecture, database, API style, package manager, capabilities). Leave a flag out and the CLI asks.

 The new project's .env.example leaves CORS_ORIGINS empty. What does that mean for a web page on another website that calls your API from a browser?

createCorsMiddleware gets its list from CORS_ORIGINS, and an empty list allows none. That is the safe default: set CORS_ORIGINS=https://tasks.example.com in .env to allow one site. Never use * for an API that uses logins.

 In the generated project, one client sends a 301st request within the same minute. What does it get?

createRateLimitMiddleware allows each client 300 requests per minute (RATE_LIMIT_MAX, RATE_LIMIT_WINDOW_MS). One more gets 429, so a single client cannot flood your server.

 Every response of the new project carries x-frame-options: DENY and x-content-type-options: nosniff. Where do they come from?

A request passes through securityHeaders(), CORS and the rate limit before dispatch hands it to the router, so every answer gets the headers with no work from you. DENY stops other sites from showing your pages in a frame; nosniff stops browsers from guessing a file's type.

 What does zudojs generate resource notes write in a monolith project?

A resource is a complete endpoint with every layer. The CLI also updates registerRoutes and the composition root, so /api/v1/notes works with no wiring by hand, and its tests pass straight away.

 After zudojs add openapi, why does /openapi.json list the example routes but not /health?

Every route with an openapi option ends up in the document; openapi: false hides one. The same document drives the interactive page at /docs.

 npm run dev runs tsx watch src/server.ts. What does watch add?

tsx runs TypeScript directly, and watch restarts it on every save. That is why a change to src/routes/health.routes.ts shows up without restarting by hand.

 The server says Listening on http://0.0.0.0:3000, and you open http://localhost:3000/health. What do localhost and 3000 mean?

Each program that listens for network requests uses its own port. localhost:3000 reaches the program on your own computer listening on port 3000.

 Why does GET /tasks answer 404 in the new project?

A new project has a health check and an example resource at /api/v1/examples, but no task routes. A path with no route gets a 404 with a JSON body, the same status-plus-body pattern as in Your first Zudo code.

 What is .env.example for?

It shows which settings exist; copy it to .env to change them. .env is in .gitignore. Real passwords and keys go only into the real environment, never into files you share or commit.

 What is .zudojs/manifest.json for?

The CLI reads it to learn, for example, that the project is a monolith, and chooses folders to match. Don't edit it by hand.

 The generated app builds a runtime. What is its job?

This is the lifecycle job from What a framework does: start in dependency order, stop in reverse. Modules are the pieces it starts and stops.

 You run npm run typecheck (tsc --noEmit) and it prints nothing after the script line. What does that mean?

--noEmit checks the types without writing files, and silence means success. Tests are a separate script: npm test.

 Something seems wrong with your setup. Which command should you run first?

doctor checks Node.js, the package manager, dependencies and the project files, and tells you what is wrong. info only shows versions and packages.

 What does zudojs generate resource tasks --dry-run do?

--dry-run is a safe way to learn where each kind of file belongs. Without it, generate resource writes the eight files, including the updates to src/routes/index.ts and src/container.ts.

 What does zudojs add database do?

add writes the code, registers it, adds its settings and installs its packages. You still need a running PostgreSQL and a DATABASE_URL; tables come from your models and the db:migrate script.

 What should you do right after zudojs generate writes new files?

Most schematics write code that compiles as it is, but not all: with zudojs-cli 2.1.0, generate command and generate query fail the type check. The check tells you at once whether the new files fit; fix what tsc reports.

 Why do you build for production instead of running npm run dev on the server?

npm run build runs tsc, which writes a JavaScript twin of each src/ file into dist/. npm start then runs node dist/server.js: no tsx, no watching.

 You change src/routes/health.routes.ts, then run npm start. The old answer comes back. Why?

start runs dist/server.js, not your TypeScript. Rebuild after every change, or use npm run dev while developing.

 A hosting platform sends SIGTERM when it replaces your app. What does a graceful shutdown do?

The server stops first, then the runtime stops each module in reverse, so nothing is cut off halfway. The time limit (30 s here) stops a hanging module from blocking forever.

 Why does the generated .gitignore list dist/?

Anyone can recreate dist/ with npm run build. Committing it would only create noise and stale copies. The deployment lesson builds it inside a Docker image.

The response body is JSON text, and content-length is its size: here 66 characters (bytes, since it is all plain ASCII). .length of an object would be undefined; of the string it is 66.

Months in Date.UTC start at 0, so 8 is September. toISOString() always gives this standard UTC format ending in Z, which is why the timestamps in the logs look alike on every computer.

 A shutdown with a time limit. What does this print? function withTimeout(promise, ms) { let timer; const timeout = new Promise((resolve) => { timer = setTimeout(() => resolve("timed out"), ms); }); return Promise.race([promise, timeout]).finally(() => clearTimeout(timer)); } const quick = new Promise((resolve) => setTimeout(() => resolve("stopped"), 5)); const hanging = new Promise(() => {}); console.log(await withTimeout(quick, 50)); console.log(await withTimeout(hanging, 20));
