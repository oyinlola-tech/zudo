Which property most distinguishes a set from a list?

A set has no duplicates and answers "is x in you?". Mathematically, order does not matter: {Ada, Bola} and {Bola, Ada} are the same set.

 A payment service must never process the same order id twice. It receives thousands of ids per minute. What should it keep the processed ids in?

The question asked again and again is membership. has on a set jumps almost straight to the answer; includes on an array checks items one by one, which gets slow as the list grows.

 How do you get the number of elements in a set called tags?

size is a property, so it has no parentheses. Arrays use length; sets use size.

 Which expression turns the array ids into an array without duplicates?

new Set(ids) drops the duplicates but gives a set, not an array. Spreading it into [ … ] gives an array back. new Set([ids]) makes a set with one element: the whole array.

 For any element x, "x is in A ∪ B" is the same as…

Union is OR on membership. Intersection is AND, difference is AND NOT, symmetric difference is XOR.

 You want the customers who bought both rice and oil. You have a set of rice buyers and a set of oil buyers. Which operation?

"Both" is AND, and AND on membership is intersection: rice.intersection(oil).

 Which is true about a.difference(b) and b.difference(a)?

Difference depends on the order, like a && !b versus b && !a. Union and intersection do not depend on the order.

 Which customers are in the symmetric difference of the web list and the store list?

Symmetric difference is XOR on membership: in one or the other, but not both.

 Why is there no complement() method on a JavaScript set?

"Customers not on the web list" only makes sense relative to all customers. Supply that universe explicitly and take the difference.

 required.isSubsetOf(held) is true. What does that mean?

A ⊆ B means every element of A is also in B. B may contain more. "At least one" would be "the intersection is not empty".

 A check fails. Which expression tells the user exactly which permissions they are missing?

Missing permissions are those required but not held: in required, not in held. The other order gives the extra permissions the user has.

 An admin page's required-permission set is accidentally empty. What happens with required.isSubsetOf(held)?

The empty set is a subset of every set: no element can fail the test. An empty requirement means "open to all", so a safe checker refuses empty requirements as a configuration mistake.

 What does held.isDisjointFrom(banned) check?

Disjoint sets share nothing: their intersection is empty.

 A user has the roles support and warehouse. Which operation combines the two roles' permission sets into the set the user holds?

A user holds a permission if any of their roles grants it: that is OR, so union. Intersection would give only permissions that both roles grant.

 A user's roles contain a typo, "suport". What should a well-designed permission checker do?

Fail closed: an unknown role adds no permissions. A warning makes the mistake visible instead of silently removing someone's access.

 Why does a set containing two separately created { id: 101 } objects have size 2?

Sets decide sameness almost exactly like ===, and === on objects asks "is it the very same object?". Store ids instead to de-duplicate records.

 A newsletter set contains "Ada@Mail.com" and "ada@mail.com". What is the fix?

To ===, a capital letter makes a different string. Decide what "the same customer" means, and apply it before the data reaches the set.

 What happens to a set when you pass it straight to JSON.stringify?

JSON has no set type, and a Set has no own properties to save. Convert with [...set] before saving or sending, and rebuild the set when reading.

 How can you check that two sets a and b contain exactly the same elements?

Two different set objects are never ===. Equal sizes are not enough: {1, 2} and {3, 4} have the same size. Each being a subset of the other means same elements.

 A has 30 customers, B has 20, and 5 are in both. How many are in A ∪ B?

|A ∪ B| = |A| + |B| − |A ∩ B| = 30 + 20 − 5. Adding the sizes counts the 5 shared customers twice.

 With a universe of all customers, which expression gives the customers on neither the web list nor the store list?

"Neither" is NOT (A OR B), by De Morgan. On sets: the complement of the union, which is the universe minus the union.
