A phone app shows your list of tasks. Where does the backend fit in?

The tasks are not stored on the phone. The app asks another computer for them, and a program there answers. That program is the backend. The screen you see is the front end.

 In which order does the course teach its four tools?

You start with the language (JavaScript), then the program that runs it on a server (Node.js), then types (TypeScript), and finally the framework (ZudoJS).

 What is Node.js?

Node.js is not a new language. It is a program that runs JavaScript outside the browser, for example on a server. The set of ready-made parts is ZudoJS, the framework.

 What does TypeScript add to JavaScript?

TypeScript is JavaScript with types. The types let tools find many mistakes before you run the program, instead of when a user hits them.

 The lesson calls ZudoJS a framework. What is a framework?

A framework gives you ready-made parts, so you do not write everything from zero. ZudoJS is a framework for building backends in TypeScript.

 Why does the course teach backends without a framework first, before ZudoJS?

ZudoJS is the destination, not the starting point. If you have built the pieces by hand first, the framework is no longer magic: you understand the problems it solves.

 You have never written code. How should you use this course?

Complete beginners follow every lesson in order. Each new word is explained the first time it appears, so skipping ahead means missing those explanations.

 You already know Python. What does the lesson advise about the first JavaScript lessons?

Knowing another language helps, so the start feels quick. But JavaScript has its own rules and surprises, so the lesson tells you to read those parts anyway.

 What do you need to take this course?

You only need a computer where you can install programs, on Windows, macOS or Linux. You do not need to be good at maths, and the course is free.

 Which three projects do you build in this course, from smallest to biggest?

Each project is bigger than the last: the Task API first, then the BookStore API in TypeScript, then ShopFlow, the capstone in the Production part.

 What is the Task API?

The Task API stores tasks. You write it first with plain Node.js, then rebuild it with ZudoJS. The book shop is the BookStore API, and the commerce backend is ShopFlow.

 The BookStore API is written in TypeScript with no framework. Why?

Building it by hand shows you the repeated work and problems that a framework removes. The final project is ShopFlow, not the BookStore API.

 What is ShopFlow?

ShopFlow is the capstone in the Production part: products, orders, users and background work, ready to deploy. A capstone is the big final project that uses everything you learned.

 How is the Task API written during the course?

You write the Task API by hand with Node.js first. Later you rebuild it with ZudoJS and add a database, users, permissions, events, queues and tests.

 Which of these is not on the lesson's list of things you will know by the end?

The course is about backends: JavaScript, Node.js, HTTP, databases, TypeScript, ZudoJS and production work such as Docker. Building phone apps is not part of it.

 The lesson says you will learn "where types stop and runtime checks must begin". What does that point to?

Types catch mistakes before the code runs. But data from users or other programs arrives while it runs, and types cannot check that. So a backend must also check data at run time.

 How is the course organised?

There are 84 lessons in 17 parts. A part is a group of lessons on one subject, like "JavaScript fundamentals" or "Data".

 What is a part in this course?

A part groups lessons on one subject. The label that says how much you need something is the tier, not the part.

 What does the Foundation tier mean?

Foundation parts (Start here, JavaScript, Node.js and npm, Backend fundamentals, TypeScript) must be understood before you continue. "Required for everyday ZudoJS work" is Core.

 The "Events and background work" part is Advanced. What does that tell you?

Advanced means "learn it when your application needs it". It is not forbidden for beginners; it is just not required before you move on.

 When should you learn the Production tier?

The Production tier covers what you need to deploy and run a real system. You learn it when you prepare an application for deployment.

 Kemi already builds websites with JavaScript in the browser but has never written a server. Where should Kemi start?

People who already know JavaScript can skip the JavaScript part. How the web works is worth reading if the web is new, then Node.js and npm is the next step.

 Lee writes TypeScript backends every day. Where should Lee start?

Someone who knows TypeScript and backends goes straight to Meet ZudoJS. If a lesson uses something skipped, it links back to the lesson that teaches it.

 What comes at the end of every lesson page?

Each lesson has short sections with an example and its output, then a Practice section with exercises and a Recap of the main points.

 You press Run in browser under an example. What happens?

The browser terminal opens at the bottom of the page and runs the example right there. You can change the code and run it again with Run or Ctrl + Enter.

 An example is marked Node.js only. Why can it not run in the browser?

Browsers are not allowed to read your files or start web servers. Examples that do that must run on your own computer with Node.js.

 A box shows $ node --version. What do you type in your terminal?

A line starting with $ is a command for you to type, but you do not type the $ itself. The lines under it (like v24.19.0) are what the computer printed back.

 In a command box, what are the lines without a $ in front?

Only lines that start with $ are commands. The lines under a command are its output, for example the version number that node --version prints.

 Your computer prints something different from the output shown in a lesson. What is the most likely reason?

Every output on the pages is real: it was produced by running the code. So a difference usually means a small typing mistake, and finding it is part of learning.

 Where is your "Mark this lesson as done" progress saved?

Progress is saved in your browser on this device. You do not need an account. On another computer or browser, your ticks are not there.

 You are afraid to change the code in the browser terminal. What does the lesson say?

The browser terminal is a safe place to try things. Change the code, press Run, and see what happens.

The quotes only mark where the text starts and ends. console.log prints the text inside them, without the quotes.

 What does this print? console.log("Parts:", 17, "Lessons:", 84);

console.log prints every value you give it on one line, with a single space between them. The commas in the code separate the values; they are not printed.

 What does this print? console.log(84); console.log("84");

The first line prints the number 84, the second prints the text "84". On their own, both look the same: console.log does not show the quotes of a string.

A comma gives console.log two values, which it prints with a space between them. + joins two texts into one, with no space added.
