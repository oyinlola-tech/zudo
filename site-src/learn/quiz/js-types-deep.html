Which of these values is not a primitive?

The seven primitives are string, number, bigint, boolean, undefined, null and symbol. An array is an object: a mutable container with its own identity.

 Why does 10n + 1 throw a TypeError?

Mixing them would force JavaScript to pick a precision for you. Write 10n + 1n, 10n + BigInt(1) or Number(10n) + 1.

 What is special about a symbol?

Symbol("id") === Symbol("id") is false: the description is only a label. Symbol.for(name) is the exception, returning one shared symbol per name from a global registry.

 How do you check reliably whether a value is an array?

typeof says "object" for arrays, plain objects, dates and null alike. Array.isArray answers the question exactly; a string also has a length.

 When is a WeakMap the right choice?

A WeakMap accepts only objects as keys and does not keep them alive, so it cannot leak memory. In exchange you cannot iterate it or ask its size.

 After const template = { items: [] }; const cart = template; cart.items.push("Garri");, what is template.items?

Assignment copies the reference, not the object. There is one object with two names, so a change through either name is visible through both.

 A function does order = { total: 0 }; to its order parameter. What happens to the caller's object?

Parameters are new variables filled from the arguments. Reassigning one changes only that variable. Changing a property (order.total = 0) would change the caller's object, because both point at it.

 Every new customer should start with an empty cart. Which approach gives each customer a separate cart?

An object literal creates a new object each time it runs, so a factory function that returns one gives every call its own cart and its own list inside.

 Why does const cart = { items: [] }; cart.items.push("Oil"); work?

const is about the variable. cart = {} would fail, but changing the object it points at is allowed. To stop that, freeze the object.

 const config = Object.freeze({ vat: 7.5, limits: { daily: 100000 } }); Which change still succeeds?

Object.freeze is shallow: it locks the object's own properties, but limits is a separate object that was not frozen.

 What does const name = "ada"; name.toUpperCase(); do to name?

Primitives never change. String methods return new strings; to keep the result, store it: const loud = name.toUpperCase();.

 Why is { id: 1 } === { id: 1 } false?

For objects, === answers "is this the same object?". Two objects written separately are never the same object, whatever they contain.

 You need to know whether two order-line objects have the same sku and qty. What is the most reliable check?

Nothing built in compares object contents. Compare the fields that matter. String(a) is "[object Object]" for every plain object, so it would call all of them equal.

 Which comparison is true?

Object.is is like === without its two exceptions: it treats NaN as equal to itself, and it tells 0 and -0 apart.

 Why does [NaN].indexOf(NaN) return -1 while [NaN].includes(NaN) returns true?

Different built-ins use different equality algorithms. includes, Map and Set use SameValueZero; indexOf uses strict equality.

 Orders are stored in a Map with number keys. The id read from a web address is the string "42". What does orders.get("42") return?

Maps compare keys with SameValueZero, which never converts types. Convert the text to a number (after validating it) before the lookup.

 What decides whether + adds or joins text?

That is why 1 + 2 + "3" is "33" (first 3, then join) and "1" + 2 + 3 is "123".

 Why is null >= 0 true while null == 0 is false?

Relational operators convert to numbers; loose equality has its own rule for null and undefined. Check for null explicitly instead of relying on either.

 Where should text from a form or web address be converted to numbers?

Converting at the edge means inner code never has to wonder whether an id is text, and invalid input is rejected in one place.

 For which values is value == null true?

Loose equality makes null and undefined equal to each other and to nothing else. It is the one widely accepted use of ==.

 A customer email says: Your order [object Object] has shipped. What happened?

String conversion of a plain object uses its default toString. The template probably received the whole order object instead of order.id.

 Which statement about typeof is correct?

For objects, typeof only distinguishes functions. Dates, arrays, maps and even null all give "object".

 What does this print? const defaults = { currency: "NGN", tags: [] }; const shopA = defaults; const shopB = { ...defaults }; shopA.currency = "USD"; shopB.tags.push("new"); console.log(defaults.currency, defaults.tags.length, shopB.currency);

shopA is the same object as defaults, so the currency change shows up. shopB is a shallow copy: its own currency is separate, but tags still points at the same list.

 What does this print? function markPaid(invoice) { invoice.paid = true; invoice = { paid: false, note: "replaced" }; return invoice.note; } const invoice = { paid: false }; const result = markPaid(invoice); console.log(invoice.paid, invoice.note, result);

The property change went to the caller's object. Reassigning the parameter only pointed the function's own variable at a new object, so the caller never sees note.

 What does this print? console.log(Number(""), Number(" 7 "), Number("7kg"), Number(null), Number(undefined), Number([]), Number(["8"]));

Empty text becomes 0 and spaces are trimmed, but any other character gives NaN. null becomes 0 and undefined NaN. Arrays become text first: "" is 0 and "8" is 8.

 What does this print? console.log(`${[1, 2]}|${[]}|${null}|${{}}|${-0}`);

Arrays join their items with commas (an empty array is empty text), null becomes "null", a plain object becomes "[object Object]", and -0 loses its sign as text.

 What does this print? console.log(2 + 3 + "4", "2" + 3 + 4, "8" - 3, true + 1, [] + 1, null + 1);

+ works left to right and joins as soon as one side is text. - always converts to numbers. true is 1. [] becomes "", so [] + 1 is the text "1". null is 0 in arithmetic.

 What does this print? console.log("" == 0, "0" == 0, "" == "0", "1" == true, "2" == true, null == false);

Strings compared with numbers become numbers, so the first two are true, but two strings compare as text. A boolean becomes a number first: true is 1, so "2" == true is false. null only equals undefined.

 What does this print? console.log(NaN === NaN, Object.is(NaN, NaN), 0 === -0, Object.is(0, -0), [0].includes(-0));

=== treats NaN as unequal and 0/-0 as equal. Object.is does the opposite on both. includes uses SameValueZero: NaN equals NaN, and 0 equals -0.

 What does this print? const seen = new Set([1, "1", NaN, NaN, 0, -0, { id: 1 }, { id: 1 }]); console.log(seen.size);

1 and "1" are different; the two NaNs count once; 0 and -0 count once (SameValueZero); the two objects are two different objects. 1, "1", NaN, 0 and two objects: 6.

 What does this print? const prices = [1500, 200, 850]; const cheapFirst = prices.toSorted((a, b) => a - b); const same = prices; same.reverse(); console.log(prices.join(","), cheapFirst.join(","));

toSorted returns a new list. same is the same list as prices, and reverse changes that list in place, so prices is reversed.

 What does this print? const fee = { kobo: 150000, valueOf() { return this.kobo; }, toString() { return "₦1,500"; }, }; console.log(fee + 50000, `${fee}`, fee > 100000, fee * 2);

Arithmetic and comparisons ask for a number, so valueOf is used. A template literal prefers text, so toString is used.

 What does this print? const limits = Object.freeze({ daily: 100000, channels: ["atm", "pos"] }); try { limits.daily = 5; } catch (error) { console.log(error.name); } limits.channels.push("web"); console.log(limits.daily, limits.channels.length);

In strict code, writing to a frozen property throws a TypeError. Freezing is shallow, so the list inside can still grow.

 What does this print? console.log(typeof 5n, typeof Symbol(), typeof null, typeof [], typeof new Map(), typeof Math.max);

typeof names the primitive types, says "object" for null (the 1995 bug) and for every non-function object, and "function" for functions.
