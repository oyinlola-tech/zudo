What is ECMAScript?

Ecma International publishes the ECMAScript standard; every engine implements it. "JavaScript" is the everyday name for the language that standard describes.

 A tutorial says "this needs ES6". Which edition is that?

ES6 is the old name of ES2015, the big update that brought let, const, arrow functions, classes, modules and promises. From then on, editions are named after their year.

 Why has a new ECMAScript edition come out every year since 2016?

After the six-year gap before ES2015, TC39 moved to a "release train": each June, the finished features ship, and anything not ready waits for the next year.

 A blog post shows a proposal "currently at stage 2". What does that tell you?

Only stage 4 means finished and part of the language. At stage 2 the specification is a draft, so the feature, and the blog post about it, may change.

 What does stage 3 mean for a proposal?

Stage 3 is "ready to implement". It reaches stage 4 after it passes the Test262 suite and ships in at least two engines.

 How does TC39 decide to move a proposal forward?

TC39 works by consensus, and its proposals and meeting notes are public on GitHub.

 Why will typeof null always be "object", although everyone agrees it is a mistake?

"Don't break the web" is TC39's first rule. Billions of pages will never be updated, so a behaviour, once shipped, almost never changes.

 Why is the array method called flat() and not flatten()?

In 2018 the proposal was renamed so that pages using MooTools kept working. It is a real example of "don't break the web".

 Where does console.log come from?

The engine runs the language; the host adds abilities such as printing, timers and networking. Browsers and Node.js both provide console, following a separate standard.

 Why is typeof document equal to "undefined" in Node.js?

The language is the same; the host differs. The browser adds document and window; Node.js adds process and file access instead.

 You want to use a feature added in ES2025. Why is the decision easier for backend code than for code sent to browsers?

Check your server's Node.js version once and you know. For browsers you must check compatibility tables (MDN, caniuse.com), detect features, or transpile.

 Which line checks whether Object.groupBy exists without crashing on an older runtime?

typeof gives "undefined" for a missing property instead of throwing, so this is feature detection. Calling a missing method throws a TypeError.

 What is the difference between a transpiler and a polyfill?

New syntax (like ?.) cannot be added by a function, so a tool must rewrite it. A missing function (like Object.groupBy) can be added by code: that is a polyfill.

 Which engine does Node.js use?

Node.js is built on V8, the engine from Chrome. SpiderMonkey is Firefox's engine and JavaScriptCore is Safari's (and Bun's).

 Which of these is an expression?

An expression produces a value. price * quantity does; a declaration, an if and a for are statements that do something but produce no value you can use.

 Which of these can go inside ${…} in a template literal?

Only expressions fit in ${…}. The ternary operator is the expression form of if/else, which is why it is used there.

 A function ends with return on one line and the object it should return on the next line. What does it return?

A line break is not allowed directly after return, so automatic semicolon insertion ends the statement there. Start the returned value on the same line: return {.

 In code written without semicolons, a line starting with which character can silently join the line before it?

A line starting with (, [ or a backtick can continue the previous expression (as a call, an index or a tagged template), so no semicolon is inserted.

 You wrap some code in /* … */ to disable it, but the code already contains a /* note */ comment. What happens?

Block comments do not nest. Disable lines with // in front of each one instead; editors do this with one shortcut.

 By convention, which name is most likely a class you create with new?

PascalCase marks classes and constructors (Map, Date, BankAccount). camelCase is for variables and functions, UPPER_SNAKE_CASE for fixed settings, and dashes are not allowed in names at all.

 Which is the best name for a boolean that says whether an invoice has been paid?

Boolean names read as yes/no questions: isPaid, hasStock, canWithdraw. paidAmount suggests a number.

 In an ES module, you mistype a variable: totl = 5000 instead of total = 5000. What happens?

Strict mode turns assignment to an undeclared name into an error. Every ES module is strict automatically, so typos like this are caught at once.

 What does this print? function receiptTotal() { return 8500 + 5000; } console.log(receiptTotal());

A semicolon is inserted right after return, so the function returns nothing. The sum on the next line is never evaluated.

 Without a semicolon, the second line joins the first. What does this print? const city = "Lagos" [1, 2] console.log(city)

The engine reads const city = "Lagos"[1, 2]. Inside the brackets, 1, 2 evaluates to 2, so city is the character at position 2 of "Lagos": "g".

 What does this print? const fee = 1500 try { const total = fee (2 + 3) console.log(total) } catch (error) { console.log(error.name) }

The line starting with ( continues the previous one, so the engine reads fee(2 + 3): a call to a number, which throws a TypeError at run time.

 What does this print? let orders = 1 let refunds = 1 orders ++ refunds console.log(orders, refunds)

A line break is not allowed before a postfix ++, so a semicolon goes after orders and the ++ attaches to the next line: orders; ++refunds;.

 What does this print, in both Node.js and the browser? console.log(typeof Math, typeof JSON.stringify, typeof console.log, typeof notDefinedAnywhere);

Math is a built-in object; JSON.stringify and console.log are functions. typeof on a name that does not exist gives "undefined" instead of throwing, which is what makes feature detection safe.

 What does this print? const deliveries = [["Ikeja", "Yaba"], ["Lekki"], [], ["Ajah"]]; console.log(deliveries.flat().length, typeof deliveries.flatten);

flat() joins the inner lists into one list of 4 places. flatten does not exist: it was renamed to flat so that old websites would not break.

 What does this print? for (const code of ["console.log(1 + 1)", "console.log(if (true) 1)"]) { try { new Function(code); console.log("valid"); } catch (error) { console.log(error.name); } }

new Function(code) only compiles the text; it does not run it, so nothing is printed by the first one except "valid". An if statement where a value is expected is a syntax error.

 What does this print? console.log(8500 + 2 * 2500, (8500 + 2) * 2500);

* runs before +, as in school maths, so the first is 8500 + 5000. Parentheses change the order: 8502 × 2500.

 What does this print? const total = 25000; console.log(`Delivery: ${total >= 20000 ? "free" : "₦1,500"}`); console.log(total < 10000 ? "small" : total < 50000 ? "medium" : "large");

A ternary is an expression, so it fits in ${…} and can be chained: 25,000 is not under 10,000, but it is under 50,000.

 What does this print? const price=2500 ; const quantity = 2; console.log(price*quantity, " x ".length);

Whitespace between tokens does not matter to the engine, so the odd layout still works. Inside a string, spaces are part of the text: " x " has 3 characters.

 What does this print? function applyDiscount() { "use strict"; let price = 10000; try { prise = price * 0.9; return price; } catch (error) { return error.name; } } console.log(applyDiscount());

prise was never declared. In strict mode assigning to it throws a ReferenceError instead of silently creating a global variable, so the typo is caught.

 Which of these names are valid? What does this print? for (const name of ["_total", "$fee", "naïra", "3rdPlace", "new"]) { try { new Function(`const ${name} = 1;`); console.log(name, "ok"); } catch { console.log(name, "invalid"); } }

Names may start with a letter (from any alphabet), _ or $, but not a digit. new is a reserved word. catch without (error) is allowed when you do not need the error.

Someone disabled the discount with a block comment around code that already contains a comment, and now the program will not run. Disable the discount line correctly with // so that the program prints 13500.

 let total = 13500; /* total = total * 0.9; /* 10% launch discount */ */ console.log(total); let total = 13500; // total = total * 0.9; /* 10% launch discount */ console.log(total); 13500

Block comments do not nest: the first */ ended the outer comment and the final */ became broken code. A line comment hides everything to the end of its line, including the inner block comment.
