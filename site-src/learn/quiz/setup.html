What is the difference between JavaScript and Node.js?

JavaScript is the language. In the browser, the browser is the runtime. On your computer and on servers, the runtime is Node.js.

 Which Node.js version does ZudoJS need?

ZudoJS needs Node.js 24 or newer. Check with node --version: the result must start with v24 or higher.

 On the Node.js download page, why should you pick the LTS version?

LTS stands for long-term support. It gets fixes for a long time, so it is the stable choice. It must also be version 24 or newer.

 You installed Node.js, but your open terminal says node: command not found. What should you do first?

The installer adds Node.js to your PATH, the list of folders where the shell looks for programs. Old terminals still have the old list. If a new terminal also fails, restart the computer.

 What is npm?

npm is installed together with Node.js. It installs packages, pieces of code other people published, such as ZudoJS.

 What does REPL stand for?

The REPL reads one line of JavaScript, evaluates (runs) it, prints the result, and loops back to wait for the next line.

 How do you start the Node.js REPL?

Typing node with nothing after it starts the REPL, and the prompt changes to >. node hello.js runs a file instead.

 In the REPL you type "Buy " + "milk". What does it show?

The result is text, and the REPL shows text in quotes so you can tell it apart from numbers. console.log would print it without quotes.

 In the REPL you type const tasks = ["Buy milk", "Write report"]. It shows undefined. What does that mean?

undefined means "no value". Storing something gives no result, but it worked: typing tasks.length next shows 2.

 In the REPL, console.log("Hi") shows Hi and then undefined. Why the undefined?

console.log does its job (printing) but returns no value. The REPL always shows the result of a line, so it shows undefined.

 How do you leave the REPL?

.exit leaves the REPL. Ctrl + D, or Ctrl + C twice, does the same.

 Why do you write real programs in files instead of the REPL?

The REPL is great for a quick "what does this give?". But nothing is saved, so real programs go in files that you can run again and again.

 Your file is at src/app.js inside the current folder. How do you run it?

node needs the path of the file from the current folder. node app.js would look for app.js in the current folder and not find it.

 You changed hello.js. What do you do to see the new output?

Node.js runs the file as it is saved on disk at that moment. Save, then run the command again. Up brings back the last command.

 What does package.json record?

Every Node.js project has a package.json. npm init -y writes one for you with the project's name, version and other settings.

 What does npm init -y do?

npm init creates package.json. -y ("yes") accepts all the default answers, so you are not asked any questions.

 After npm init -y, the course runs npm pkg set type=module. Why?

npm init -y writes "type": "commonjs", the old way of splitting code into files. ES modules are the modern way. After the command, the line says "type": "module".

 You run npm pkg set type=module and it prints nothing. What happened?

Like many commands, it is silent on success. Open package.json to check: the last line now says "type": "module".

 What is a comment in JavaScript?

// starts a comment until the end of the line, and /* … */ wraps a comment over several lines. Node.js ignores both.

 Which comment is the most useful?

Good comments explain why the code is written this way. "print the tasks" only repeats what the code already says.

 A file is console.log("Hello from Node.js!); with the closing quote missing. What happens when you run it?

Without the closing ", the text never ends, which breaks JavaScript's grammar. Node.js rejects the whole file with SyntaxError: Invalid or unexpected token.

 A file is Console.log("Hi");. What error do you get?

JavaScript is case-sensitive: Console is a different name from console, and no Console exists. The grammar is fine, so the file starts and fails at that line.

 Which three things should you read in a Node.js error?

The top says where (file and line), the name says what kind (SyntaxError, ReferenceError, TypeError), and the message says what is wrong. The at node:internal… lines are inside Node.js, not your code.

 A file has a missing " on line 1, Console.log on line 2 and a missing ) on line 3. Which error do you see first?

Syntax errors stop the whole file before anything runs, so Node.js reports one of them first. The capital C is only found while the code runs, after the grammar is fixed.

 What does this print? console.log("Hello from Node.js!");

In a file, console.log prints the text without quotes. The extra undefined only appears in the REPL or the devtools Console.

 What does this print? // This program prints a short task list. console.log("My tasks for today:"); console.log("- Buy milk"); // a comment can also end a line // console.log("- Walk the dog"); console.log("- Write report");

Everything after // is skipped. That includes the whole line with "Walk the dog": putting // in front of code is a common way to switch it off.

 What does this print? console.log("one"); /* console.log("two"); console.log("three"); */ console.log("four");

Everything between /* and */ is one comment, even across several lines, so the two lines inside it never run.

 What does this print? console.log("Tasks:", 2, "Done:", 0);

console.log prints all its values on one line, with one space between them. The commas in the code are not printed.

 What does this print? console.log(1 + 2); console.log(10 * 3 - 4);

* runs before -, so 10 * 3 - 4 is 30 - 4, which is 26.

 What does this print? console.log("Minutes in a week:", 7 * 24 * 60);

Numbers without quotes are calculated: 7 days × 24 hours × 60 minutes is 10080. 1440 is only one day, and 168 is the hours in a week.

 What does this print? console.log("7 * 24"); console.log(7 * 24);

Text in quotes is printed exactly as written. Without quotes, 7 * 24 is a calculation, so it prints 168.

 What does this print? const tasks = ["Buy milk", "Write report"]; console.log(tasks.length);

const tasks = … stores the list under the name tasks. tasks.length is how many items it holds: 2.

 What does this print? console.log("Buy " + "milk"); console.log("Buy" + "milk");

+ joins texts exactly as they are. The first has a space at the end of "Buy ", the second does not. In a file, console.log shows no quotes.

 What does this print? try { Console.log("Hello from Node.js!"); } catch (error) { console.log(error.name + ":", error.message); }

Console with a capital C is a name that does not exist, so JavaScript throws a ReferenceError. The catch prints its name and message instead of crashing.

 What does this print? console.log("Shopping list:"); console.log("- Bread"); console.log("- Milk");

Statements run from top to bottom, one after another, and each console.log prints one line.

 What does this print? console.log("Tasks:", 3); // 3 tasks today console.log("Done:", 1); /* only one done */

A comment can end a line after the code. Node.js runs the code before it and skips the comment.

 What does this print? try { consol.log("Hi"); } catch (error) { console.log(error.name); }

consol is misspelt, but the grammar is still fine. The name simply does not exist, which is a ReferenceError when that line runs.

Every error has a name and a message. error.name + ":" glues the colon to the name, and the comma adds a space before the message.
