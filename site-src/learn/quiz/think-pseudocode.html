What is pseudocode?

Pseudocode is for people. It is precise enough to argue about and simple enough for a non-programmer to read. The drawing with boxes and arrows is a flowchart.

 The branch manager knows the ATM rules but cannot read JavaScript. Why write pseudocode before the code?

Writing the pseudocode forced decisions the email never made: the order of the checks, the exact messages, whether the whole balance can be taken. The manager can check those, which is much cheaper than fixing code later.

 Which flowchart symbol shows a yes/no decision?

A diamond holds a yes/no question and has two labelled exits. It is the flowchart version of IF.

 Which symbol is used for INPUT balance, amount or OUTPUT "Insufficient funds"?

Data coming in and results going out are drawn as slanted boxes. Rectangles are for processes (calculations), diamonds for decisions and rounded boxes for Start and End.

 What does a rounded box (terminator) mark in a flowchart?

Every flowchart begins at a Start terminator and finishes at an End terminator. They match START and END in pseudocode.

 How many arrows should leave a decision diamond?

A diamond with only a "yes" arrow leaves the "no" case undefined: the flowchart version of a missing case. Always draw and label both exits.

 How is a loop drawn in a flowchart?

The arrow goes back to a decision such as "saved < goal?". The decision's other exit is the way out. An arrow back with no decision on its path never ends.

 When you translate pseudocode into JavaScript, what does END IF become?

JavaScript marks the end of a block with a closing brace. END WHILE and END FOR also become }.

 What does ELSE IF amount > balance THEN become in JavaScript?

It must stay part of the same chain. Writing it as a separate if changes the meaning: every check runs, even after an earlier one has failed.

 Which JavaScript does OUTPUT "New balance: ₦" balance become in these lessons?

For now, output means printing with console.log. In a backend, the same pseudocode line would become part of an HTTP response.

 Which pseudocode line is too vague?

Check it for what? Two developers would write different code from it. A good test: if two people could translate your line differently, it is not precise enough.

 Which line is really code, not pseudocode?

Brackets, abbreviations and operators like !== make it unreadable for the manager, and it gains nothing over real code. Pseudocode should be readable by someone who does not program.

 The rule: "Delivery is free for orders of ₦15,000 or more; otherwise it costs ₦1,500." Which pseudocode is correct?

"Or more" means >=. The first option charges delivery on an order of exactly ₦15,000; the third swaps the two cases; the fourth never sets delivery when the order is small.

 Which pseudocode correctly outputs the total of a list of prices?

The total must start at 0 once, before the loop. The first option resets it every round, so it outputs only the last price. The third prints a running total on every round. The fourth never gives total a starting value.

 A customer with a blocked card asks for ₦25,300, which breaks two more rules. Why do they only see "Card blocked"?

In a chain of ELSE IFs, as in a column of diamonds, you only reach a check if every check above it passed. The order of the diamonds is a design decision.

 A flowchart has four refusal paths and one success path from Start to End. What is the smallest number of test cases that visits every path?

Each path is a different behaviour, so each needs at least one test. Then add boundary tests on top, such as exactly the limit and exactly the balance.

 The first withdrawal flowchart checked the limit, the multiple of 500 and the balance. Which input slipped past every check to the success path?

0 and -500 are both multiples of 500, are not over ₦20,000 and are not over the balance. A negative withdrawal even added money to the account. The fix was a new diamond, "amount < 500?", added to the design first.

 A developer translates the chain of ELSE IFs into separate ifs, with the final else (pay out) attached to the last one. What can go wrong?

Separate ifs all run, so every failed rule prints its message. And the else only belongs to the last if, so if the balance is enough, the cash comes out after the error messages.

 Inside WHILE saved < goal DO, someone forgot the line SET saved TO saved + perWeek. What happens?

The condition only becomes false if something inside the loop changes it. When you trace a loop, check that every round moves towards the exit.

 When is a flowchart usually a better choice than pseudocode?

A flowchart shows at a glance which paths exist and where they lead. Past 15 or so boxes it gets hard to follow, and pseudocode scales better.

 What is a trace table?

Tracing predicts what an algorithm does before any code runs. Printing the values inside a loop gives the same table, which is a good way to check your trace.

 WHILE saved < goal DO starts with saved = ₦60,000 and goal = ₦50,000. How many times do the indented steps run?

WHILE checks its condition before every round, including the first. 60,000 < 50,000 is false, so the body never runs. In the flowchart, the decision sits at the top of the loop.
