## How Sponsorship Works

Sponsorship is managed through [GitHub Sponsors](https://github.com/sponsors/oyinlola-tech). All recognition is based on public GitHub Sponsors profiles unless otherwise requested.

### Updating This Page

This page is automatically updated when new sponsors join. To request changes to your listing:

1. Open an issue on the [Zudo repository](https://github.com/oyinlola-tech/zudo/issues)
2. Reference your sponsorship details
3. The maintainers will update the page

### Privacy

- Only public GitHub usernames are displayed by default
- Organizations may display their name and logo
- Private sponsorship details are not shared
